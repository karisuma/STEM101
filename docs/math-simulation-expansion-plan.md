# STEM101 수학 시뮬레이션 확장 제안

작성 기준: 2026-08-13

## 1. 현재 공백 진단

현재 구현된 수학 실험실은 `확률·표본·추론`과 `함수·변환·모델링` 두 개다. 함수와 통계의 탐구 기반은 확보했지만 다음 교육과정 축이 비어 있다.

- 중학교: 수와 연산, 문자와 식, 방정식·부등식, 도형과 측정
- 고등학교: 지수·로그, 삼각함수, 수열, 미분·적분, 벡터·행렬, 공간도형
- 공통 결손: 식·그래프·기하 장면을 서로 번역하는 경험, 증명 전 추측과 반례 탐색, 오차와 근사의 정량 비교

2022 개정 교육과정은 수학과를 별책 8로 고시했고, 2026학년도에는 중학교 2학년과 고등학교 2학년까지 적용 범위가 확대된다. 따라서 신규 교구는 2015 개정 내용만 재현하기보다 2022 개정 성취기준의 탐구·디지털 소양 방향에 맞춰야 한다.

근거 자료:

- [교육부 고시 제2022-33호 — 초·중등학교 교육과정 총론 및 각론](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)

## 2. 우선 개발 제안

### P0 — 중학교 핵심 공백을 먼저 채우는 6개

| 프로젝트 | 핵심 오개념·질문 | 주요 조작과 샌드박스 | 1시간 수업 산출물 |
|---|---|---|---|
| 수체계·수직선·근삿값 실험실 | 음수의 크기, 절댓값, 유리수와 무리수, 근삿값과 실제값을 혼동한다 | 수직선 확대·축소, 수 카드 배치, 제곱 넓이에서 제곱근 구성, 반올림 자리와 허용 오차 조절 | 수의 분류 지도, 오차 구간, 학급별 추정 오차 분포 |
| 대수 타일·항등식·인수분해 공작소 | 음수 타일, 분배법칙, 전개와 인수분해의 역관계가 끊어진다 | 양·음 타일을 놓고 자르기·합치기·상쇄하기, 직사각형 변의 길이 구성 | 같은 식의 서로 다른 타일 구성, 최소 타일 해법, 오류 유형 통계 |
| 방정식·부등식 균형 실험실 | 이항을 단순한 ‘부호 바꾸기’로 외우고 부등호 반전의 이유를 모른다 | 양팔저울 양쪽에 항 추가·제거·배율 적용, 해집합 수직선, 매개변수 슬라이더 | 등가 변형 기록, 해가 없음·하나·무수히 많음 분류, 풀이 단계 비교 |
| 작도·합동·닮음 자유 설계실 | 눈으로 비슷해 보이는 것과 수학적 합동·닮음을 혼동한다 | 점·선·원·평행선·수선을 제한 도구로 작도, 꼭짓점 드래그, 조건 잠금, 도형 절단·재조립 | 최소 작도 미션, 조건별 반례, 학급 해법 수·단계 수 분포 |
| 피타고라스·삼각비 측량 실험실 | 빗변 식별, 제곱 관계, 각에 따른 비의 불변성을 혼동한다 | 사다리·그림자·경사로·관측점 배치, 길이·각도·측정 오차 조작 | 접근 불가능한 높이 추정, 서로 다른 측량법 오차 비교 |
| 공간도형·전개도·단면 실험실 | 2차원 그림만 보고 보이지 않는 면, 단면, 부피를 잘못 추론한다 | 정육면체 블록 조립·해체, 전개도 접기, 절단 평면 회전·이동, 내부 채우기 | 가능한 전개도 판정, 같은 부피의 다른 모양, 단면 종류 학급 갤러리 |

### P1 — 고등학교 공통·일반 선택을 채우는 5개

| 프로젝트 | 핵심 오개념·질문 | 주요 조작과 샌드박스 | 1시간 수업 산출물 |
|---|---|---|---|
| 좌표기하·자취·영역 설계실 | 식을 계산 대상으로만 보고 점의 조건과 도형의 자취로 읽지 못한다 | 점·직선·원·거리 조건 배치, 교점 추적, 부등식 영역 겹치기, 매개변수 조작 | 조건에서 방정식 만들기, 역으로 식에서 자취 예측, 경계 포함 오류 비교 |
| 지수·로그·스케일 실험실 | 지수적 변화와 선형 변화를 혼동하고 로그를 단순 계산 규칙으로 본다 | 복리 주기, 감쇠율, 반감기, 밑, 초기값 조작; 선형·로그 축 전환 | 감염·약물·소리·지진 규모 시나리오의 모델 선택과 잔차 비교 |
| 삼각함수·주기 현상 합성실 | 단위원, 그래프, 실제 주기 운동을 서로 다른 내용으로 본다 | 회전점, 진폭·주기·위상·중심선, 여러 파동 합성·분해 | 조수·관람차·음파 데이터 맞추기, 위상 추정 오차 분포 |
| 수열·재귀·프랙탈 실험실 | 일반항과 점화식을 별개로 외우고 장기 거동을 직관적으로 오판한다 | 초깃값·재귀 규칙 편집, 항 직접 연결, 가지치기·치환 규칙 제작 | 증가·수렴·진동·발산 분류, 임계값 도달 시간 학급 통계 |
| 벡터·행렬 변환 공작소 | 좌표 성분과 실제 이동, 행렬 계산과 공간 변환의 의미가 분리된다 | 벡터 화살표 합성, 기저 벡터 변경, 행렬 블록 연결, 회전·반사·전단·확대 순서 변경 | 같은 최종 변환의 여러 조합, 비가환 반례, 역변환 설계 |

### P2 — 고등학교 심화 탐구를 완성하는 2개

| 프로젝트 | 핵심 오개념·질문 | 주요 조작과 샌드박스 | 1시간 수업 산출물 |
|---|---|---|---|
| 미분·접선·최적화 실험실 | 평균변화율과 순간변화율, 도함수 0과 최댓값을 기계적으로 동일시한다 | 곡선 제어점, 할선 간격, 접선, 제약 조건, 목적함수 편집 | 포장·교통·수익 최적화, 끝점·미분 불가능점 반례, 해법 비교 |
| 적분·누적량·근사 실험실 | 넓이 공식과 변화량 누적의 관계, 부호 있는 넓이를 혼동한다 | 구간 분할, 좌·우·중점 합, 속도·유량 데이터 편집, 기준선 이동 | 분할 수에 따른 오차 수렴, 이동거리와 변위 비교, 근사법 성능 통계 |

## 3. 권장 개발 순서

1. `방정식·부등식 균형` — 학년 간 활용 폭이 가장 넓고 오개념 교정 효과가 직접적이다.
2. `작도·합동·닮음` — 자유 제작 샌드박스의 상품 차별성이 가장 크다.
3. `공간도형·전개도·단면` — 종이 교구로 하기 어려운 반복 절단·복원이 강점이다.
4. `대수 타일·인수분해` — 조작과 기호를 연결해 중3·고1 전환 수업에 적합하다.
5. `피타고라스·삼각비 측량` — 실제 장소·사진·거리 측정 미션으로 흥미를 만들기 쉽다.
6. `수체계·근삿값` — 기초 보정과 진단평가용으로 묶는다.
7. 이후 P1 다섯 개를 고등학교 패키지로 개발한다.
8. 미분과 적분은 공통 그래프·수치근사 엔진을 완성한 뒤 연속 개발한다.

## 4. 모든 신규 수학 실험실에 공통 적용할 기능

- `구성 → 추측 → 실행 → 반례 찾기 → 설명` 흐름
- 정답 모드와 별도로 제한 없는 자유 제작 샌드박스
- 식, 표, 그래프, 기하 장면 중 최소 세 표현의 동시 연결
- 교사가 변수·도구·허용 오차·제출 횟수를 잠그는 수업 설정
- 학생별 비식별 좌석과 학급 해법 분포, 오차, 단계 수, 성공률 비교
- 결과뿐 아니라 조작 순서를 저장해 풀이 전략을 비교하는 시행 기록
- 틀린 구성도 삭제하지 않고 실패 원인과 위반 조건을 표시
- 모델의 가정, 수치 근사의 한계, 측정 오차를 별도 설명

## 5. 상품 구성 제안

- `중등 수학 핵심 팩`: 기존 함수·확률 + P0 여섯 개 = 8개 실험실
- `고등 수학 모델링 팩`: 함수·확률 + P1 다섯 개 + P2 두 개 = 9개 실험실
- `전 과정 통합 팩`: 중복을 제거한 총 15개 수학 실험실
- 학교에는 학년별 50분 수업안, 학생 활동지, 교사용 예상 오개념·질문 카드, 학급 결과 CSV를 함께 제공한다.

신규 항목은 구현 전 제안 단계이며, 현재 공개 카탈로그의 `완료` 프로젝트 수에는 포함하지 않는다.
