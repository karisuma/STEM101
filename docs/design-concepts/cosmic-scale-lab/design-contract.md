# 우주 규모·비유 검증 실험실 디자인 계약

## 승인 기록

- 승인 시점: 2026-08-13
- 승인 근거: 데스크톱·모바일 세로·모바일 가로 개념을 제시한 뒤 사용자가 `구현진행해줘`라고 요청함.
- 구현 표면: `projects/middle/science/우주규모비교실험실/`
- 테마 색: `#0B1020`(바탕·넓은 면), `#FF6B5E`(조작·핵심 변화)

## 수용된 화면 개념

- `desktop-approved.png`: 넓은 상단 관찰장, 오른쪽 조작 열, 하단 규모 레일과 고정 미니맵
- `mobile-portrait-approved.png`: 장면 우선, 아래로 이어지는 조작·설명 흐름
- `mobile-landscape-approved.png`: 장면을 최대화하고 오른쪽에 압축된 조작 열

세 이미지는 구조·밀도·색의 기준이며 런타임에 직접 삽입하는 자산이 아니다. 텍스트와 천체 표시는 실제 HTML/Canvas/SVG로 구현한다.

## 잠긴 요소

1. 장면이 첫 화면에서 가장 넓은 면을 차지한다.
2. 오른쪽 조작 열은 `미션 → 축척 → 보기 렌즈 → 선택 측정 → 예측` 순서를 지킨다.
3. 실제 모형 크기와 보기 위한 확대 원은 실선/점선 및 설명으로 항상 구분한다.
4. 포인터 기준 확대, 드래그 이동, 전체 범위 미니맵, 선택 천체 맞춤을 제공한다.
5. 라벨은 대상에서 떨어져 배치하고 리더선과 충돌 회피를 적용한다.
6. `#0B1020`과 `#FF6B5E` 외의 프로젝트 고유 강조색을 추가하지 않는다.
7. 장식적 카드, 배지, 그라데이션, 과도한 둥근 모서리를 사용하지 않는다.
8. 학생 모드와 선생님 모드, 비식별 좌석, 학급 산점도에서 내 결과 강조를 유지한다.

## 유연한 요소

- 캔버스 눈금 간격과 라벨 수는 현재 확대 배율과 화면 폭에 따라 달라질 수 있다.
- 모바일 세로 화면에서 조작부는 고정 바텀시트 대신 자연스러운 문서 흐름으로 배치할 수 있다. 스크롤 트랩 방지가 우선이다.
- 천체는 실제 축척 원이 1픽셀보다 작을 수 있으므로 위치 십자선과 선택 가능한 DOM 라벨을 별도로 제공한다.
- 빛 이동은 수업 관찰을 위해 압축 재생하되 실제 시간 수치를 함께 표시한다. 동작 줄이기 설정에서는 즉시 완료한다.

## 의미 보존 규칙

- 데이터 좌표의 거리와 지름은 언제나 같은 축척 `S`를 사용한다.
- 보기 렌즈는 Canvas 원의 표시 반지름만 바꾸며 계산값·좌표·미니맵 위치를 바꾸지 않는다.
- 로그 관점은 위치만 `log10`으로 변환하고 그 사실을 HUD와 눈금에 명시한다.
- 행성 거리는 ‘평균’ 대신 ‘대표 거리(궤도 장반경)’로 부른다.
- 달의 거리 부모는 태양이 아니라 지구다.
- 프록시마 지름은 추정값으로 표시한다.
- 반올림은 화면 표시 단계에서만 수행한다.

## 기술 계약

- 정적 ES Modules, 외부 프레임워크·CDN 없음
- 주 장면: DPR 상한이 있는 단일 Canvas
- 라벨·조작·표: DOM
- 미니맵·학급 산점도: SVG
- 공유 가능한 URL 상태: 관점, 미션, 기준, 모형 값, 선택 천체, 렌즈, 비식별 수업·좌석, 설명 깊이
- 기존 교실 API: `Authorization: Seat`, `/api/classroom/session`, `/api/classroom/trials`
- 키보드: 화살표 이동, `+/-` 확대, `Home` 맞춤
- 테스트 기준: 데이터 불변식, 카탈로그/정적 경로, 데스크톱 1440×900, 모바일 390×844, 가로 844×390, 콘솔 오류 없음, 주요 상호작용 상태 변화
