# STEM101 판매용 디지털 실험 교구 운영 가이드

## 수업의 정체성

STEM101은 중·고등학생이 전문적인 과학·수학 원리를 관찰·조작·측정·비교로 익히는 완성형 디지털 실험 교구입니다. 학생에게 코드를 만들게 하는 수업이 아니라, 검증 가능한 질문을 세우고 시뮬레이션에서 증거를 수집하게 하는 수업입니다.

```text
질문·예측 → 변수 통제 → 실행·측정 → A/B·학급 비교 → 원리 설명 → 모형 한계
```

## 수업에서 학생이 만드는 증거

- 현상에서 출발한 탐구 질문
- 결과를 예상할 수 있는 간단한 가설
- 변수를 직접 조절하는 인터랙티브 시뮬레이터
- 예상과 실제 결과를 비교하는 테스트
- 실패와 수정 과정의 기록
- 발견한 원리에 대한 학생의 설명

## 역할

### 학생

- 궁금한 점을 질문으로 바꿉니다.
- 어떤 값을 바꿀 수 있어야 하는지 제안합니다.
- 한 번에 하나의 원인을 분리해 조건 A와 B를 설계합니다.
- 실행 결과가 예상과 같은지 수치·그래프로 검증합니다.
- 결과, 근거와 모형 한계를 자신의 말로 설명합니다.

### 선생님

- 결과를 먼저 알려주기보다 예측을 먼저 기록하게 합니다.
- 질문을 테스트 가능한 형태로 다듬도록 돕습니다.
- 과학적·수학적으로 잘못된 가정을 확인합니다.
- 통제 변수, 반복 수, 비교 축과 학급 표본 공개 시점을 설정합니다.
- 결과값뿐 아니라 학생의 예측·근거·이상점 설명을 관찰합니다.

## 설명 깊이

| 단계 | 학생에게 열리는 내용 |
| --- | --- |
| 중등 직관 | 한 핵심 변수와 장면의 즉시 변화, 쉬운 현상 언어 |
| 중등 정량 | 단위가 있는 판독값, 표·그래프와 비례 관계 |
| 고등 기본 | 관계식, 벡터·로그·에너지·확률 등 교과 모형 |
| 고등 심화 | 유도, 가정 비교, 잔차·표본오차와 모형 한계 |

## 프로젝트 필수 요소

각 프로젝트에는 다음 항목이 있어야 합니다.

- `index.html`: 실행 가능한 시뮬레이터
- `project.json`: 학년, 과목, 질문, 제작 단계, 두 테마 색상, 테스트 기준
- `README.md`: 교과 연결, 오개념, 조작 변수, 수업 흐름, 원리와 모형의 한계
- 사용자가 바꿀 수 있는 변수와 즉시 확인 가능한 결과
- 최소 한 가지 예상 결과와 이를 확인하는 테스트
- 프로젝트 목록으로 돌아가는 링크
- 키보드와 모바일 화면 대응

상세 화면을 새로 만들 때는 [시뮬레이션 디자인 시스템](simulation-design-system.md)과 `templates/simulation-page/`의 골격을 사용합니다.

## 좋은 테스트 질문

- 이 값을 두 배로 바꾸면 무엇이 달라져야 하나요?
- 두 조건이 같을 때와 반대일 때 결과는 어떻게 달라야 하나요?
- 코드가 보여주는 결과가 실제 원리와 일치하나요?
- 예상과 다른 결과가 나온 이유는 계산, 표현, 가정 중 무엇인가요?
- 이 시뮬레이터가 설명하지 못하는 실제 현상은 무엇인가요?

## 보호자가 볼 수 있는 가치

완성 화면의 화려함보다 학생이 어떤 질문을 했고, 무엇을 테스트했으며, 실패 후 어떤 판단으로 수정했는지를 봅니다. 결과물을 설명하는 과정에서 개념 이해와 문제 해결 방식이 함께 드러납니다.
