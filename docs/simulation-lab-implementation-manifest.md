# STEM101 실험실 구현 명세·인수 목록

## 공통 구현

모든 신규 실험실은 `shared/lab-runtime.js`와 `shared/lab-runtime.css`를 사용하고 각 주제 폴더에 `index.html`, `lab.js`, `project.json`, `README.md`를 둔다.

- 학생/선생님 모드, M1·M2·H1·H2 설명 깊이
- 질문·미션, 예측, 재생·시간 탐색, 변수 조작·교사 잠금
- 실시간 판독값, 정량 관계 그래프, A/B 시행 저장과 차이 요약
- 비식별 좌석별 제출, 학급 표본 산점도·평균·중앙값·표준편차, 내 결과 강조, CSV
- 원리 설명 사다리와 모형 경계
- 모바일 단일 열 재배치와 키보드 조작
- 정적 로컬 학급 데모와 선택적 원격 학급 API 동기화

## 학급·라이선스 구현

- 관리 콘솔: `classroom/`
- API·SQLite 스키마: `server/classroom-server.mjs`
- 시스템 관리자: 감독자 코드, 초기 암호, 좌석 한도, 만료일 발급·활성화
- 감독자: 한도 안의 수업·좌석 생성, 좌석 토큰 재발급, 수업 설정과 전체 표본 조회
- 학생: 좌석 별칭·임의 토큰만 사용, 같은 수업의 익명 표본 조회
- 금지 필드: 이름, 이메일, 전화번호, 생년월일, 주소, 사진·자기소개

## 인수 검사

```text
node scripts/validate-catalog.mjs
node scripts/validate-lab-models.mjs
node --no-warnings scripts/test-classroom-server.mjs
```

추가 브라우저 인수 기준은 데스크톱 16개 실험실 렌더링, 8개 샌드박스 팔레트·판정, 교사 좌석 생성·학급 통계, 모바일 390×844 화면, 조석·포물선 기존 공개 빌드와 카탈로그 필터다.
