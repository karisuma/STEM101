# STEM101 조작·수업·학급 통계·계정 체계 상세 사양

## 0. 문서 목적

이 문서는 `commercial-simulation-labs-plan.md`의 주제 기획을 실제 판매용 수업 제품으로 구체화한다. 조석을 포함한 17개 실험실마다 학생이 조작할 수 있는 요소, 60분 수업 흐름, 반복·변형 실험, 학급 통계, 창의 미션을 정의하고, 시스템 관리자–감독자–학급–학생의 계정·권한·좌석 구조를 명세한다.

제품의 목표는 많은 슬라이더를 제공하는 것이 아니다. 학생이 다음 질문을 계속 만들 수 있게 하는 것이다.

> 무엇을 바꾸면, 무엇이 달라지며, 그 관계는 항상 성립하는가? 나와 같은 조건을 실험한 학급의 결과는 왜 같거나 다른가?

## 1. 조작 시스템의 공통 설계

### 1.1 조작을 다섯 종류로 구분한다

모든 실험실은 변수 목록을 한 화면에 늘어놓지 않고 조작을 다음 다섯 종류로 구분한다.

| 조작 종류 | 의미 | UI 예시 | 기록 방식 |
| --- | --- | --- | --- |
| 원인 변수 | 학생이 가설을 세우고 의도적으로 바꾸는 값 | 슬라이더, 수치 입력, 드래그 | 변경 전후 값과 단위 |
| 통제 변수 | 비교를 위해 고정해야 하는 조건 | 자물쇠, 허용 범위 | 잠금 여부와 고정값 |
| 구조 조작 | 대상의 연결·배치·관계를 바꾸는 행위 | 끌어놓기, 연결, 회전, 경계 이동 | 구조 그래프 또는 배치 상태 |
| 사건 조작 | 특정 순간에 변화를 가하는 행위 | 발사, 혼합, 충격, 가열, 교란 | 시각과 사건 종류·크기 |
| 관측 조작 | 현상은 바꾸지 않고 보는 방법을 바꾸는 행위 | 관점, 축, 레이어, 배율, 센서 위치 | 분석 화면 상태로 별도 저장 |

관측 조작은 원인 변수와 구분한다. 카메라를 움직이거나 축 범위를 바꿔도 실험 조건이 바뀐 것으로 기록하지 않는다.

### 1.2 변수 공개 수준

| 수준 | 공개 범위 | 한 화면의 권장 조작 수 | 용도 |
| --- | --- | --- | --- |
| 입문 조작판 | 핵심 원인 1~3개, 재생, 초기화 | 3~6개 | 첫 10분, 교사 시연 |
| 탐구 조작판 | 통제 변수와 센서 포함 | 6~10개 | A/B 비교, 모둠 실험 |
| 연구 조작판 | 모델 선택, 환경·오차·경계 조건 | 10개 이상을 접힌 그룹으로 제공 | 고등 심화, 자유 탐구 |

교사는 학생별로 수준을 지정하는 대신 미션별로 공개 수준을 정한다. 같은 학생도 첫 미션에서는 입문판, 마지막 미션에서는 연구판을 사용할 수 있다.

### 1.3 조작 안전장치

- 슬라이더 옆에 현재값, 단위, 정상 수업 범위, 전체 모델 범위를 구분한다.
- 직접 수치 입력은 허용하되 모델 범위를 넘으면 가장 가까운 값으로 몰래 바꾸지 않고 이유를 설명한다.
- 한 변수 실험에서는 선택 변수 외의 조건이 실제로 잠긴다.
- `자유 실험`에서는 모든 변수를 열되 마지막 유효 상태와 전체 초기화를 분리한다.
- 결과가 극단값 때문에 보이지 않으면 자동 축을 쓸 수 있지만, 축이 바뀌었다는 표시를 고정한다.
- 학습용 과장, 실제 비율, 이상 모형, 현실 모형을 서로 다른 상태로 저장한다.
- 실행마다 모델 버전과 난수 시드를 기록하여 같은 조건을 재현할 수 있게 한다.

#### 1.3.1 자유 제작 샌드박스 상호작용

조립 가능한 실험은 다음 상태를 공통으로 사용한다.

1. 팔레트에서 부품을 추가한다.
2. 장면에서 드래그해 배치하고 필요하면 회전한다.
3. `연결` 모드에서 시작 부품과 도착 부품을 순서대로 선택한다.
4. 구성 검사기가 닫힌 경로, 필수 부품, 방향, 고립 요소, 부모 수 같은 주제별 규칙을 판정한다.
5. 작동하지 않는 구성도 유지하며 오류를 `열린 경로`, `필수 부품 없음`, `규칙 모순`, `측정 범위 밖`처럼 원리 언어로 설명한다.
6. 구성과 계산 결과를 A/B로 저장하고 학급에 제출한다.

현재 구현의 주제별 자유도는 다음과 같다.

| 주제 | 자유 부품/구성 | 계산에 반영되는 구조 |
|---|---|---|
| 일·에너지 | 고정점, 도르래, 화물, 손잡이, 줄 연결 | 지지 경로 수, 필요한 힘, 당김 거리 |
| 전기회로 | 전원, 저항, 전구, 스위치, 접속점 | 닫힌 경로, 직렬/병렬 경향, 합성저항, 전류·전력 |
| 빛·파동 | 광원, 볼록/오목렌즈, 거울, 스크린 | 광학축 거리, 상 위치, 스크린 초점 오차 |
| 원자 | 양성자, 중성자, 전자 | 원소, 질량수, 전하, 전자 수 |
| 화학반응 | N₂, H₂, 촉매 | 반응비, 제한 반응물, 최대 생성량, 속도 |
| 생태계 | 생산자, 소비자, 포식자, 분해자 | 에너지 방향, 고립 종, 연결 경로와 복원성 질문 |
| 유전 | AA, Aa, aa 개체와 부모→자손 링크 | 가능한 자손 유전자형, 가계 모순 수 |
| 함수 | 입력, 제곱, sin, 절댓값, 확대, 이동, 출력 | 연산 순서, 합성식, 그래프와 함숫값 |

교사가 배포하는 수업에는 `초기 구성`, `허용 부품`, `부품별 상한`, `연결 가능 규칙`, `성공 조건`을 저장한다. 학생 계정에는 실명 대신 기존과 같은 좌석 별칭만 연결되며 자유 구성 안에도 개인정보를 적는 텍스트 필드를 두지 않는다.

### 1.4 실행 한 건의 공통 데이터

```text
tenant_id / class_id / session_id / mission_id / seat_account_id
topic_id / model_version / run_id / started_at / ended_at
prediction / manipulated_variables / locked_variables / structure_state
event_log / result_metrics / observation_settings / random_seed
student_claim / evidence_refs / limitation_choice / teacher_feedback
```

학급 통계에는 관측 화면 상태를 원인 변수처럼 사용하지 않는다. 동일 미션, 동일 모델 버전, 동일 단위, 동일 고정 조건을 만족하는 실행만 기본 비교 집단으로 묶는다.

### 1.5 전문 콘텐츠의 공통 설명 순서

모든 주제는 조작법보다 원리를 먼저 가르치되 긴 교과서식 글로 시작하지 않는다. 하나의 개념을 다음 일곱 단계로 연다.

1. **현상:** 실제로 관찰할 수 있는 장면과 `왜 이렇게 될까?`라는 질문을 제시한다.
2. **원인 대상:** 현상에 참여하는 물체·입자·장·에너지·확률 요소를 짚는다.
3. **인과 모형:** 어떤 원인이 어떤 중간 과정을 거쳐 결과를 바꾸는지 화살표와 짧은 문장으로 설명한다.
4. **변수 정의:** 조작 변수, 통제 변수, 결과 변수의 물리적·수학적 뜻과 단위를 밝힌다.
5. **측정 관계:** 표와 그래프로 관계의 방향, 비례성, 임계점, 시간 지연을 찾는다.
6. **정량 모형:** 식의 각 항을 화면의 대상·벡터·수치와 직접 연결하고 계산 결과를 시뮬레이션과 대조한다.
7. **적용과 한계:** 실제 사례, 반례, 생략한 조건, 모형이 실패하는 범위를 실험한다.

설명은 현상 가까이에 짧게 두고, `왜?`, `식으로 보기`, `실제에서는?`, `모형의 한계`를 학생이 필요할 때 단계적으로 연다. 쉬운 설명을 위해 과학적으로 틀린 비유를 사용하지 않는다.

### 1.6 중학교–고등학교 깊이 사다리

중학교용과 고등학교용을 서로 다른 단순·복잡 앱으로 만들지 않는다. 같은 계산 엔진과 같은 장면을 사용하고 설명·변수·수학 수준을 단계적으로 연다.

| 단계 | 권장 대상 | 학생이 해야 하는 사고 | 열리는 표현 |
| --- | --- | --- | --- |
| M1 현상 이해 | 중학교 입문 | 방향·순서·증가/감소를 말한다 | 장면, 상태 언어, 핵심 변수 1개 |
| M2 관계 탐구 | 중학교 표준 | 한 변수를 통제하고 표·그래프에서 규칙을 찾는다 | 단위 수치, A/B, 비례·상관, 오차 범위 |
| H1 정량 모델 | 고등학교 표준 | 식으로 결과를 예측하고 실험값과 비교한다 | 벡터·성분, 함수, 보존식, 잔차 |
| H2 연구 확장 | 고등학교 심화 | 모형을 바꾸고 가정·불확실성·적용 범위를 비판한다 | 수치모형, 분포, 민감도, 이상/현실 비교 |

- M1에서도 정확한 과학 용어를 사용하되 처음 등장할 때 일상 언어와 연결한다.
- M2에서는 그래프를 결과 장식으로 제시하지 않고 학생이 직접 표본을 모아 완성하게 한다.
- H1에서는 공식을 암기 문구로 띄우지 않고 변수 변화, 단위, 그래프 기울기·넓이와 연결한다.
- H2에서는 변수를 많이 여는 것으로 심화를 대신하지 않고 모형 선택과 근거·한계 판단을 요구한다.
- 교사는 학년이 아니라 수업 목표에 따라 시작 단계를 선택하고, 수업 중 다음 단계를 공개할 수 있다.

### 1.7 원리 설명 패널의 필수 구성

각 핵심 개념에는 다음 패널을 하나의 연결된 묶음으로 제공한다.

| 패널 | 필수 내용 |
| --- | --- |
| 한 문장 원리 | 원인–과정–결과를 정확한 한 문장으로 설명 |
| 대상과 방향 | 힘·속도·에너지·입자·빛·정보 흐름의 대상과 방향 표시 |
| 변수 사전 | 기호, 이름, 뜻, 단위, 정상 범위, 현재값 |
| 식 해부 | 항 하나를 가리키면 장면의 대응 대상과 그래프가 함께 강조됨 |
| 단위 검산 | 입력·출력 단위와 차원 일치 확인 |
| 대표 예제 | 현재 조건으로 한 단계 계산하고 시뮬레이션 값과 대조 |
| 흔한 오해 | 그럴듯한 오답, 실패하는 반례, 수정 설명 |
| 실제 적용 | 기술·자연·생활 사례와 사용되는 판단 |
| 모형 한계 | 이상화, 제외 변수, 유효 범위, 실제 측정과의 차이 |

학생이 식을 열지 않아도 현상과 관계를 이해할 수 있어야 하지만, 식을 열었을 때는 화면의 현상과 분리된 별도 강의가 되어서는 안 된다.

### 1.8 주제별 실험 포트폴리오 최소 기준

주제마다 버튼만 바꾼 유사 실험이 아니라 서로 다른 사고를 요구하는 최소 10개의 수업 실험을 갖춘다.

- 원리를 직접 확인하는 **기초 인과 실험 2개 이상**
- 한 변수 관계를 수집하는 **정량 실험 2개 이상**
- 둘 이상의 원인이 경쟁하는 **복합 조건 실험 1개 이상**
- 이상 모형과 현실 모형을 비교하는 **모형 비교 실험 1개 이상**
- 흔한 주장을 무너뜨리는 **반례 실험 1개 이상**
- 제한 조건 안에서 해를 찾는 **설계·최적화 실험 1개 이상**
- 반복 시행이나 모둠 분담이 필요한 **학급 통계 실험 1개 이상**
- 새 상황으로 원리를 옮기는 **전이·응용 실험 1개 이상**

각 실험에는 질문, 선수 개념, 예상 시간, 공개 변수, 잠금 변수, 반복 횟수, 수집 지표, 예상 그래프, 대표 오개념, 후속 질문, 적용 한계를 기록한다.

### 1.9 과학·수학 전문성 기준

- 모든 수치에는 단위와 정의 기준을 표시하고 단위 변환을 자동 검증한다.
- 해석해가 있는 모형은 기준 사례에서 시뮬레이션 값과 대조한다.
- 근삿값, 경험식, 교육용 과장, 임의 매개변수를 실제 상수처럼 제시하지 않는다.
- 그래프에는 축 이름·단위·표본 수·조건·모델 버전을 포함한다.
- 무작위 모형은 한 번의 결과와 분포의 성질을 구분하고 시드 재현을 지원한다.
- 정밀도보다 많은 자릿수를 보여 주지 않고 불확실성·반올림·센서 오차의 출처를 설명한다.
- 상관관계, 인과관계, 계산 모형의 가정을 서로 구분한다.
- 과목 전문가가 식·용어·상수·경계값을, 현장 교사가 설명 난이도와 수업 흐름을 각각 검수한다.
- 중학생의 쉬운 이해와 고등학생의 정량 깊이를 모두 충족하지 못하면 같은 화면에서 단계가 자연스럽게 이어질 때까지 출시하지 않는다.

| 시간 | 단계 | 학생 활동 | 교사 기능 | 남는 데이터 |
| --- | --- | --- | --- | --- |
| 0~5분 | 현상·질문 | 장면을 보고 결과를 예측한다 | 결과·그래프 가리기, 예측 집계 | 최초 예측과 확신도 |
| 5~12분 | 조작 익히기 | 핵심 변수 하나를 바꾸고 센서를 읽는다 | 입문 조작판, 안내 화살표 | 연습 실행 1~2건 |
| 12~27분 | 통제 실험 | A/B 조건을 설계하고 반복한다 | 변수 잠금, 오류 확인 | 비교 가능한 실행 4~8건 |
| 27~40분 | 변형·응용 | 모둠별 다른 조건 또는 설계 미션을 푼다 | 미션 분기, 조건 카드 배포 | 다양한 표본과 설계안 |
| 40~50분 | 학급 통계 | 내 결과를 분포에서 찾고 차이를 해석한다 | 익명 집계 공개, 표본 필터 | 학급 분포·회귀·범주표 |
| 50~57분 | 주장·반박 | 증거를 들어 설명하고 다른 모둠의 반례를 검토한다 | 대표 결과 핀 고정 | 주장–증거–한계 문장 |
| 57~60분 | 출구 문항 | 새 조건에 결과를 전이 예측한다 | 동형·변형 문항 공개 | 개념 변화와 잔여 오개념 |

한 시간 내내 자유 조작만 시키지 않는다. `한 변수 통제 실험`으로 비교 기준을 만들고, 그 뒤 자유 설계와 학급 표본으로 확장한다.

### 2.2 수업 유형 네 가지

1. **법칙 발견형:** 여러 조가 서로 다른 입력 구간을 맡아 학급 전체가 하나의 그래프를 완성한다.
2. **모형 비교형:** 이상/현실, 입자/거시, 우주/관측자 같은 두 모형이 같은 결과와 다른 결과를 내는 조건을 찾는다.
3. **설계 최적화형:** 목표값, 비용, 안전, 오차 제한을 동시에 만족하는 해를 찾고 해가 하나가 아님을 비교한다.
4. **오개념 반례형:** 흔한 주장 하나를 선택하고 그 주장이 실패하는 최소 반례를 설계한다.

### 2.3 실험을 오래 흥미롭게 만드는 장치

- 미션은 `정답 한 개 찾기`보다 `서로 다른 해 2개 찾기`, `실패하는 경계 찾기`, `가장 단순한 반례 만들기`를 우선한다.
- 목표값만 주지 않고 재료 수, 허용 오차, 에너지, 시간 같은 제약을 함께 준다.
- 같은 미션에 초급 목표, 표준 목표, 연구자 보너스를 둔다.
- 결과가 좋은 실행뿐 아니라 예측과 다르게 나온 실행, 재현되지 않은 실행, 학급의 극단값을 토론 후보로 올린다.
- 속도·점수 순위표 대신 `가장 잘 통제된 실험`, `흥미로운 반례`, `재현에 성공한 결과`, `좋은 한계 설명`을 교사가 선택한다.

## 3. 개인·학급 통계 설계

### 3.1 학생 화면의 `학급 속 나`

학생은 학급 집계가 공개되면 다음을 볼 수 있다.

- 히스토그램·상자그림·산점도 위의 `내 실행` 강조점
- 같은 조건을 사용한 학급 표본 수와 내 결과의 중앙값 차이
- 내 A/B 변화량과 학급 A/B 변화량 분포
- 나와 결과가 가장 비슷한 익명 표본 2개와 가장 다른 익명 표본 2개
- 다른 결과가 `다른 조건`, `무작위 변동`, `측정·판독 차이`, `모델 버전` 중 무엇 때문인지 확인하는 필터

학생 자신의 점은 본인 화면에서만 강조한다. 다른 학생의 이름이나 공개 순위는 보여주지 않고 `표본 12`, `모둠 C`처럼 표시한다.

### 3.2 교사 통계 화면

| 보기 | 답하는 질문 | 주요 차트 |
| --- | --- | --- |
| 예측 분포 | 수업 전 어떤 생각이 우세한가? | 선택 비율, 확신도 분포 |
| 실행 진행 | 누가 실행하지 못했거나 통제 변수를 바꿨는가? | 상태 매트릭스, 조건 이탈 경고 |
| 결과 분포 | 같은 조건에서 결과가 얼마나 퍼졌는가? | 히스토그램, 상자그림, 점그림 |
| 관계 탐색 | 입력과 출력의 관계가 어떤 모양인가? | 산점도, 추세선, 잔차 |
| A/B 효과 | 조건 변화가 같은 학생·모둠에서 어떤 차이를 냈는가? | 대응점, 변화량 분포 |
| 설명 유형 | 결과를 어떤 원리로 설명했는가? | 교사 태그 범주표, 대표 문장 |
| 개념 변화 | 예측과 출구 문항 사이에 무엇이 바뀌었는가? | 전이표, 오개념 이동 흐름 |

교사는 전체 좌석 ID별 표본을 볼 수 있지만, 수업 공개 화면으로 전환할 때는 자동으로 수업용 ID·집계 상태가 된다.

### 3.3 통계적 정직성 규칙

- 비교 가능한 표본이 5개 미만이면 개인점은 보이되 학급 분포·백분위 표현은 열지 않는다.
- 다른 모델, 단위, 고정 조건의 실행을 하나의 추세선에 자동으로 합치지 않는다.
- 반복 실행이 많은 학생 한 명이 학급 결과를 과도하게 지배하지 않도록 `학생별 대표 실행`과 `모든 실행`을 구분한다.
- 교사가 사후에 실행을 제외하면 제외 이유와 표본 수 변화를 기록한다.
- 추세선은 표본 수, 적합 모형, 결정계수 또는 잔차와 함께 표시하고 인과관계로 자동 해석하지 않는다.
- 모의실험의 계산 오차와 학생 측정 오차를 구분한다. 결정론적 모형에서 같은 입력의 다른 출력이 생겼다면 난수·판독·모델 설정을 먼저 확인한다.
- `내 위치`는 성취 등수나 성적이 아니다. 중앙값보다 멀다는 이유로 틀렸다고 표시하지 않는다.

### 3.4 학급 공동 데이터 만들기

교사는 변수를 구간별로 분담할 수 있다. 예를 들어 발사각 10~30°는 1모둠, 35~55°는 2모둠이 맡는다. 시스템은 다음을 자동 처리한다.

1. 중복·빈 구간을 보여 준다.
2. 모둠별 최소 반복 횟수를 확인한다.
3. 수집 중에는 다른 모둠 결과를 가릴 수 있다.
4. 공개 후 전체 학급 데이터셋을 하나의 그래프로 합친다.
5. 이상점을 삭제하지 않고 재실험 요청 또는 이유 주석을 붙인다.
6. CSV에는 원자료, 대표 실행, 제외 사유, 모델 버전을 별도 열로 내보낸다.

## 4. 교사 모드와 학생 모드

### 4.1 감독자·교사 모드

교사 모드는 네 단계로 나눈다.

#### 수업 만들기

- 학년, 과목, 주제, 10/25/50/60분 수업안을 선택한다.
- 미션을 순서대로 배치하고 단계별 공개 시각을 정한다.
- 변수별로 숨김, 표시, 잠금, 허용 범위, 초기값을 설정한다.
- 모둠별 다른 조건 카드와 공통 결과 지표를 배정한다.
- 학생이 볼 학급 통계 종류와 공개 최소 표본 수를 정한다.
- 출구 문항, 제출 형식, 데이터 보존 기간을 지정한다.

#### 수업 진행

- 예측 접수, 실행 시작, 일시정지, 다음 단계 공개를 한 화면에서 제어한다.
- `실험 화면 잠시 고정`은 입력만 막고 작성 중 기록은 보존한다.
- 변수 잠금 위반, 미실행, 단위 오류, 과도한 무작위 반복을 확인한다.
- 특정 학생 화면을 몰래 조작하지 않고 `힌트 보내기` 또는 `기준 상태 복구 요청`을 보낸다.
- 대표 실행을 최대 4개 핀으로 고정해 학급 토론 화면에 올린다.

#### 결과 검토

- 학생·모둠별 예측, 대표 실행, 설명, 수정 설명을 한 흐름으로 본다.
- 교사는 오개념·증거 사용·통제 수준·한계 인식 태그를 붙인다.
- 점수는 자동 계산보다 루브릭 제안을 우선하며 교사가 확정한다.
- 원자료·집계·학생 보고서를 CSV/PDF로 내보낼 수 있다.

#### 템플릿 관리

- 자주 쓰는 수업을 학교 템플릿으로 저장한다.
- 공동 교사는 템플릿을 복제할 수 있으나 원본 변경 권한은 별도로 준다.
- 모델 버전이 바뀌면 이전 템플릿의 결과 호환 여부를 경고한다.

### 4.2 학생 모드

- 수업 코드 또는 교사 발급 계정으로 들어가 오늘의 질문부터 시작한다.
- 현재 단계에 필요한 조작만 먼저 보며, 교사가 열면 심화 조건이 나타난다.
- 실행 전에 예측을 제출하되 실행 후에도 최초 예측은 지워지지 않는다.
- 실행을 `연습`, `증거 A`, `증거 B`, `내 대표 결과`로 분류한다.
- 자기 실행은 무제한 탐색할 수 있지만 제출용 대표 실행 수는 교사가 정한다.
- 학급 통계에서는 자기 점을 보고 다른 결과의 조건을 익명으로 비교한다.
- 설명은 `바꾼 것 → 달라진 것 → 이유 → 성립 조건` 문장 틀과 자유 서술 중 선택한다.
- 재미 미션의 배지와 기록은 점수 순위가 아니라 탐색 방식과 증거 품질에 연결한다.

## 5. 계정·라이선스·권한 체계

### 5.1 계층 구조

```text
STEM101 시스템 관리자
└─ 기관 테넌트(학교·학원·교육청·교사 개인 라이선스)
   ├─ 주 감독자(구매·좌석·보존정책 관리자)
   ├─ 감독자/교사
   │  ├─ 학급
   │  │  ├─ 모둠
   │  │  └─ 비식별 학생 좌석 계정
   │  └─ 수업 템플릿·세션·과제
   └─ 공동 교사/열람자(선택)
```

시스템 관리자가 감독자 계정을 판매하고, 감독자는 구매한 학생 좌석 수 안에서 학급과 학생 계정을 자유롭게 만든다. 기관 데이터는 테넌트별로 논리적으로 분리한다.

### 5.2 라이선스 단위

| 항목 | 정의 | 권장 규칙 |
| --- | --- | --- |
| 감독자 좌석 | 수업을 만들고 학생 데이터를 보는 성인 계정 | 상품별 허용 수를 지정 |
| 활성 학생 좌석 | 로그인 가능한 학생 계정 한 개 | 기관 전체 활성 계정 합이 구매량을 넘지 않음 |
| 동시 수업 한도 | 동시에 열 수 있는 실시간 세션 수 | 서버 용량 상품과 연결 |
| 주제 권한 | 구매한 실험실·교안 범위 | 단품·묶음·전체 라이선스 |
| 보존 용량 | 원자료·보고서 저장량 | 보존 기간과 함께 표시 |

- 감독자가 학기형 좌석 계정을 활성화하면 구매 좌석을 사용한다.
- 세션형 좌석은 상품에 정한 동시 참여 한도 안에서만 생성한다.
- 더 이상 쓰지 않는 좌석은 `비활성`으로 바꾸고 기존 실험 기록을 읽기 전용으로 보존하거나 감독자가 비울 수 있다.
- 좌석 부족 시 기존 계정을 자동 삭제하지 않고 어떤 좌석을 비활성화할지 감독자가 결정한다.
- 시스템 관리자의 좌석 변경, 감독자의 학생 생성·삭제·내보내기는 감사 로그에 남긴다.

### 5.3 학생 계정 생성 방식

#### 학기형 좌석 계정

- 감독자가 `생성 수량`, `접두어`, `번호 자릿수`를 지정해 한 번에 만든다.
- 예: `학생01~학생30`, `1반-01~1반-30`, `과학A-01~과학A-24`.
- 계정에는 시스템 생성 로그인 ID와 접근 PIN만 있다.
- 이름, 이메일, 전화번호, 생년월일, 실제 학번, 보호자 정보, 학교 명단을 입력하는 필드와 가져오기 기능을 만들지 않는다.
- 교사가 현실의 학생과 좌석 ID를 어떻게 배정했는지는 STEM101에 입력하거나 업로드하지 않는다.
- 접근 PIN 분실 시 감독자가 해당 좌석 계정의 PIN을 재발급한다.
- 학기 동안 같은 좌석 ID로 개인 실험 이력을 이어서 볼 수 있다.

#### 세션형 좌석 계정

- 감독자가 수업을 열 때 `학생1~학생N` 계정을 즉시 생성한다.
- 학생은 수업 코드와 배정된 번호로 입장하며 별도의 회원 가입을 하지 않는다.
- 세션 종료 후 결과를 즉시 비우거나, 감독자가 정한 기간 동안 수업 결과로 보존할 수 있다.
- 장기 이력이 필요하지 않은 공개 수업·체험 수업·대회형 수업에 사용한다.

#### 배포 링크

```text
/org/{tenant-slug}/join/{class-code}
/org/{tenant-slug}/session/{session-code}
```

- 링크만 알면 무제한 가입되는 구조를 금지하고 만료, 허용 인원, 재사용 여부를 설정한다.
- 교사는 QR, 인쇄용 로그인 카드, 좌석 ID–PIN 목록으로 배포할 수 있다.
- 수업 코드는 짧게 쓰되 반복 시도 제한과 세션 만료를 적용한다.

### 5.5 비식별 수업 계정의 불변 원칙

- 학생 좌석 계정은 사람의 신원을 나타내는 회원 프로필이 아니라 수업 안의 실험 표본 주체다.
- 계정 레코드는 `seat_account_id`, 수업용 표시 ID, 학급, 접근 PIN 해시, 상태, 실험 결과만 가진다.
- STEM101은 실제 이름과 `학생07` 또는 `1반-03`의 대응표를 생성·저장·가져오기 하지 않는다.
- 학생 화면에는 프로필, 이메일 복구, 연락처, 생년월일, 주소, 자기소개, 사진 업로드 기능을 두지 않는다.
- 학년·반 정보가 필요하면 개인 계정이 아니라 학급 설정에 한 번만 기록한다.
- 실험 설명은 과학적 주장·근거·한계 입력란으로만 받으며 신원정보를 요구하는 질문은 만들지 않는다.
- 학생 계정을 다른 학생에게 재배정하면 이전 실행을 새 사용자 이력과 합치지 않는다. 기존 좌석 인스턴스를 종료하고 같은 표시 ID의 새 내부 인스턴스를 만든다.
- 데이터 내보내기에도 수업용 좌석 ID와 실험 결과만 포함하며 이름 열이나 명단 결합 기능을 제공하지 않는다.
- 공개 학급 화면에는 `학생12`, `표본12` 같은 수업용 ID 또는 완전 익명 점만 표시한다.
- 시스템 관리자는 학생의 실제 신원을 알 수 없고, 감독자에게도 신원 대응표 입력을 요구하지 않는다.

### 5.6 구현된 계정·동기화 구성

- `server/classroom-server.mjs`: 시스템 관리자, 감독자 라이선스, 좌석 한도, 수업, 좌석 토큰, 시행 표본과 수업 설정 API.
- `classroom/`: 시스템 관리자와 감독자가 브라우저에서 라이선스와 좌석 링크를 발급하는 관리 콘솔.
- `shared/lab-runtime.js`: 학생 링크의 API 주소·좌석 토큰을 읽어 같은 수업의 표본을 동기화하고 `학급 속 나`를 표시한다.
- `scripts/test-classroom-server.mjs`: 관리자 → 감독자 → 좌석 한도 → 학생 제출 → 학급 조회의 통합 검증.

암호는 scrypt, 세션과 좌석 토큰은 SHA-256 해시로 저장한다. 좌석 토큰 원문은 생성·재발급 응답에서만 제공한다. 학생 링크를 처음 연 뒤 토큰은 URL 기록에서 제거하고 해당 탭의 세션 저장소에만 보관한다. 정적 SITE만 열면 로컬 수업 데모로 동작하고, `api`와 `seatToken`이 있는 감독자 발급 링크에서는 서버 동기화 모드로 전환한다.

## 6. 주제별 조작·60분 수업·통계·창의 미션

각 주제의 조작 요소는 `입문 조작`, `탐구·연구 조작`, `구조·사건 조작`, `관측 조작` 순으로 제시한다. 교사는 한 차시에 모두 열지 않고 수업 목표에 맞는 조작만 공개한다.

### 6.1 조석 실험실

#### 조작 가능한 요소

- **입문:** 달 공전 위치, 태양–지구–달 각도, 시간 재생·정지·속도, 달 효과/태양 효과 켜기.
- **탐구:** 달까지 거리, 태양까지 거리, 달·태양 질량 배율, 지구 자전 속도, 관측 해안의 경도.
- **연구:** 평형조석/지연 반응 모형, 해저 마찰, 평균 수심, 해안 증폭계수, 분지 공명 주기, 궤도 경사.
- **구조·사건:** 관측소를 지구 표면에 배치, 달·태양을 프리셋 위치로 이동, 가상 행성의 질량·반지름 조합 만들기.
- **관측:** 지구 집중/천체 전체, 지구 중심/태양 중심, 조석력 벡터/등고선/수면 과장, 실제 비율, 시간 그래프.
- **핵심 출력:** 관측소별 수위 편차, 만·간조 시각, 조차, 달·태양 조석력 성분, 두 효과의 합성값, 위상 지연.

#### 60분 수업안

1. `0~5분` 달 가까운 쪽만 만조인지 예측하고 두 번째 만조 위치를 표시한다.
2. `5~15분` 태양을 끄고 달 위치만 바꾸며 조석력 벡터와 양쪽 융기를 관찰한다.
3. `15~28분` 모둠별 달 거리 구간을 맡아 조차를 3회 측정하고 거리–조차 공동 산점도를 만든다.
4. `28~40분` 태양을 켜고 삭·상현·망·하현 조건에서 대조와 소조를 비교한다.
5. `40~50분` 해안 증폭·지연 모형을 열어 같은 천체 조건인데 관측소 결과가 다른 이유를 분석한다.
6. `50~60분` `달이 반대편 바다도 끌어당기므로 만조다`라는 설명을 조석력 차이와 기준계로 수정한다.

#### 학급 통계

- 달 거리와 조차의 산점도, 로그축 또는 역세제곱 후보 모형의 잔차를 비교한다.
- 태양–달 각도별 조차 분포를 상자그림으로 묶는다.
- 같은 천체 조건에서 해안 증폭계수와 실제 관측 조차의 관계를 본다.
- 학생은 자기 관측소가 학급 관측소 분포에서 어디에 있는지 확인한다.

#### 재미·상상 미션

- **외계 해양 행성:** 하루에 두 번 큰 조석이 생기지만 해안 도시가 침수되지 않는 달·행성 조합을 설계한다.
- **항구 시간표:** 최대 조차가 아니라 원하는 시간대의 만조를 만드는 관측 경도와 위상을 찾는다.
- **최소 반례:** `보름달이면 언제나 하루 중 가장 높은 만조`라는 주장이 실패하는 조건을 만든다.
- **천문 사진가:** 우주 관점만 보고 6시간 뒤 관측소 수위의 방향을 예측한다.

### 6.2 운동 분석 실험실

#### 조작 가능한 요소

- **입문:** 초기 속력, 발사각, 발사 높이, 중력가속도, 발사·일시정지·한 단계.
- **탐구:** 물체 질량, 단면적, 항력계수, 공기밀도, 바람 크기·방향, 표적 위치·크기.
- **연구:** 항력 없음/선형/이차 모형, 시간 간격, 지면 경사, 회전·마그누스 효과 모듈, 측정 잡음.
- **구조·사건:** 발사기와 표적 드래그, 동일 조건 동시 발사, 비행 중 추진 사건 또는 낙하물 분리.
- **관측:** 궤적/수평·수직 성분/에너지/시간 그래프, 속도·가속도 벡터, 스트로보 간격, 실제·과장 벡터.
- **핵심 출력:** 비행 시간, 거리, 최고점, 착지 속력·각도, `vₓ/vᵧ`, 가속도, 운동·위치에너지, 표적 오차.

#### 60분 수업안

1. `0~7분` 최고점에서 속도와 가속도가 0인지 예측한다.
2. `7~17분` 수평 발사와 자유낙하를 동기화해 수직 운동이 같은지 확인한다.
3. `17~30분` 모둠별 발사각 구간을 맡아 같은 속력으로 거리·최고점·시간을 수집한다.
4. `30~40분` 학급 각도–거리 곡선에서 최대 조건과 보완각 쌍을 찾는다.
5. `40~50분` 항력·바람을 열고 이상 모형의 결론이 실패하는 조건을 설계한다.
6. `50~60분` 두 가지 서로 다른 발사 조건으로 같은 표적을 맞히고 어떤 해가 더 안전한지 논증한다.

#### 학급 통계

- 발사각–거리·최고점·시간의 다중 산점도와 이론 곡선 잔차.
- 같은 표적을 맞힌 성공 조건의 각도–속력 분포와 해 군집.
- 이상/항력 모형의 개인별 거리 차이와 학급 변화량 분포.
- 자기 실행을 학급 곡선 위에 표시하고, 이상점은 조건표로 원인을 추적한다.

#### 재미·상상 미션

- **화성 구조 물자 투하:** 제한된 속력으로 협곡 건너 표적에 도달한다.
- **두 궤적 한 표적:** 가장 낮은 최고점 해와 가장 긴 체공 해를 각각 찾는다.
- **바람을 이용하라:** 맞바람 또는 옆바람이 있는 상황에서 최소 에너지 조건을 설계한다.
- **틀린 물리 영화:** 궤적과 힘 화살표가 모순되는 장면을 만들고 무엇이 잘못됐는지 설명한다.

### 6.3 일·에너지·간단한 기계 실험실

#### 조작 가능한 요소

- **입문:** 도구 종류(지레·고정/움직도르래·빗면), 짐 질량, 목표 높이, 받침점 또는 빗면 길이.
- **탐구:** 힘점·작용점 위치, 힘의 크기·방향, 도르래 수와 줄 연결, 마찰계수, 막대·줄 질량.
- **연구:** 효율, 탄성 줄, 도르래 관성, 속도 제한, 작업자의 최대 힘·이동거리, 안전계수.
- **구조·사건:** 받침점·짐·힘점 배치, 도르래에 줄 걸기, 빗면 경로 제작, 힘을 시간에 따라 가하기.
- **관측:** 힘 벡터/돌림힘/이동거리/에너지 장부/힘–거리 그래프, 이상·현실 기계 비교.
- **핵심 출력:** 필요한 입력 힘, 입력·출력 거리, 돌림힘, 입력·출력 일, 손실 에너지, 효율, 평형·운동 방향.

#### 60분 수업안

1. `0~5분` 작은 힘이 일을 줄이는지 예측한다.
2. `5~15분` 지레에서 받침점만 움직여 필요한 힘과 힘점 이동거리를 동시에 측정한다.
3. `15~28분` 모둠별 지레·도르래·빗면으로 같은 짐을 같은 높이까지 올린다.
4. `28~38분` 학급의 힘–거리–일 자료를 합쳐 이상적 교환 관계를 확인한다.
5. `38~50분` 마찰과 효율을 열고 실제 기계에서 입력 일이 더 커지는 이유를 에너지 장부로 추적한다.
6. `50~60분` 힘 제한과 공간 제한을 동시에 만족하는 실제 운반 장치를 설계한다.

#### 학급 통계

- 기계적 이득과 입력거리의 관계, 입력 일의 도구별 분포.
- 마찰계수–효율 산점도와 도구 종류별 상자그림.
- 목표를 달성한 설계의 힘·거리·재료 수를 평행좌표 또는 산점도 행렬로 비교한다.
- 자기 설계가 힘 절약형, 거리 절약형, 균형형 중 어디에 있는지 본다.

#### 재미·상상 미션

- **피라미드 건설팀:** 최대 인력과 통로 길이 제한 안에서 돌을 올린다.
- **달 기지 화물문:** 낮은 중력과 제한된 실내 공간에 맞는 기계를 고른다.
- **접이식 구조 장치:** 짐을 올린 뒤 가장 작은 공간에 접히는 구조를 만든다.
- **영구기관 심사관:** 입력보다 큰 일을 계속 내놓는 설계를 찾아 왜 불가능한지 에너지 장부로 반박한다.

### 6.4 전기회로 실험실

#### 조작 가능한 요소

- **입문:** 전지·스위치·전구·저항 배치, 도선 연결·해제, 전지 전압, 저항값.
- **탐구:** 전류계·전압계 위치, 직렬·병렬 구조, 전구 정격, 전지 내부저항, 도선 저항.
- **연구:** 비오옴성 전구, 다이오드·축전기 모듈, 접촉 불량, 센서 입력, 전원 전류 제한.
- **구조·사건:** 부품 끌어놓기, 노드 연결, 스위치 사건, 고장 삽입, 부품 하나 제거.
- **관측:** 실물/표준 회로도/전위 지도/에너지 전달, 전류 방향, `V-I`, 전력·시간 그래프.
- **핵심 출력:** 가지별 전류, 소자별 전압·전력, 등가저항, 전지 출력, 밝기, 계기 판독, 단락·과부하 상태.

#### 60분 수업안

1. `0~7분` 전구를 지난 전류가 줄어드는지 예측한다.
2. `7~17분` 단일 회로를 연결하고 세 지점의 전류를 측정한다.
3. `17~30분` 모둠별 직렬·병렬·혼합 회로를 만들고 전구 제거 전후를 비교한다.
4. `30~40분` 학급 회로 구조–전체 전류–전구 전력 자료를 합친다.
5. `40~50분` 전위 지도로 전압 상승·강하를 검산하고 계기 연결 오류를 진단한다.
6. `50~60분` 제한된 전지·전구로 일부가 고장 나도 나머지가 켜지는 교실 조명을 설계한다.

#### 학급 통계

- 회로 구조별 전체 전류·등가저항·전력 분포.
- 저항값–전류 산점도와 오옴성/비오옴성 소자의 잔차 비교.
- 고장 진단 선택과 실제 원인의 혼동행렬.
- 자기 회로를 같은 밝기 조건을 만족한 다른 익명 설계들과 비교한다.

#### 재미·상상 미션

- **우주선 비상등:** 전구 한 개가 끊어져도 두 구역 이상이 켜져야 한다.
- **도둑 경보기:** 문 스위치와 조명 상태가 조건에 따라 바뀌는 회로를 만든다.
- **최소 부품 도시:** 목표 밝기와 안전 전류를 가장 적은 부품으로 만족한다.
- **회로 탐정:** 화면에 보이지 않는 고장 하나를 전압·전류 측정 세 번 이내에 찾는다.

### 6.5 확률·통계 실험실

#### 조작 가능한 요소

- **입문:** 동전·주사위·공 추출 선택, 시행 횟수, 반복 속도, 결과 가리기, 시드 재실행.
- **탐구:** 면별 확률·공 구성, 복원/비복원 추출, 표본 크기, 반복 집단 수, 중단 규칙.
- **연구:** 자료 생성 분포, 평균·분산, 표본 추출 방식, 이상치, 집단 혼합, 추세·잡음, 제3변수.
- **구조·사건:** 표본공간 구성, 룰렛 구간 조절, 자료점 추가·삭제, 집단 라벨 변경, 조사 표본 선택.
- **관측:** 빈도/상대도수, 누적 경로, 히스토그램, 상자그림, 산점도, 표본분포, 로그·고정 축.
- **핵심 출력:** 빈도·비율·기댓값·분산, 최장 연속, 평균·중앙값·사분위범위, 상관계수, 잔차, 신뢰구간 직관.

#### 60분 수업안

1. `0~6분` 5회 연속 앞면 뒤 다음 결과와 확신도를 예측한다.
2. `6~16분` 개인이 20회 시행하고 상대도수와 빈도 차이를 구분한다.
3. `16~28분` 모둠별 20·100·500·2,000회 표본을 생성해 학급 누적 경로를 비교한다.
4. `28~38분` 같은 평균이지만 퍼짐이 다른 두 집단을 만들어 어떤 요약값이 필요한지 찾는다.
5. `38~50분` 산점도에 숨은 집단 또는 제3변수를 열어 상관–인과 주장을 검토한다.
6. `50~60분` 제한된 시도만으로 조작된 게임과 공정한 게임을 구분하는 검사 계획을 설계한다.

#### 학급 통계

- 학생별 표본비율의 분포와 표본 크기별 퍼짐 비교.
- 연속 사건 길이, 이론확률과의 차이, 중단 규칙별 결과 분포.
- 학급 전체가 하나의 메타 표본이 되어 개인 표본이 어디에 놓이는지 확인한다.
- 같은 원자료에 대한 평균·중앙값 선택과 인과 판단의 응답 분포를 함께 본다.

#### 재미·상상 미션

- **축제 게임 감사관:** 참가자에게 불리한 숨은 확률을 제한된 표본으로 찾아낸다.
- **외계 주사위:** 면 수와 가중치를 설계해 특정 합이 가장 자주 나오게 한다.
- **가짜 그래프 제작소:** 사실은 같지만 오해를 부르는 축·구간 그래프를 만들고 서로 비판한다.
- **희귀 사건 사냥:** 가장 드문 사건을 정의하고 필요한 시행 횟수를 먼저 추정한 뒤 관찰한다.

### 6.6 행성 중력 실험실

#### 조작 가능한 요소

- **입문:** 천체 질량, 반지름, 시작 높이, 물체 질량, 낙하·점프·수평 발사.
- **탐구:** 초기 속력·방향, 시작 고도, 대기 켜기, 천체 자전, 관측 물체 단면적.
- **연구:** 밀도 고정 모드, 내부 질량분포, 비구형성 단순 모듈, 다천체 섭동, 충돌·탈출 판정.
- **구조·사건:** 가상 행성 제작, 표면 관측소 배치, 물체 동시 낙하, 순간 속도 변화.
- **관측:** 표면 비교/중력장 등고선/거리–`g` 그래프/궤도/에너지, 실제·과장 크기.
- **핵심 출력:** 표면·현재 고도의 `g`, 무게, 낙하 시간·충돌 속력, 최고점, 궤도 주기·근원점·원점, 탈출 여부.

#### 60분 수업안

1. `0~7분` 큰 행성이 항상 표면 중력이 큰지 예측한다.
2. `7~17분` 질량이 다른 두 물체를 진공에서 동시 낙하한다.
3. `17~30분` 모둠별 천체 질량·반지름 구간을 맡아 같은 표면 중력을 만드는 조합을 찾는다.
4. `30~40분` 학급 질량–반지름–표면중력 데이터를 등고선 또는 산점도에 합친다.
5. `40~50분` 일정 `g`와 역제곱 모형의 낙하·점프 결과가 달라지는 높이를 찾는다.
6. `50~60분` 인간이 점프할 수 있고 대기를 붙잡을 가능성도 있는 가상 탐사 행성을 설계한다.

#### 학급 통계

- 질량·반지름–표면중력의 3변수 분포와 같은 `g` 조합 군집.
- 물체 질량별 낙하 시간 분포를 진공/대기 조건으로 분리한다.
- 수평 발사 속력과 궤도 상태의 범주 전이표.
- 자기 행성을 학급의 밀도·중력·탈출속력 공간에서 찾는다.

#### 재미·상상 미션

- **점프 행성:** 5초 이상 체공하지만 탈출하지 않는 표면 조건을 만든다.
- **작지만 강한 행성:** 반지름은 지구보다 작고 표면 중력은 더 큰 천체를 설계한다.
- **궤도 우편:** 최소 속도 변화로 위성을 목표 관측 고도에 올린다.
- **중력 가짜뉴스:** `무거운 물체가 더 빨리 떨어진다`를 참처럼 보이게 하는 대기 조건과 진짜 원인을 구분한다.

### 6.7 함수 그래프 실험실

#### 조작 가능한 요소

- **입문:** 함수족 선택, `a/b/h/k` 계수, 입력 `x`, 정의역, 좌표축 범위.
- **탐구:** 식의 형식(일반형·꼭짓점형·인수분해형), 기준 함수, 대표점, 두 번째 함수, 교점 조건.
- **연구:** 절댓값·지수·삼각 함수 확장, 조각함수, 데이터 잡음, 적합 모형, 잔차, 매개변수 애니메이션.
- **구조·사건:** 그래프를 점·꼭짓점·절편으로 드래그, 조건 카드를 끌어 식 구성, 데이터점 추가·이동.
- **관측:** 식/표/대응/그래프/변화율/잔차, 고정·자동 축, 변환 궤적, 입력점 동기 추적.
- **핵심 출력:** 기울기·절편·꼭짓점·대칭축·근·교점, 평균변화율, 조건 오차, 적합도·잔차.

#### 60분 수업안

1. `0~6분` 계수 하나를 바꾸면 그래프가 어느 방향으로 움직일지 예측한다.
2. `6~16분` 입력점 하나를 식–표–그래프에서 동기 추적한다.
3. `16~30분` 모둠별 계수 구간을 맡아 `a`와 기울기 또는 이차함수 폭의 관계를 수집한다.
4. `30~40분` 학급 매개변수–그래프 성질 자료에서 부호·크기 효과를 일반화한다.
5. `40~50분` 서로 다른 표현의 식이 같은 그래프인지 대표점·전개·근으로 검증한다.
6. `50~60분` 주어진 점·꼭짓점·통과 금지 구역을 만족하는 서로 다른 함수를 설계한다.

#### 학급 통계

- 계수–기울기·폭·근·꼭짓점의 산점도와 부호별 범주.
- 같은 조건을 만족한 함수들의 매개변수 분포와 해 공간.
- 데이터 적합 미션에서 기울기·절편·잔차 합의 학급 분포.
- 자기 함수가 목표 오차와 복잡도 공간에서 어디에 있는지 본다.

#### 재미·상상 미션

- **그래프 롤러코스터:** 출발·도착점과 최대 높이 제한을 만족하는 궤도를 만든다.
- **함수 지문:** 그래프 일부만 보고 가능한 식을 여러 개 찾아 추가 측정 한 번으로 구분한다.
- **교점 숨바꼭질:** 두 함수가 보이는 범위에서는 만나지 않지만 정의역을 넓히면 만나게 한다.
- **데이터 위조 탐정:** 자동 축과 일부 데이터 삭제로 만든 오해를 원자료와 잔차로 찾아낸다.

### 6.8 원자 조립 실험실

#### 조작 가능한 요소

- **입문:** 양성자·중성자·전자 추가·제거, 핵종 기호·원소명 가리기, 중성 상태 자동 맞춤.
- **탐구:** 전자 껍질 배치, 동위원소 존재비, 이온 전하, 원자번호 범위, 에너지 준위 전이.
- **연구:** 평균 원자량, 간단한 방출 스펙트럼, 유효 핵전하의 정성 표현, 보어/전자구름 모형 비교.
- **구조·사건:** 입자를 핵·전자 영역에 배치, 전자 들뜸·방출 사건, 동위원소 혼합물 구성.
- **관측:** 입자 조립/핵종 기호/주기율표/전자배치/모형 비교/스펙트럼, 축척 경고.
- **핵심 출력:** 원소·핵종·이온 정체, `Z/A/N`, 순전하, 전자배치, 평균 원자량, 방출 파장·에너지.

#### 60분 수업안

1. `0~7분` 원소의 정체를 결정하는 입자를 예측한다.
2. `7~17분` 양성자·중성자·전자를 각각 하나씩 바꾸며 무엇이 달라지는지 표를 만든다.
3. `17~30분` 모둠별 미지 핵종 카드의 입자 수를 조립해 검증한다.
4. `30~40분` 학급 핵종을 주기율표와 질량수–전하 공간에 모은다.
5. `40~50분` 동위원소 존재비를 달리해 같은 원소의 평균 원자량을 역으로 맞힌다.
6. `50~60분` 보어 모형과 전자구름 모형 중 주어진 질문에 더 적절한 표현을 선택하고 한계를 설명한다.

#### 학급 통계

- 양성자·중성자·전자 변경에 따른 정체 변화 범주표.
- 같은 평균 원자량을 만든 동위원소 존재비 조합 분포.
- 핵종 기호 해독 오류를 `Z/A/전하 위치` 유형으로 집계한다.
- 자기 핵종을 학급의 원자번호–중성자수 지도에서 찾는다.

#### 재미·상상 미션

- **원자 신분증 위조범:** 원소는 그대로인데 질량이나 전하만 달라지게 만든다.
- **미지 우주 광물:** 평균 원자량 단서로 가능한 동위원소 혼합을 찾는다.
- **스펙트럼 암호:** 제한된 전자 전이로 목표 색 조합을 만든다.
- **모형 재판:** `전자는 정해진 원형 궤도를 돈다`는 주장을 두 모형의 용도와 한계로 심문한다.

### 6.9 먹이사슬 생태계 실험실

#### 조작 가능한 요소

- **입문:** 종별 초기 개체수, 생산자 성장률, 포식·섭식률, 사망률, 환경수용력, 시간.
- **탐구:** 먹이망 연결, 번식 효율, 계절성, 서식지 크기, 질병·가뭄·오염 충격, 포획.
- **연구:** 확률적 출생·사망, 공간 이동, 연령 구조, 외래종, 복원 사업, 에너지 전달효율, 분해율.
- **구조·사건:** 종·연결 추가·삭제, 특정 시각에 교란 발생, 보호구역 배치, 정책 시작·중단.
- **관측:** 서식지/개체군 그래프/상호작용망/에너지 흐름/물질 저장고/방정식 항.
- **핵심 출력:** 개체수·변화율·봉우리 시각, 진동 주기, 회복 시간, 멸종 위험, 영양 단계 에너지, 생물량·물질 저장량.

#### 60분 수업안

1. `0~6분` 포식자를 줄이면 초식동물이 계속 증가하는지 예측한다.
2. `6~16분` 세 단계 먹이사슬의 기본 진동과 봉우리 시간차를 측정한다.
3. `16~30분` 모둠별 포식·성장·수용력 구간을 맡아 회복·붕괴 조건을 수집한다.
4. `30~40분` 학급 매개변수–장기 상태 지도를 만들고 경계 조건을 찾는다.
5. `40~50분` 에너지 흐름과 탄소 물질 순환을 켜서 같은 화살표로 설명할 수 없는 이유를 본다.
6. `50~60분` 예산 제한 아래 서식지 회복·포획·외래종 통제 정책을 설계하고 부작용을 비교한다.

#### 학급 통계

- 매개변수 조합별 안정·진동·붕괴·멸종 범주 지도.
- 교란 크기–회복 시간 산점도와 정책별 분포.
- 봉우리 시간차와 영양 단계 관계, 에너지 전달효율 분포.
- 자기 생태계가 학급의 안정성–다양성–복원력 공간에서 어디에 있는지 본다.

#### 재미·상상 미션

- **100년 섬 생태계:** 한 종도 사라지지 않되 개체수가 고정되지 않는 섬을 설계한다.
- **외계 생물 침입:** 새 연결 하나가 예상 밖의 종에 미치는 간접 효과를 찾는다.
- **생태계 소방대:** 가뭄 뒤 가장 빨리 회복하는 제한 예산 정책을 만든다.
- **화살표 통역사:** 먹이, 에너지, 물질, 개체수 영향의 네 화살표를 서로 바르게 번역한다.

### 6.10 달의 위상 실험실

#### 조작 가능한 요소

- **입문:** 달 공전 위치, 시간, 태양광 방향, 지구 관측자 위치, 재생 속도.
- **탐구:** 날짜·시각, 관측 위도·반구, 달 궤도 경사, 지구 자전, 항성 배경.
- **연구:** 항성월/삭망월 비교, 교점 위치, 일·월식 조건, 거리 변화, 실제 천문력 비교 모듈.
- **구조·사건:** 관측자와 지평선 배치, 달을 예측 위치에 드래그, 특정 위상·식 조건 만들기.
- **관측:** 우주/지구 관측창/하늘 경로/실제 비율/광선·그림자 원뿔, 위상명 가리기.
- **핵심 출력:** 밝은 면 비율, 태양 각거리, 위상, 출·남중·몰 시각, 고도·방위, 삭망월 진행, 식 가능 여부.

#### 60분 수업안

1. `0~7분` 위상이 지구 그림자 때문에 생기는지 예측 그림을 그린다.
2. `7~17분` 우주 관점과 지구 관측창을 동기화해 항상 절반이 밝은 달을 확인한다.
3. `17~30분` 모둠별 공전 위치를 맡아 위상·각거리·예상 출몰 시각을 기록한다.
4. `30~40분` 학급 자료를 한 삭망월 시간선과 하늘 경로에 합친다.
5. `40~50분` 궤도 경사를 켜 위상과 식의 조건을 분리한다.
6. `50~60분` 모양만 보고 관측 가능 시간과 하늘 방향을 예측하는 달 관측 계획을 만든다.

#### 학급 통계

- 공전각–밝은 면 비율·출몰 시각의 주기 그래프.
- 위상 예측과 실제 관측창 결과의 혼동행렬.
- 위도·반구별 달 방향·하늘 경로 차이 분포.
- 자기 예측을 학급 위상 시간선에서 확인하고 180° 반전·그림자설 오류를 비교한다.

#### 재미·상상 미션

- **달 사진 촬영 계획:** 주어진 시각에 원하는 위상을 어느 방향에서 찾을지 정한다.
- **식 없는 한 달:** 위상은 모두 나타나지만 일·월식은 없게 궤도 경사를 조절한다.
- **위상 암호:** 위상 세 장과 촬영 시각 단서만으로 순서와 관측 방향을 복원한다.
- **외계 달력:** 자전·공전 속도가 다른 행성에서 위상 달력 한 달을 설계한다.

### 6.11 산·염기 실험실

#### 조작 가능한 요소

- **입문:** 용액 종류, 농도, 부피, 혼합량, 지시약 종류·양, 가상 피펫·뷰렛.
- **탐구:** 강산·강염기/약산·약염기, 첨가 간격, 희석수, 목표 pH, 온도 고정값.
- **연구:** `pKₐ`, 완충 성분비, 다양성자산 단순 모듈, 측정 오차, 지시약 농도·조명 조건.
- **구조·사건:** 용액 선택·혼합, 한 방울/연속 적가, 미지 시료 생성, 센서 보정.
- **관측:** 실험대/색 스펙트럼/입자 비율/로그 농도축/적정 곡선/물질량 장부.
- **핵심 출력:** pH, `[H⁺]/[OH⁻]`, 남은 몰수, 중화율, 지시약 상태비·색, 등당량점·종말점 오차.

#### 60분 수업안

1. `0~7분` pH 3과 pH 4의 수소 이온 농도 차이를 예측한다.
2. `7~17분` 같은 용액에 여러 지시약을 넣어 색과 정확한 pH 판독을 구분한다.
3. `17~30분` 모둠별 다른 농도의 강산을 같은 강염기로 적정해 곡선을 수집한다.
4. `30~40분` 학급 적정곡선과 종말점 오차 분포를 지시약별로 비교한다.
5. `40~50분` 약산·완충 모듈을 열어 강산의 단순 몰수 계산이 그대로 적용되지 않는 조건을 찾는다.
6. `50~60분` 제한된 지시약과 적가 횟수로 미지 용액의 가능한 범위를 가장 좁게 만든다.

#### 학급 통계

- 농도·부피–등당량점 부피 관계와 잔차.
- 지시약별 종말점 오차의 상자그림.
- 학생별 한 방울 크기·적가 간격을 포함한 측정 분포.
- 자기 적정 결과를 같은 농도 학급 곡선의 중앙값·범위와 비교한다.

#### 재미·상상 미션

- **지시약 탐정:** 세 번의 색 관찰만으로 미지 용액 후보를 최대한 줄인다.
- **pH 착륙:** 적가 횟수 제한 안에서 목표 pH 구간에 들어간다.
- **완충 방패:** 최소 성분량으로 정해진 산 첨가 뒤 pH 변화를 제한한다.
- **색만 믿지 마:** 같은 색처럼 보이지만 pH가 다른 조건을 만들고 추가 측정을 제안한다.

### 6.12 열과 열전달 실험실

#### 조작 가능한 요소

- **입문:** 물질, 질량, 초기 온도, 접촉, 주변 온도, 가열·냉각·정지.
- **탐구:** 접촉 면적, 비열, 열전도율, 단열재 종류·두께, 열원 출력, 유체 흐름.
- **연구:** 대류 계수, 표면 방사율, 상변화, 온도 의존 물성 단순 모듈, 센서 위치·지연·잡음.
- **구조·사건:** 물체를 접촉·분리, 단열층 배치, 열원 켜기, 뜨거운 물체 투입, 진공 설정.
- **관측:** 열화상/입자 속력 분포/에너지 장부/`T-t`/전달률/전도·대류·복사 레이어.
- **핵심 출력:** 물체별 온도, 주고받은 에너지, 전달률, 평형 온도·도달 시간, 상 비율, 손실 경로.

#### 60분 수업안

1. `0~6분` 작은 뜨거운 물체와 큰 미지근한 물체 중 에너지가 더 많은 쪽을 예측한다.
2. `6~16분` 질량·물질이 다른 두 물체의 열평형을 관찰한다.
3. `16~30분` 모둠별 질량·비열 조합을 맡아 최종 온도를 예측·측정한다.
4. `30~40분` 학급 에너지 보존 장부와 예측 오차 분포를 비교한다.
5. `40~50분` 전도·대류·복사를 하나씩 제거해 냉각 경로를 분리한다.
6. `50~60분` 재료비·두께 제한 안에서 가장 오래 목표 온도를 유지하는 용기를 설계한다.

#### 학급 통계

- 질량·비열–평형 온도 및 도달 시간의 산점도.
- 단열재 조합별 열손실률·비용 분포.
- 예측 온도와 모형 결과의 대응 차이, 오개념 유형별 오차 방향.
- 자기 설계를 보온 성능–비용–질량 공간에서 찾는다.

#### 재미·상상 미션

- **화성 도시락:** 얇고 가벼우면서 30분간 따뜻함을 유지한다.
- **얼음 구조 작전:** 같은 냉각 에너지로 가장 늦게 완전히 어는 조건을 만든다.
- **열화상 위장:** 표면 온도만 같지만 내부 에너지 상태가 다른 두 물체를 설계한다.
- **우주선 냉각:** 대류가 없는 환경에서 열을 내보낼 방법을 찾는다.

### 6.13 빛·상·파동 실험실

#### 조작 가능한 요소

- **입문:** 광원·물체·눈 위치, 평면거울·렌즈 배치, 입사각, 렌즈 초점거리.
- **탐구:** 굴절률, 경계면, 거울 곡률, 물체거리, 스크린·조리개, 빛 색·파장.
- **연구:** 파동 진폭·진동수·위상, 매질 속력, 간섭·회절 모듈, 렌즈 수차 단순 모듈, 센서 해상도.
- **구조·사건:** 광학 소자 끌어놓기·회전, 광선 차단, 렌즈 일부 가리기, 파동원 생성·동기화.
- **관측:** 현상/대표 광선/파면/관측자/상 측정/시간 파형·스펙트럼.
- **핵심 출력:** 반사·굴절각, 임계각, 상 위치·크기·방향·실허, 초점, 파장·진동수·속력, 간섭 세기.

#### 60분 수업안

1. `0~7분` 눈–물체–광원 중 빛의 진행 방향을 예측한다.
2. `7~17분` 눈 위치를 움직여 실제로 들어오는 반사 광선만 추적한다.
3. `17~30분` 모둠별 물체거리·초점거리 구간을 맡아 렌즈 상을 측정한다.
4. `30~40분` 학급 물체거리–상거리 자료를 이론 관계와 비교한다.
5. `40~50분` 렌즈 절반 가리기와 거울 시야 실험으로 `상의 일부가 사라진다`는 예측을 검증한다.
6. `50~60분` 주어진 공간 안에서 잠망경·카메라·확대기 중 하나를 설계하고 광선으로 설명한다.

#### 학급 통계

- 입사각–반사·굴절각, 물체거리–상거리의 산점도와 잔차.
- 상의 실허·정립도립·확대축소 예측 혼동행렬.
- 장치 설계별 시야각·상 크기·총 길이 분포.
- 자기 광학 장치를 학급의 선명도–크기–공간 제약 지도에서 본다.

#### 재미·상상 미션

- **모퉁이 구조 잠망경:** 사람을 노출하지 않고 목표를 보는 장치를 만든다.
- **거울 미로:** 최소 거울 수로 광선을 목표 센서까지 보낸다.
- **렌즈 암호:** 상의 방향과 크기 단서로 숨은 렌즈·물체 위치를 찾는다.
- **소리 조각가:** 진폭과 진동수를 따로 조절해 큰/작은 소리와 높은/낮은 소리 조합 네 가지를 만든다.

### 6.14 입자와 기체 실험실

#### 조작 가능한 요소

- **입문:** 입자 수, 용기 부피, 온도, 피스톤 이동·고정, 가열·냉각.
- **탐구:** 외부 압력·피스톤 하중, 입자 질량, 혼합 비율, 벽 종류, 미세 구멍·막.
- **연구:** 등온/등압/등적 경로, 상호작용 세기, 이상/실제기체 단순 비교, 속력 분포, 측정 시간창.
- **구조·사건:** 칸막이 제거, 입자 추가·제거, 추 달기, 용기 연결, 순간 가열·압축.
- **관측:** 입자 용기/선택 입자 경로/충돌 지도/거시 계기/속력 분포/`P-V-T` 그래프/상태 모형.
- **핵심 출력:** 압력·부피·절대온도·입자 수, 충돌 빈도·평균 충격량, 평균·제곱평균제곱근 속력, 확산 시간.

#### 60분 수업안

1. `0~6분` 기체를 압축하면 입자 크기와 간격 중 무엇이 변하는지 예측한다.
2. `6~16분` 피스톤을 천천히 눌러 충돌 지도와 압력계를 연결한다.
3. `16~30분` 모둠별 부피 구간을 맡고 온도·입자 수를 잠가 `P-V` 자료를 모은다.
4. `30~40분` 학급 공동 곡선에서 반비례와 측정 요동을 구분한다.
5. `40~50분` 등압 가열에서 입자 크기·속력 분포·피스톤 이동을 추적한다.
6. `50~60분` 압력 제한을 넘지 않으면서 목표 부피까지 팽창하는 가상 기체 장치를 설계한다.

#### 학급 통계

- 등온 `P-V`, 등압 `V-T`, 등적 `P-T` 자료와 이론 곡선 잔차.
- 측정 시간창·입자 수에 따른 압력 요동 분포.
- 확산 시간의 반복 분포와 온도·입자 질량 관계.
- 자기 실행을 학급 상태도에 표시하고 같은 압력을 만든 서로 다른 조건을 찾는다.

#### 재미·상상 미션

- **행성 탐사 풍선:** 외부 압력이 변해도 터지지 않는 초기 조건을 설계한다.
- **분자 경주:** 평균 속력이 아니라 도착 시간 분포를 이용해 가벼운 입자와 무거운 입자를 구분한다.
- **보이지 않는 누출:** 압력·온도 기록만으로 입자 손실이 시작된 시점을 찾는다.
- **입자 크기 착시:** 거시 결과는 같지만 미시 설명 하나가 틀린 장면을 만들어 서로 판별한다.

### 6.15 화학 반응과 보존 실험실

#### 조작 가능한 요소

- **입문:** 반응물 종류·입자 묶음 수, 혼합 비율, 열린/닫힌 용기, 반응 시작.
- **탐구:** 질량·몰수, 농도, 온도, 표면적, 촉매, 기체 포집, 저울 경계.
- **연구:** 제한 반응물, 수득률·불순물, 반응속도 단순 모형, 에너지 프로필, 가역 반응 확장.
- **구조·사건:** 입자 직접 배치, 반응식 계수 조절, 용기 밀폐·개방, 특정 시각에 반응물 추가.
- **관측:** 거시 실험대/입자 재배열/원자 장부/화학 반응식/질량–시간/에너지 흐름.
- **핵심 출력:** 원소별 원자 수, 반응·생성·남은 양, 계 안팎 질량, 제한 반응물, 진행률·속도, 온도·에너지 변화.

#### 60분 수업안

1. `0~7분` 기체가 생기는 열린 반응에서 저울 질량이 어떻게 변할지 예측한다.
2. `7~17분` 같은 반응을 열린/닫힌 용기에서 실행하고 계 경계를 표시한다.
3. `17~30분` 모둠별 반응물 비율을 맡아 생성량·남는 반응물을 측정한다.
4. `30~40분` 학급 혼합비–생성량 그래프에서 최대점과 제한 반응물 전환을 찾는다.
5. `40~50분` 온도·농도·표면적을 바꿔 반응 속도와 최종 생성량을 분리한다.
6. `50~60분` 목표 생성량을 만들되 남는 반응물과 에너지 소비를 줄이는 공정을 설계한다.

#### 학급 통계

- 혼합비–생성량·잔량의 꺾은 관계와 전환점.
- 열린/닫힌 계의 저울 변화 분포와 계 경계 설명 유형.
- 반응 조건별 초기 속도와 최종량의 이변량 비교.
- 자기 공정을 학급의 생성량–폐기량–시간 공간에서 찾는다.

#### 재미·상상 미션

- **우주선 산소 공장:** 제한된 원료로 목표 기체를 만들고 남는 물질을 최소화한다.
- **사라진 질량 사건:** 저울값은 줄었지만 원자는 사라지지 않은 실험 장면을 재구성한다.
- **반응식 해킹 방지:** 아래첨자를 바꿔 억지로 맞춘 반응식을 찾아 입자 모형으로 반박한다.
- **빠르지만 낭비 없는 공장:** 시간 제한·온도 비용·수득량을 함께 만족한다.

### 6.16 유전과 세포분열 실험실

#### 조작 가능한 요소

- **입문:** 부모 유전자형, 대립유전자, 자손 수, 무작위 시드, 체세포/감수분열 선택.
- **탐구:** 두 유전자 좌위, 독립/연관, 교차율, 성염색체 연관, 불완전 우성, 환경 조건.
- **연구:** 다유전자 형질의 정성 모형, 침투도·표현도, 돌연변이 사건, 집단 빈도 모듈.
- **구조·사건:** 염색체 쌍 배치, 분열 단계 진행, 교차 위치 선택, 배우자 결합, 가상 가계 구성.
- **관측:** 세포/염색체 추적/배우자 표본공간/퍼넷 사각형/가계도/유전자–단백질–형질 경로.
- **핵심 출력:** 세포별 염색체·DNA 상대량, 가능한 배우자, 유전자형·표현형 이론확률과 관측빈도, 교차형 비율.

#### 60분 수업안

1. `0~7분` 우성 형질이 더 흔하거나 강한지 예측한다.
2. `7~17분` 같은 시작 세포의 체세포분열과 감수분열 결과를 비교한다.
3. `17~30분` 모둠별 부모 조합에서 가상 생물 자손 20개를 생성한다.
4. `30~40분` 학급 자손을 합쳐 이론비와 한 가족의 결과 차이를 비교한다.
5. `40~50분` 연관·교차 또는 환경 효과를 열어 단순 퍼넷 사각형의 한계를 찾는다.
6. `50~60분` 목표 형질 조합을 얻을 가능성을 높이되 결과를 보장할 수 없는 이유를 설명하는 가상 생물 계획을 만든다.

#### 학급 통계

- 가족 규모별 관측 비율 분포와 학급 합산 비율.
- 이론확률–관측빈도 차이가 표본 크기에 따라 줄어드는 양상.
- 교차율–재조합형 비율 산점도.
- 자기 가상 가족을 학급 유전자형·표현형 분포에서 찾되 실제 학생·가족 정보와 연결하지 않는다.

#### 재미·상상 미션

- **가상 생물 연구소:** 날개 무늬·촉수 색 등 비인간 형질로 다양한 자손 집단을 만든다.
- **네 자녀 3:1 함정:** 이론비와 정확히 맞지 않는 가족을 찾고 왜 정상인지 설명한다.
- **우성 가짜뉴스:** 우성이 더 흔하지 않은 집단을 설계한다.
- **염색체 추적 구조대:** 분열 결과가 잘못된 세포에서 어느 단계의 분리가 실패했는지 찾는다.

### 6.17 계절과 태양 고도 실험실

#### 조작 가능한 요소

- **입문:** 날짜·공전 위치, 시간, 위도·반구, 자전축 기울기, 지구 자전.
- **탐구:** 궤도 이심률, 공전 속도, 표면 경사·방향, 대기 투과 단순계수, 지표 반사율.
- **연구:** 지표 열용량·온도 지연, 구름 조건, 과거·가상 행성 기울기, 세차 방향 모듈.
- **구조·사건:** 관측 도시 배치, 표면 패치 회전, 가상 행성·궤도 제작, 날짜 프리셋 이동.
- **관측:** 우주/지역 표면/태양 하늘 경로/양반구 비교/연간 그래프/실제·과장 비율.
- **핵심 출력:** 태양 적위·남중 고도, 낮 길이, 입사각, 순간·일 누적 에너지, 지구–태양 거리, 표면 온도 지연값.

#### 60분 수업안

1. `0~7분` 북반구 여름에 지구가 태양과 더 가까운지 예측한다.
2. `7~17분` 원궤도·기울기 있음 조건에서 양반구의 태양 고도와 낮 길이를 비교한다.
3. `17~30분` 모둠별 위도 구간을 맡아 네 계절의 남중 고도·낮 길이·누적 에너지를 수집한다.
4. `30~40분` 학급 위도–에너지 연간 지도를 완성한다.
5. `40~50분` 기울기 0°, 실제값, 큰 기울기를 비교하고 거리 효과를 별도로 복원한다.
6. `50~60분` 주어진 생물·에너지 조건에 적합한 가상 행성 정착지와 활동 달력을 설계한다.

#### 학급 통계

- 위도–남중 고도·낮 길이·일 누적에너지의 계절별 곡선.
- 자전축 기울기와 연간 에너지 변동폭의 관계.
- 같은 날짜 북·남반구의 대응 변화량 분포.
- 자기 정착지를 학급의 계절 변동–연평균 에너지–낮 길이 공간에서 확인한다.

#### 재미·상상 미션

- **계절 없는 행성:** 어느 조건을 바꾸면 계절 에너지 변동이 최소가 되는지 설계한다.
- **두 번의 여름?** 자전축과 궤도 조건을 바꿔 거리 효과와 기울기 효과가 경쟁하는 가상 행성을 만든다.
- **태양광 도시:** 계절별 발전량 차이가 제한을 넘지 않는 위도·패널 경사를 고른다.
- **달력 탐정:** 남중 고도·낮 길이 기록만으로 관측 위도와 계절 후보를 좁힌다.

## 7. 흥미 기반 적용 사례 설계

### 7.1 흥미는 원리를 사용하는 이유에서 만든다

적용 사례는 이론 설명이 끝난 뒤 붙이는 장식이 아니다. 학생이 원리를 배워야 할 이유를 먼저 느끼게 하는 수업의 출발점이다. 모든 사례는 다음 조건을 만족한다.

- 학생이 뉴스, 스포츠, 게임, 교통, 우주, 환경, 생활기술에서 접할 법한 장면으로 시작한다.
- `정답을 계산하라`가 아니라 `성공 조건을 찾아라`, `두 설계를 비교하라`, `주장을 검증하라`처럼 판단할 문제를 준다.
- 핵심 교과 원리를 쓰지 않고는 미션을 안정적으로 해결할 수 없게 한다.
- 결과가 하나뿐이지 않도록 두 개 이상의 성공 해, 비용·안전·시간의 상충, 또는 실패 경계를 둔다.
- 화려한 이야기 때문에 과학 조건을 숨기지 않고 학생이 사용한 변수와 근거를 최종 산출물에 남긴다.
- 실제 장치 제작이나 위험한 물질 혼합을 지시하지 않고 시뮬레이션 안에서 안전하게 탐구한다.
- 특정 직업·성별·문화에만 익숙한 소재로 편중하지 않고 생활, 자연, 스포츠, 기술, 미래 사회를 균형 있게 섞는다.

### 7.2 적용 사례 한 편의 구조

| 단계 | 화면과 활동 | 교육적 역할 |
| --- | --- | --- |
| 15초 장면 | 짧은 영상형 장면, 사진, 데이터 이상 현상 | `왜?`를 먼저 만든다. |
| 의뢰·문제 | 누구에게 어떤 문제가 생겼고 성공 조건이 무엇인지 제시 | 원리를 사용할 목적을 만든다. |
| 첫 선택 | 실행 전 방향·조건·대략값을 고른다 | 직관과 오개념을 드러낸다. |
| 기본 실험 | 핵심 변수 1개로 관계를 확인한다 | 원리의 뼈대를 이해한다. |
| 응용 설계 | 변수 2~4개와 제약조건을 함께 다룬다 | 단순 공식 대입을 넘어선다. |
| 학급 비교 | 서로 다른 성공 해와 실패 해를 분포에서 본다 | 해의 다양성과 통계적 사고를 만든다. |
| 실제 검토 | 모델에서 빠진 조건을 찾아 설계를 수정한다 | 전문성과 모형 비판 능력을 기른다. |

각 주제는 최소한 `생활 미스터리`, `기술·사회 문제`, `미래·상상 설계` 사례를 하나씩 제공한다. 동일 원리를 배경 그림만 바꿔 세 번 반복하는 것은 서로 다른 사례로 세지 않는다.

### 7.3 주제별 관심·응용 사례

#### 조석

1. **갯벌 탐사대의 귀환 시간**
   - 조수 웅덩이를 조사하는 팀이 물에 고립되지 않도록 관측소의 만조 시각과 안전 귀환 시간을 정한다.
   - 달 위치, 태양–달 각도, 관측 경도, 해안 지연을 조작하고 `천문학적 조석`과 `지역 해안 반응`을 구분한다.
   - 최종 산출물은 시간표 하나가 아니라 예측 범위와 이 모형에 기상 효과가 빠졌다는 안전 한계다.
2. **조력발전 운영자**
   - 발전량이 큰 조차와 생태계 통행 시간이 충돌하는 상황에서 수문 운영 시간대를 설계한다.
   - 사리·조금 주기와 시간 지연을 분석하고 학급의 여러 운영안을 에너지–환경 제약 공간에서 비교한다.
3. **두 개의 달을 가진 행성**
   - 서로 다른 질량·거리·주기의 두 달이 만드는 복합 조석에서 항구가 견딜 수 있는 해안 조건을 찾는다.
   - 단순히 가장 큰 조석을 만드는 놀이가 아니라 두 주기의 중첩, 극값 빈도, 장기 관측 필요성을 탐구한다.

#### 운동 분석

1. **농구 슛은 왜 높은 궤적과 낮은 궤적이 모두 가능한가**
   - 같은 골대에 들어가는 발사각–속력 조합을 찾고 림 통과 각도와 최고점까지 비교한다.
   - `45°가 항상 최선`이라는 규칙 대신 발사 높이, 표적 높이, 허용 오차가 최적 조건을 바꾸는 것을 확인한다.
2. **드론의 구호품 투하**
   - 드론은 목표 지점 전에 물자를 놓아야 한다. 고도, 수평속력, 바람, 항력, 투하 시각을 조작한다.
   - 이상 모형으로 첫 예측을 만들고 현실 모형에서 오차가 생기는 이유를 수정한다.
3. **달 기지 협곡 횡단**
   - 제한된 발사 에너지로 장비를 협곡 반대편 안전 구역에 보낸다.
   - 지구와 달의 중력에서 같은 조건을 비교하고 긴 체공시간이 반드시 안전한 것은 아님을 착지 속력으로 판단한다.

#### 일·에너지·간단한 기계

1. **휠체어 경사로 설계**
   - 사용 가능한 복도 길이, 최대 경사, 필요한 힘, 높이 조건을 동시에 만족하는 경사로를 찾는다.
   - 힘을 줄이면 이동거리가 늘어난다는 교환과 마찰·안전 여유를 함께 다룬다.
2. **재난 현장의 구조 장치**
   - 제한된 인원과 줄·도르래로 무거운 장애물을 안전하게 들어 올리는 장치를 배치한다.
   - 최대 힘뿐 아니라 줄을 당겨야 하는 거리, 고정점 하중, 효율을 비교한다.
3. **고대 건축가의 운반 계획**
   - 같은 돌을 지레·빗면·도르래 중 어떤 조합으로 옮길지 지형과 인력 제한에 맞춰 설계한다.
   - 학생은 `옛사람은 힘이 셌다`가 아니라 역학적 이득과 입력 일을 근거로 설명한다.

#### 전기회로

1. **공연장의 무대 조명**
   - 한 조명이 꺼져도 다른 구역이 유지되고 전원 한도를 넘지 않는 회로를 설계한다.
   - 직렬·병렬 구조, 전구 전력, 전체 전류, 고장 격리를 함께 판단한다.
2. **스마트 자전거 안전등**
   - 주변 밝기와 브레이크 상태에 따라 다른 등이 켜지는 가상 회로를 만든다.
   - 회로 연결을 논리 조건과 연결하고 센서의 실제 전기적 한계는 심화에서 검토한다.
3. **우주선 전력 위기**
   - 총 전력 한도 아래 생명유지, 통신, 조명의 우선순위를 정하고 회로 고장 뒤 다시 배분한다.
   - 밝기만 보는 실험을 넘어 전력, 에너지, 작동 시간, 안전 여유의 차이를 사용한다.

#### 확률·통계

1. **확률형 보상은 공정한가**
   - 공개 확률과 모의 결과가 일치하는지 제한된 표본으로 조사하고 성급한 조작 판정을 피한다.
   - 큰 수의 법칙, 표본 변동, 희귀 사건, 중단 규칙을 학생 생활과 가까운 비판적 소비 상황에 적용한다.
2. **스포츠의 연속 성공은 실력 상승인가 우연인가**
   - 슛·서브 성공 기록을 독립 시행 모형과 비교하고 선수별 기본 성공률 차이를 통제한다.
   - `연속 성공 다음에는 실패할 차례`와 `연속 성공은 무조건 흐름`이라는 두 극단을 함께 검증한다.
3. **학교 축제 게임 설계자**
   - 재미, 참가비, 상품 비용, 당첨 체감 빈도를 동시에 고려해 룰렛·주사위 게임을 만든다.
   - 학급 전체가 서로의 게임을 표본 추출로 감사하고 이론확률과 실제 운영 위험을 비교한다.

#### 행성 중력

1. **다른 행성에서 농구를 한다면**
   - 같은 선수의 점프와 슛이 달·화성·가상 행성에서 어떻게 달라지는지 비교한다.
   - 학생 질량은 그대로인데 무게와 체공시간이 달라지는 원리를 분리한다.
2. **소행성 탐사 로봇 착륙**
   - 중력이 약한 천체에서 너무 세게 점프하거나 분사하면 돌아오지 못할 수 있다.
   - 표면 중력, 탈출속력, 반지름을 함께 사용해 안전 이동 범위를 설계한다.
3. **살 수 있는 가상 행성**
   - 지구와 같은 중력을 만들되 질량과 반지름이 다른 여러 행성을 찾고 밀도·탈출속력 차이를 비교한다.
   - `표면 중력 하나가 같으면 환경도 같다`는 결론이 왜 부족한지 토론한다.

#### 함수 그래프

1. **휴대전화 요금제 역설**
   - 기본요금과 사용량 요금이 다른 여러 요금제의 교점을 찾아 누구에게 어느 요금제가 유리한지 판단한다.
   - 교점이 단순한 방정식 답이 아니라 선택이 바뀌는 경계임을 이해한다.
2. **게임 캐릭터 성장 곡선**
   - 초반 성장, 후반 난이도, 최대 능력 제한을 만족하는 함수 모형을 설계한다.
   - 직선·이차·지수형 후보의 장단점과 정의역 밖 외삽 위험을 비교한다.
3. **롤러코스터 안전 곡선**
   - 통과점, 최대 높이, 경사 제한을 만족하는 그래프를 만들고 같은 조건의 여러 해를 비교한다.
   - 화면상 예쁜 곡선과 실제 물리적 안전을 동일시하지 않고 이 함수가 나타내는 것과 생략한 것을 밝힌다.

#### 원자 조립

1. **우주망원경의 원소 암호**
   - 미지 별의 방출선 패턴에서 가능한 원소를 찾고 전자 에너지 준위와 빛을 연결한다.
   - 보어식 표현이 스펙트럼 질문에는 유용하지만 전자의 실제 경로 그림은 아님을 확인한다.
2. **박물관 동위원소 사건**
   - 같은 원소인데 질량이 다른 시료들을 핵종 기호와 입자 수로 분류한다.
   - 원소의 정체, 질량수, 전하를 각각 결정하는 입자를 분리한다.
3. **외계 광물의 평균 원자량**
   - 지구와 동위원소 존재비가 다른 행성의 시료에서 평균 원자량을 맞히는 혼합비를 찾는다.
   - 평균값이 실제 원자 하나의 질량수와 같아야 한다는 오해를 반례로 다룬다.

#### 먹이사슬 생태계

1. **도시 공원의 사라진 곤충**
   - 살충, 꽃 감소, 조명, 포식자 변화 중 어떤 조합이 먹이망 전체에 영향을 주는지 비교한다.
   - 한 원인만 단정하지 않고 시간 지연과 여러 가능한 설명을 자료로 좁힌다.
2. **섬의 외래종 대응팀**
   - 외래 포식자를 제거할 때 예상치 못한 먹이망 반응과 장기 회복을 함께 살핀다.
   - 즉시 효과가 큰 정책과 복원력이 좋은 정책이 다를 수 있음을 비교한다.
3. **100년 생태 돔**
   - 제한된 외부 물질·에너지 조건에서 생산자, 소비자, 분해자가 유지되는 시스템을 설계한다.
   - 에너지는 흐르고 물질은 순환한다는 차이를 장기 그래프로 증명한다.

#### 달의 위상

1. **달 사진 촬영 계획**
   - 원하는 위상을 학교가 끝난 뒤 촬영하려면 언제 어느 방향을 봐야 하는지 정한다.
   - 모양, 태양 각거리, 출몰 시각, 하늘 경로를 하나의 관측 계획으로 연결한다.
2. **영화 속 달 오류 찾기**
   - 장면의 시각, 그림자 방향, 달 위치가 동시에 가능한지 시뮬레이션으로 재구성한다.
   - 단순 명칭 암기보다 공간 배치의 일관성을 검증한다.
3. **달 기지의 작업 달력**
   - 지구와 다른 낮·밤 주기를 가진 달 표면에서 태양광 작업과 통신 시간을 계획한다.
   - 지구에서 보는 위상과 달 표면의 조명 조건을 구분한다.

#### 산·염기

1. **탄산음료의 pH 숫자는 왜 생각보다 낮은가**
   - pH 숫자 차이를 수소 이온 농도비로 바꾸고 단순한 `한 단계 차이` 직관을 검증한다.
   - 실제 음료의 건강 효과를 판정하지 않고 로그 척도와 측정·완충의 과학에 집중한다.
2. **호수 복원 가상 회의**
   - 산성화된 가상 호수의 목표 pH를 맞추되 한 번에 과도하게 바꾸지 않는 투입 계획을 세운다.
   - 강산–강염기 단순 모형과 실제 자연수의 완충·생태 변수 차이를 명시한다.
3. **색 변화만으로 미지 용액 찾기**
   - 제한된 지시약과 관찰 횟수로 가능한 pH 범위를 가장 효율적으로 좁힌다.
   - 색이 정확한 pH 숫자를 알려 준다는 오해를 범위 추론 문제로 바꾼다.

#### 열과 열전달

1. **배달 음식이 식는 속도**
   - 용기 재료, 두께, 표면적, 빈 공간, 주변 온도를 바꿔 목표 시간의 온도를 유지한다.
   - `따뜻함을 넣어 둔다`는 표현 대신 에너지 전달 경로와 전달률을 추적한다.
2. **여름 교실의 자리별 체감 차이**
   - 창문 복사, 에어컨 대류, 벽 전도를 분리해 같은 공기 온도에서도 다른 열교환을 설명한다.
   - 실제 인체 쾌적성 전체를 예측하지 않는다는 모형 한계를 함께 제시한다.
3. **우주복의 열 관리**
   - 진공에서 대류가 사라질 때 햇빛 흡수와 복사 방출로 온도를 조절한다.
   - 표면 색, 방사율, 내부 열원, 차광을 조합해 안전 범위를 유지한다.

#### 빛·상·파동

1. **스마트폰 카메라가 가까운 물체에 초점을 못 맞추는 이유**
   - 물체거리, 렌즈 초점거리, 센서 위치를 바꿔 선명한 실상이 생기는 조건을 찾는다.
   - 디지털 필터가 아니라 실제 광학적 상 형성부터 설명한다.
2. **수영장 바닥이 얕아 보이는 이유**
   - 관측자 위치와 물의 굴절률을 바꿔 보이는 위치와 실제 위치를 비교한다.
   - 광선의 연장선으로 허상 위치를 재구성한다.
3. **콘서트장의 소리 사각지대**
   - 두 스피커의 진동수·위상·위치를 조절해 강해지는 곳과 약해지는 곳을 찾는다.
   - 실제 공연장 음향의 반사·흡음·다중 경로가 단순 간섭 모형에 추가되어야 함을 밝힌다.

#### 입자와 기체

1. **과자 봉지가 높은 산에서 부푸는 이유**
   - 외부 압력, 온도, 봉지 부피를 바꾸고 밀폐된 기체의 평형을 입자 충돌로 설명한다.
   - 입자 자체가 커져서 봉지가 부푼다는 오해를 직접 반박한다.
2. **뜨거운 자동차 타이어의 압력**
   - 부피가 거의 일정한 조건에서 온도와 압력의 관계를 조사한다.
   - 실제 타이어의 변형·누출·안전 기준은 단순 용기 모형 밖임을 명시한다.
3. **화성 탐사 풍선**
   - 낮은 외부 압력과 큰 온도 변화에서 목표 부피를 유지하는 초기 기체 조건을 설계한다.
   - 한 시점의 상태방정식뿐 아니라 낮–밤 변화와 재료 부피 제한을 함께 고려한다.

#### 화학 반응과 보존

1. **철이 녹슬면 왜 더 무거워질까**
   - 금속만 저울에 올린 계와 주변 산소까지 포함한 계를 비교한다.
   - 질량 보존이 `모든 물체의 질량은 언제나 그대로`라는 뜻이 아니라 계 경계와 관련됨을 이해한다.
2. **우주선 산소 생성 장치**
   - 제한된 반응물로 목표 기체를 만들고 남는 물질을 최소화한다.
   - 균형 반응식, 몰비, 제한 반응물을 생명유지 설계 문제에 사용한다.
3. **친환경 공정 심사**
   - 빠른 반응, 높은 생성량, 낮은 에너지 비용, 적은 잔류 반응물이 충돌하는 여러 공정을 비교한다.
   - 촉매가 최종 생성량과 반응 속도에 미치는 효과를 혼동하지 않게 한다.

#### 유전과 세포분열

1. **가상 생물의 무늬 연구소**
   - 실제 사람 형질 대신 날개 무늬·촉수 모양을 가진 가상 생물로 분리·조합·확률을 탐구한다.
   - 같은 부모 조합에서도 자손 결과가 매번 다른 이유를 학급 표본으로 확인한다.
2. **우성은 더 강한 형질인가**
   - 우성 형질의 집단 빈도를 낮게, 열성 형질의 빈도를 높게 설정해 반례를 만든다.
   - 우성, 흔함, 유리함, 건강함을 서로 다른 개념으로 분리한다.
3. **우주 농장의 종자 계획**
   - 제한된 세대와 개체 수에서 목표 가상 형질을 얻을 가능성을 높이되 결과를 보장하지 못함을 설명한다.
   - 멘델 모형과 환경·다유전자 형질의 한계를 안전한 가상 데이터로 다룬다.

#### 계절과 태양 고도

1. **학교 태양광 패널의 계절별 발전량**
   - 위도, 계절, 패널 경사·방향을 조작해 하루 누적 입사 에너지를 비교한다.
   - 태양 고도 하나가 아니라 낮 길이와 입사각을 함께 사용한다.
2. **왜 하지가 가장 더운 날은 아닐까**
   - 일사량 최대 시점과 지표 온도 최대 시점의 지연을 열용량 모형으로 비교한다.
   - 천문학적 원인과 실제 날씨·기후 변수를 구분한다.
3. **외계 행성 정착지 선정**
   - 자전축 기울기와 위도가 다른 행성에서 낮 길이와 계절 에너지 변동이 지나치지 않은 지역을 찾는다.
   - 평균 조건만 좋고 계절 극값이 위험한 설계를 학급 분포에서 걸러 낸다.

### 7.4 피해야 할 흥미 요소

- 원리와 무관한 클릭 횟수, 출석 보상, 속도 순위로 주의를 끌지 않는다.
- 스포츠·우주 배경만 씌우고 실제 조작 변수와 계산은 기존 예제 그대로인 `스킨 교체`를 응용 사례로 세지 않는다.
- 한 번 운 좋게 성공한 결과를 실력이나 개념 이해로 판정하지 않는다.
- 학생을 이름·점수·성적 순으로 공개 비교하지 않는다.
- 실제 위험 행동, 의약적 판단, 환경 정책의 정답을 단순 모형 하나로 지시하지 않는다.
- 영화적 연출을 위해 힘의 방향, 입자 크기, 천체 거리, 시간축을 바꾸면 과장 배율과 이유를 즉시 표시한다.
- 이야기를 이해하느라 교과 개념을 놓치지 않도록 도입 장면은 짧게 하고 실험 질문·변수·증거를 화면 중심에 둔다.

## 8. 주제 간 확장 수업

각 실험실을 단품으로 판매하더라도 동일한 데이터 계약을 사용하면 두 주제를 연결한 60~100분 프로젝트를 만들 수 있다.

| 연결 주제 | 공동 프로젝트 | 합치는 데이터 |
| --- | --- | --- |
| 운동 + 행성 중력 | 다른 행성의 구조 물자 투하 | `g`, 발사 조건, 착지 오차 |
| 함수 + 운동 | 궤적 데이터를 이차함수로 모델링 | 시간·위치, 계수, 잔차 |
| 확률 + 유전 | 한 가족의 결과와 집단 확률 비교 | 이론확률, 표본 크기, 관측비율 |
| 열 + 기체 | 가열·압축 경로와 에너지 분석 | `P-V-T`, 전달 에너지 |
| 원자 + 화학 반응 | 원자 보존에서 반응식 구성 | 원소별 원자수, 계수, 질량 |
| 화학 반응 + 생태계 | 연소·광합성과 탄소 저장고 추적 | 탄소 원자, 에너지, 저장량 |
| 달 위상 + 조석 | 달 위치와 관측 조차의 주기 연결 | 공전각, 위상, 조차, 시각 |
| 계절 + 생태계 | 일사 계절성이 개체군에 미치는 영향 | 누적에너지, 성장률, 개체수 |
| 빛 + 열 | 표면 색·방사·흡수와 온도 변화 | 파장·흡수율, 온도, 에너지 |

교사는 한 주제의 결과를 다음 실험의 초기 조건으로 보낼 수 있다. 연결 시 원 단위와 모델 가정을 보여 주고, 서로 다른 단순화 모형을 실제 세계의 완전한 연쇄 예측처럼 합치지 않는다.

## 9. 비식별 계정·실험 데이터 운용 사양

### 9.1 저장하는 것

- 기관·학급·수업·미션 ID
- `학생01`, `1반-03` 같은 수업용 좌석 ID
- 로그인 검증을 위한 접근 PIN 해시
- 예측, 조작 조건, 실행 결과, 선택한 대표 실행, 과학적 설명
- 학급 통계를 만들기 위한 모델 버전·난수 시드·실행 시각

### 9.2 저장하지 않는 것

- 이름, 이메일, 전화번호, 생년월일, 주소, 실제 학번, 보호자 정보
- 실제 이름과 좌석 ID의 대응표
- 학생 사진·음성·위치·연락처·기기 연락처
- 광고 식별자, 교과 활동과 무관한 행동 프로필
- 실제 가족의 유전·건강·생활 정보

### 9.3 운영 규칙

1. 감독자는 학생 수만 입력해 좌석 계정을 일괄 생성한다.
2. 좌석 ID 규칙은 자유롭게 정할 수 있지만 개인 이름 입력란은 제공하지 않는다.
3. 모든 통계·보고서·CSV는 좌석 ID 기준으로 생성한다.
4. 학급 삭제 시 좌석 계정과 연결된 실행을 함께 삭제하거나 완전 익명 학급 집계만 남긴다.
5. 기관별 데이터와 접근 권한을 분리하고 접근 PIN은 원문이 아닌 해시로 저장한다.
6. 시스템 관리자의 지원 접근, 감독자의 생성·초기화·삭제·내보내기는 감사 로그에 남긴다.
7. 학생이 과학적 설명란에 신원정보를 입력하도록 유도하지 않으며 교사는 해당 응답을 즉시 지울 수 있다.

## 10. 구현 우선순위

### 10.1 1단계 — 개인 실험의 완성

- 공통 실행 데이터, 변수 잠금, A/B 저장, 예측, 학생 설명, 모델 버전·시드 재현.
- 조석·운동·전기회로에서 먼저 검증한다.

### 10.2 2단계 — 교사 수업 운영

- 감독자 계정, 학급, 학생 좌석, 수업 코드, 단계 공개, 미션 배정, 결과 가리기.
- 학기형 좌석 계정과 세션형 좌석 계정을 함께 제공한다.

### 10.3 3단계 — 비교 가능한 학급 통계

- 동일 조건 표본 묶기, 개인점 강조, 분포·산점도·A/B 변화량, 대표 실행 핀, CSV.
- 표본 수 문턱, 실행 가중치, 다른 모델 혼합 금지 규칙을 자동 테스트한다.

### 10.4 4단계 — 창의 미션과 주제 연결

- 제약조건 편집기, 모둠별 변수 구간 배정, 설계 해 공간, 주제 간 결과 전달.
- 점수 경쟁보다 반례·재현·증거·한계 루브릭을 먼저 완성한다.

### 10.5 5단계 — 기관 운영

- 기관 테넌트, 감독자 좌석, 학생 좌석 풀, 공동 교사, 감사 로그, 보존·삭제, 교사용 SSO·LMS 연동.
- 운영 편의보다 권한 분리와 학생 데이터 최소화를 먼저 검수한다.

## 11. 완료 정의

주제 하나가 `60분 판매 수업 가능` 상태가 되려면 다음을 모두 만족해야 한다.

- 생활 미스터리, 기술·사회 문제, 미래·상상 설계를 포함한 원리 기반 적용 사례가 최소 3개 있다.
- 적용 사례마다 도입 장면, 성공 조건, 첫 예측, 기본 실험, 응용 설계, 학급 비교, 실제 모형 한계가 연결된다.
- 이야기 배경을 제거해도 학생이 무엇을 조작하고 어떤 증거로 판단할지가 명확하며, 핵심 원리 없이는 미션을 안정적으로 해결할 수 없다.
- 핵심 원인 변수 3개 이상과 구조 또는 사건 조작 1개 이상이 있다.
- 한 차시에서 최소 8회의 의미 있는 실행을 만드는 통제 실험과 변형 미션이 있다.
- 기초 인과·정량 관계·복합 조건·모형 비교·반례·최적화·학급 통계·전이를 포함한 실험 포트폴리오가 최소 10개 있다.
- M1 현상 이해, M2 관계 탐구, H1 정량 모델, H2 연구 확장의 네 깊이가 같은 장면과 계산 엔진으로 연결된다.
- 핵심 개념마다 한 문장 원리, 변수 사전, 식 해부, 단위 검산, 대표 예제, 오개념 반례, 실제 적용, 모형 한계가 있다.
- 식의 각 항과 화면 대상·벡터·그래프가 상호 강조되며 시뮬레이션 값과 계산값을 대조할 수 있다.
- 결정론적 결과, 무작위 표본, 범주형 판단 중 적합한 학급 통계가 정의돼 있다.
- 학생이 학급 분포에서 자기 결과를 확인하고 차이의 원인을 필터링할 수 있다.
- 정답 하나가 아닌 해 공간 또는 반례를 탐색하는 창의 미션이 3개 이상 있다.
- 60분 수업안에 예측, A/B 비교, 학급 집계, 주장–증거–한계, 출구 문항이 모두 포함된다.
- 교사는 변수 공개·잠금·범위, 결과 공개, 모둠 조건, 집계 화면을 수업 전에 설정할 수 있다.
- 학기형 좌석 계정 없이도 세션형 `학생1~학생N` 계정으로 같은 수업을 운영할 수 있다.
- 모델 버전, 단위, 고정 조건이 다른 실행이 학급 통계에 잘못 합쳐지지 않는다.
- 과목 전문가의 과학·수학 검수와 중·고 현장 교사의 설명 난이도·수업성 검수를 각각 통과한다.
- 이름·이메일·명단을 받지 않는지 확인하는 비식별 계정 감사와 접근성·모바일·프로젝터·학교 네트워크 검수를 통과한다.
