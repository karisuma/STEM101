# 역사적 재현형 수학·과학 탐구 확장 계획

## 1. 목적

역사적 사례를 인물 소개나 읽을거리로 소비하지 않고, 학생이 당시 사람이 풀어야 했던 문제를 당시의 관측 조건과 도구로 다시 풀어보는 시뮬레이션으로 만든다.

모든 역사 재현 모드는 다음 질문을 중심으로 설계한다.

1. 직접 가거나 볼 수 없는 크기와 힘을 무엇으로 추론했는가?
2. 실제로 측정한 값과 가정한 값은 무엇인가?
3. 같은 자료를 설명하는 경쟁 모형은 무엇이었는가?
4. 오차는 계산이 아니라 어느 가정과 측정에서 커졌는가?
5. 현대 장비를 쓰지 않고 당시 조건에서 더 나은 결과를 만들 수 있는가?

역사적 사례는 현재 카탈로그의 완성 실험 수에 곧바로 추가하지 않는다. 기존 실험실 안의 `역사 재현 모드` 또는 충분한 조작 깊이가 있는 독립 실험실로 구현·검증한 뒤 완료 항목으로 승격한다.

## 2. 공통 인터페이스

### 학생 화면

- `당시의 문제`: 그 시대에 실제로 알 수 없었던 값을 한 문장으로 제시한다.
- `사용 가능한 도구`: 막대, 각도기, 물시계, 저울, 망원경 등 시대에 맞는 도구만 먼저 제공한다.
- `관측 기록`: 원자료, 교육용 단순화 자료, 오차가 포함된 합성 자료를 구분한다.
- `가정 장부`: 평행한 햇빛, 구형 지구, 닫힌 용기처럼 계산에 필요한 가정을 켜고 끈다.
- `계산 작업대`: 장면의 길이·각도·시간을 식, 표, 그래프와 연결한다.
- `오차 예산`: 각 측정과 가정이 최종값의 오차에 얼마나 기여했는지 보여준다.
- `현대값 공개`: 제출 전에는 숨기고, 제출 뒤 역사적 추정값·현대값·학급 분포를 비교한다.
- `사료 렌즈`: 기록으로 확인되는 사실, 후대의 재구성, 널리 알려진 일화를 서로 다른 표시로 구분한다.

### 교사 화면

- 역사적 도구만 허용하거나 현대 도구를 단계적으로 해제한다.
- 실제 사료 기반 데이터, 잡음이 추가된 데이터, 개념 입문용 데이터 중 하나를 배정한다.
- 허용 오차, 측정 횟수, 협력 좌석 수, 가정 공개 여부를 설정한다.
- 학급의 추정값 분포, 상대오차, 선택한 모형, 가정 위반, 재측정 전략을 비교한다.
- 단순히 정답에 가까운 팀이 아니라 `근거를 남긴 팀`, `오차 원인을 가장 잘 설명한 팀`, `반례를 찾은 팀`을 별도로 볼 수 있다.

### 역사적 신뢰도 표시

- `A — 문헌·유물로 직접 확인`: 원문, 관측표, 실험 기구 또는 상세 기록이 남아 있다.
- `B — 근거 있는 재구성`: 방법은 기록되어 있으나 정확한 장치·수치·절차 일부가 불확실하다.
- `C — 일화·전승`: 개념 도입이나 사실 검증 미션으로만 사용하고 실제 사건처럼 단정하지 않는다.

예를 들어 갈릴레이가 경사면으로 낙하 법칙을 논한 사실과 특정 종 장치를 정확히 사용했다는 주장은 같은 확실도로 다루지 않는다. 아르키메데스의 왕관 이야기도 부력·밀도 개념의 도입용 전승으로 표시하고, 검증 가능한 정수압 원리와 분리한다.

## 5. P2 — 심화·선택 수업용 사례

- `아리스타르코스의 달·태양 크기 추론`: 반달일 때의 각도, 월식 그림자, 매우 작은 각도 오차와 식별 가능성을 다룬다.
- `캐번디시 비틀림 저울`: 작은 중력, 역제곱 법칙, 비틀림 상수, 진동 감쇠를 조작한다. 역사적으로는 ‘지구의 밀도 측정’이라는 목표를 전면에 두고, 현대의 중력상수 표현과 구분한다.
- `볼타 전지와 옴의 측정`: 금속 조합, 전지 수, 내부저항, 계기 부하를 조작하여 이상적 전압원 오개념을 교정한다.
- `보일의 J자관`: 갇힌 기체 부피, 수은주 높이, 대기압, 온도를 조작하여 압력-부피 관계와 실험 조건을 찾는다.
- `갈릴레이·뉴턴·현대 조석 모형 비교`: 동일한 항구 자료에 서로 다른 모형을 맞추고 각 모형이 설명하지 못하는 현상을 찾는다.
- `로트카·볼테라와 어획 기록`: 포식자-피식자 주기와 실제 자료의 불일치를 통해 모형의 유용성과 한계를 함께 판단한다.
- `소렌센의 pH 척도`: 수소 이온 농도의 큰 범위를 로그 척도로 바꾸고 측정 분해능과 지시약 구간을 비교한다.
- `네이피어의 로그와 항해 계산`: 곱셈을 덧셈으로 바꾸는 표의 원리, 보간 오차, 유효숫자를 다룬다.

## 7. 신규 수학 13개와의 결합

- 수체계·근삿값: 바빌로니아식 제곱근 근사, 유휘·아르키메데스의 원주율 구간
- 대수 타일·인수분해: 알콰리즈미의 기하적 완전제곱 재구성
- 방정식·부등식 균형: 고대 문제 풀이법과 현대 기호식의 조작 수 비교
- 작도·합동·닮음: 유클리드식 자·컴퍼스 제한과 불가능 작도 탐색
- 피타고라스·삼각비 측량: 에라토스테네스와 알비루니의 지구 측정
- 공간도형·단면: 아르키메데스의 구와 원기둥 관계
- 좌표기하·자취: 항해·천문 관측점을 좌표 모형으로 바꾸기
- 지수·로그: 네이피어의 계산표와 현대 로그 축 비교
- 삼각함수·주기: 해시계·천체 주기·조석 성분 합성
- 수열·재귀·프랙탈: 다각형 배가에 따른 원주율 수렴, 피보나치 모형의 현실 한계
- 벡터·행렬 변환: 지도·천구 좌표계 전환과 변환 순서
- 미분·최적화: 갈릴레이 운동 자료의 순간변화율, 관측 오차가 접선에 미치는 영향
- 적분·누적량: 거리·강우·유량의 누적과 역사 관측 기록의 결측 보정

## 8. 60분 수업 구조

1. `0–7분 — 문제 봉인`: 현대 정답을 숨긴 채 당시의 질문과 도구만 공개한다.
2. `7–15분 — 가정 선택`: 학생이 필요한 가정을 선택하고 결과 방향을 예측한다.
3. `15–30분 — 재현 실험`: 측정하고 계산하며 시행 기록을 남긴다.
4. `30–42분 — 자유 샌드박스`: 도구를 재배치하거나 새로운 관측 전략을 만든다.
5. `42–52분 — 학급 증거 합치기`: 여러 좌석의 값을 모아 분포·잔차·오차 예산을 비교한다.
6. `52–60분 — 역사와 현대 비교`: 역사적 값, 현대값, 사료의 불확실성, 모형의 한계를 정리한다.

## 9. 한 시간 이후의 연속 수업 변형

- `학교 간 지구 측정`: 서로 다른 위도의 두 학급이 같은 날짜의 태양고도 자료를 교환한다.
- `시대 제한 대회`: 고대 도구만, 17세기 도구까지, 현대 센서 허용의 세 조건으로 정밀도를 비교한다.
- `틀린 모형 토너먼트`: 여러 역사 모형이 어떤 관측까지는 맞고 어디에서 무너지는지 평가한다.
- `측정 표준 만들기`: 각 팀의 단위와 도구를 교환해 재현성을 검사한 뒤 공통 표준을 협상한다.
- `사료 탐정`: 설명 카드 중 과장·후대 전승·문헌 확인 사실을 근거와 함께 분류한다.
- `오차 최소화 설계`: 센서 성능을 올리지 않고 배치·반복·자료 결합만으로 추정 오차를 줄인다.

## 10. 학급 통계

- 추정값의 히스토그램, 중앙값, 사분위 범위, 실제값 대비 상대오차
- 측정 횟수와 오차의 관계, 관측 간격과 모형 판별력의 관계
- 학생이 선택한 가정·모형별 결과 분포
- 각 팀이 지목한 주된 오차 원인의 빈도와 실제 민감도 비교
- 같은 정확도에 도달하기까지 사용한 관측 수·조작 수·시간
- 개별 좌석은 별칭으로만 표시하고 개인정보는 수집하지 않는다.

## 12. 사료·사실 검증 원칙과 기초 자료

- 에라토스테네스 수업은 두 지점의 막대 그림자와 거리를 이용하는 방법을 재현하되, 정확한 스타디온 길이와 세부 절차가 불확실하다는 점을 함께 제시한다. [NASA/JPL 수업 자료](https://www.nasa.gov/wp-content/uploads/2009/07/136202main_measure.of_.the_.universe.pdf)
- 알비루니 실험은 산 높이와 수평선 하강각을 이용한 방법, 대기 굴절 무시라는 가정을 명시한다. [MacTutor 자료](https://mathshistory.st-andrews.ac.uk/Strick/al-biruni.pdf)
- 갈릴레이 경사면은 문헌에 기술된 방법과 후대 박물관 장치의 구체적 형상을 구분한다. [Museo Galileo](https://www.museogalileo.it/it/galileo/strumenti.html)
- 케플러 모드는 티코의 화성 관측과 원 궤도 모형의 실패를 중심에 둔다. [NASA Kepler’s Laws](https://science.nasa.gov/solar-system/orbits-and-keplers-laws/)
- 뢰머 모드는 이오의 식 시각이 지구-목성 거리 변화에 따라 누적 지연되는 자료를 사용한다. [American Museum of Natural History](https://www.amnh.org/learn-teach/curriculum-collections/cosmic-horizons-book/ole-roemer-speed-of-light)
- 멘델 모드는 3:1을 매번 나오는 값이 아니라 표본 분포의 기대 비율로 다룬다. [National Human Genome Research Institute](https://www.genome.gov/25520230/online-education-kit-1865-mendels-peas)
- 존 스노 모드는 단순한 펌프 주변 점 지도와 급수회사별 사망률 비교를 구분한다. [CDC 역학 수업 자료](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson1/section2.html)
- 파스퇴르 모드는 백조목 플라스크의 대조 조건과 먼지·미생물 차단을 중심에 둔다. [Institut Pasteur](https://www.pasteur.fr/en/institut-pasteur/history/middle-years-1862-1877?language=fr)
- 러더퍼드 모드는 가이거·마스든의 산란 측정과 러더퍼드의 1911년 해석을 구분한다. [Nobel Prize 자료](https://www.nobelprize.org/prizes/physics/1990/9592-the-nobel-prize-in-physics-1990/)
- 앙부일구는 현존 유물과 국가유산 자료를 바탕으로 구조를 재현한다. [국가유산포털](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?ccbaCpno=1121108450000&pageNo=1_1_1_0)
- 측우기는 용기만이 아니라 단위·관측 시각·중앙 보고를 포함한 측정 제도로 다룬다. [우리역사넷](https://contents.history.go.kr/front/km/view.do?levelId=km_015_0030_0040_0010), [기상자료개방포털](https://data.kma.go.kr/data/history/htmtHistoryList.do)
- 거중기는 도르래 수만 단순화하지 않고 실제 줄 경로·마찰·당기는 거리와 함께 다룬다. [사료로 본 한국사](https://contents.history.go.kr/front/hm/print.do?levelId=hm_112_0050&tabId=01&treeId=010604&whereStr=)

역사적 인물의 국적·문명·시대는 장식용 배경이 아니라 서로 다른 측정 도구와 지식 교류를 이해하는 맥락으로 사용한다. 한 명의 천재가 단번에 정답을 만들었다는 서사는 피하고, 관측자·기술자·자료 제공자와 후대 검증자의 역할을 함께 표시한다.
