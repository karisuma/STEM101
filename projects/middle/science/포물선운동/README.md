# 포물선 운동 실험

학생과 선생님이 발사 벡터와 환경 조건을 직접 바꾸고, 반복 실험에서 쌓인 데이터로 입력값과 결과값의 관계를 추론하는 2D·3D 시뮬레이션입니다.

## 현재 구현 범위

- 발사점에서 클릭·터치 후 드래그하여 발사 각도와 초기 속력을 동시에 조절
- 발사 높이 `0–5 m` 조절
- 중력, 바람, 공기저항, 공기밀도를 각각 `0–5 단계`로 조절
- 입력 단계와 실제 물리값을 함께 표시
- 착지 시 실험 조건과 결과를 자동 기록
- 기록을 브라우저에 계속 저장하고 새로고침 후 복원
- 모든 기록을 CSV로 내려받기
- 발사각, 초기 속력, 발사 높이, 중력, 바람, 공기저항, 공기밀도, 비행 거리, 최대 높이, 비행 시간, 착지 속력을 X·Y·Z축에 자유롭게 배치
- 2D 산점도와 상관계수, 드래그 회전이 가능한 3D 관계 그래프
- 전체 실험 기록을 접근 가능한 HTML 표로 확인

## 추천 실험

1. 공기저항과 바람을 0으로 두고 발사각만 바꾸어 비행 거리를 비교합니다.
2. 발사각을 고정하고 초기 속력을 바꾸어 최대 높이와 비행 시간을 비교합니다.
3. 같은 발사 벡터에서 중력 단계만 바꾸어 세 결과값이 어떻게 달라지는지 확인합니다.
4. 공기저항을 켠 뒤 공기밀도와 바람을 각각 바꾸어 단독 효과와 결합 효과를 비교합니다.
5. 2D 그래프에서 한 입력과 한 결과를 비교한 뒤, 3D 그래프에서 두 입력과 한 결과를 함께 살펴봅니다.

상관계수는 현재 기록의 직선적인 경향을 요약할 뿐 원인을 증명하지 않습니다. 원인을 확인하려면 한 번에 한 조건만 바꾸어 반복 실험해야 합니다.

## 물리 모형

- 시간 간격 `0.02초`의 수치 적분을 사용합니다.
- 공기저항은 상대 속도의 제곱, 저항 계수, 공기밀도에 비례하는 단순 모형입니다.
- 공기저항 또는 공기밀도가 0이면 바람도 궤적에 영향을 주지 않습니다.
- 실제 공의 회전, 모양, 난류와 고도에 따른 공기밀도 변화는 포함하지 않습니다.

## 실행과 배포용 빌드

`projectile-lab` 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

정적 배포 파일은 `../projectile-lab-static/`에 생성됩니다.

```sh
npm run build
```
