# STEM101 판매용 중·고등 디지털 실험실 세부 기획

## 0. 문서의 지위

이 문서는 STEM101을 학생의 바이브코딩 결과물 모음이 아니라, **학교와 교사가 구매하여 수업에 바로 사용하는 완성형 웹 기반 디지털 교구**로 전환하기 위한 제품 기획서다. 기존 `docs/ideas.md`의 주제 목록은 이어받되, 학생이 제품을 제작한다는 전제는 이어받지 않는다.

각 주제의 조작 가능한 요소, 60분 수업 흐름, 개인·학급 통계, 창의 미션, 시스템 관리자–감독자–학생 계정과 좌석 사양은 `docs/commercial-simulation-interaction-classroom-spec.md`에서 별도로 정의한다.

제품의 핵심 약속은 다음 한 문장으로 정리한다.

> 전문적인 수학·과학 내용을 현상에서 출발해 이해시키고, 학생이 변수를 통제한 여러 실험으로 원리·수치·그래프·식을 스스로 연결하게 하는 디지털 실험실.

주 사용자는 중학생과 고등학생이며, 구매자와 수업 운영자는 과학·수학 교사와 학교다. 모든 실험실은 중학생도 첫 장면에서 현상을 읽을 수 있어야 하고, 고등학생은 같은 화면에서 정량 모델과 식까지 탐구할 수 있어야 한다.

### 0.1 교육과정·오개념 재검토 결론

이 문서의 주제 목록은 2022 개정 국가교육과정의 중학교 내용 요소와 고등학교 공통·선택과목 구조, 그리고 학생 오개념 연구를 기준으로 다시 판정했다. 학교마다 교과서, 단원 순서, 자유학기·학교자율시간, 고교 선택과목 편성이 다르므로 `모든 학교의 같은 학년·같은 차시`에 맞는다고 주장하지 않는다. 대신 각 실험실에 다음 세 가지 라벨을 붙여 판매·수업 범위를 명확히 한다.

**2026학년도는 교육과정 전환기다.** 현행 고시에 따라 2022 개정 교육과정은 2026년 중·고 1~2학년에 적용되고, 중·고 3학년 적용은 2027년 3월부터다. 따라서 2026년에 학교에 판매하는 자료는 2022 개정 매핑만 제시해서는 안 되며, 3학년용 미션에는 2015 개정 교육과정 매핑을 함께 제공해야 한다. 2027년 이후에는 2015 매핑을 `구 교육과정 아카이브`로 이동한다.

- **중핵:** 중학교 1~3학년군의 내용 요소를 직접 다룬다.
- **고핵:** 고등학교 공통 또는 일반·진로 선택과목에서 직접 다룬다.
- **연계:** 선수 개념을 복습하거나 다음 학교급의 개념을 직관적으로 여는 심화·융합 자료다.

주제 선정은 다음 네 축으로 판단한다.

| 판단 축 | 확인 질문 | 통과 기준 |
| --- | --- | --- |
| 교육과정 중요도 | 국가교육과정의 핵심 아이디어·내용 요소에 직접 포함되는가? | 단원명 유사성이 아니라 학생이 설명해야 할 관계가 일치한다. |
| 오개념 위험 | 직관만으로 잘못 이해하기 쉽고 수업 뒤에도 오류가 남는가? | 연구·개념검사 또는 현장 검토에서 반복되는 오류가 2개 이상 있다. |
| 시뮬레이션 이점 | 정지 그림이나 설명보다 조작·시간 변화·관점 전환이 유리한가? | 학생이 변수를 통제하고 반례를 만들어 자기 예측을 검증할 수 있다. |
| 수업 도입성 | 교사가 한 차시에 평가 가능한 탐구로 운영할 수 있는가? | 성취기준, 선수 개념, 10/25/50분 수업안, 산출물이 연결된다. |

### 0.3 빠져 있던 핵심 주제

초기 목록에는 중학교 과학의 큰 축인 `열`, `빛과 파동`, `입자 운동·기체 법칙`, `화학 반응의 규칙성`, `유전`, `계절 변화`가 빠져 있었다. 이 주제들은 교육과정 직접성이 높고, 학생의 직관이 자주 실패하며, 동적·다중 표상 시뮬레이션의 장점도 크다. 따라서 4.11~4.16에 신규 실험실로 추가한다.

특히 다음 세 주제는 기존 후순위 주제보다 먼저 개발할 가치가 있다.

1. **열과 열전달:** 열과 온도, 열평형, 전도·대류·복사, 비열을 한 모델 안에서 구분한다.
2. **입자와 기체:** 거시적 압력·온도·부피를 미시적 충돌·속도·입자 수와 연결한다.
3. **빛·상·파동:** 눈으로 보이는 결과와 광선 경로, 거울·렌즈·파동 표현을 연결한다.

## 1. 조석 시뮬레이션에서 반드시 계승할 것

조석 시뮬레이션의 디테일은 3D 표현 자체보다 **한 현상을 여러 관점과 여러 정확도 수준으로 교차 검증하게 하는 구조**에 있다.

### 1.1 제품 철학

1. **장면이 먼저다.** 긴 소개보다 움직이는 현상과 핵심 조작이 첫 화면의 대부분을 차지한다.
2. **관점을 바꿀 수 있다.** 조석의 `지구 집중/천체 보기`, `지구 중심/태양 중심`처럼, 같은 현상을 서로 다른 기준계·표현·모형으로 보게 한다.
3. **학습용 표현과 실제 모델을 구분한다.** 보이지 않는 차이는 과장할 수 있지만 배율, 이유, 생략한 조건을 바로 표시한다.
4. **원인과 결과가 붙어 있다.** 변수를 움직이면 장면, 현재 수치, 그래프, 설명이 동시에 갱신된다.
5. **비교가 기억에 의존하지 않는다.** 이전 실험을 궤적·윤곽·표·그래프로 고정해 현재 실험과 직접 비교한다.
6. **수치가 장식이 아니다.** 단위, 기준값, 상대값의 정의를 밝히고 그래프와 식으로 같은 결과를 확인한다.
7. **모형의 정직함을 유지한다.** 실제 예측 도구인지 개념 모델인지, 어떤 변수를 생략했는지 명시한다.
8. **관측 장비처럼 보인다.** 넓은 실험 장면, 얇은 구분선, 각진 제어, 고정폭 수치, 절제된 두 색을 쓴다.

### 1.2 모든 실험실의 공통 화면 구조

```text
짧은 제목 · 실행 상태 · 교사용 도구
관점/표현/난이도 전환 툴바
┌──────────────────────────────┬────────────┐
│                              │ 현재 상태  │
│       가장 큰 실험 장면       │ 핵심 변수  │
│                              │ 조건 잠금  │
├──────────────────────────────┴────────────┤
│ 재생 · 시간 · 속도 · 한 단계 · 초기화     │
├───────────────────────────────────────────┤
│ 예측 → 실험 A/B 기록 → 그래프·표·식 검증 │
├───────────────────────────────────────────┤
│ 원리 설명 · 오개념 확인 · 모형의 한계      │
└───────────────────────────────────────────┘
```

- **상단 헤더:** 주제명, 현재 실행 상태, 전체 초기화, 교사용 모드 진입.
- **관점 툴바:** 공간 관점, 표현 모형, 중·고 심화 수준을 한곳에서 전환한다.
- **주 장면:** 데스크톱 첫 화면 폭의 약 70%, 모바일 첫 순서를 차지한다.
- **전송 제어:** 재생/정지/한 단계/속도/시간축/다시 보기를 영상 제어처럼 일관되게 둔다.
- **제어 레일:** 한 번에 바꿀 원인 1~3개를 우선 노출하고 나머지는 `심화 조건`으로 연다.
- **현재 판독:** 현상을 설명하는 핵심 결과 3~5개만 큰 숫자로 보여 준다.
- **증거 영역:** 실험 A/B, 고정된 이전 실행, 그래프, 표, 식을 연결한다.
- **모형 설명:** 적용 조건과 한계를 결과 가까이에 짧게 표시하고, 자세한 기술 설명은 별도 패널로 연다.

### 1.3 한 화면 안의 깊이 사다리

별개의 쉬운 버전과 어려운 버전을 만들지 않는다. 같은 계산 엔진과 같은 현상을 세 층으로 연다.

| 층 | 학생이 보는 것 | 학생이 하는 일 | 대표 표현 |
| --- | --- | --- | --- |
| 관찰 | 변화와 방향 | 예상하고 움직여 본다 | 장면, 짧은 질문, 상태 언어 |
| 측정 | 크기와 관계 | 변수를 통제하고 A/B 비교한다 | 단위가 있는 수치, 표, 그래프 |
| 모델 | 법칙과 한계 | 식으로 설명하고 모델을 비판한다 | 식, 성분 분해, 잔차, 가정 |

교사는 수업 전에 시작 층을 정하고, 수업 중 다음 층을 열 수 있다. 중학생에게 식을 감추는 것이 아니라 관찰과 측정 뒤에 의미 있게 등장시키고, 고등학생에게는 식의 각 항을 화면의 대상·화살표·그래프와 직접 연결한다.

### 1.4 공통 탐구 루프

모든 주제는 다음 상태를 실제 제품 상태로 구현한다.

1. **질문:** 오늘 확인할 인과 관계를 한 문장으로 제시한다.
2. **예측:** 실행 전에 방향·순서·대략값 중 하나를 선택하거나 표시한다.
3. **통제:** 미션이 요구하는 변수 외에는 교사가 잠글 수 있다.
4. **실행:** 장면이 변하고 현재 판독값이 즉시 갱신된다.
5. **고정:** 의미 있는 실행을 A 또는 B로 저장한다.
6. **비교:** 차이값, 겹친 궤적, 동일 축 그래프, 조건표를 함께 본다.
7. **설명:** 학생이 `무엇을 바꾸었고 → 무엇이 달라졌으며 → 왜 그런지` 한 문장으로 정리한다.
8. **한계:** 이 결과가 성립하는 조건과 실제 현상에서 달라질 이유를 고른다.

#### 1.4.1 자유 제작 샌드박스 원칙

구성·연결·분해 행위 자체가 개념인 주제는 슬라이더형 `자유 실험`과 별도로 **자유 제작 샌드박스**를 제공한다. 정답 회로를 고르는 문제가 아니라 학생이 부품을 놓고, 연결하고, 실패한 구성을 관찰한 뒤 고치는 실험 환경이다.

- 공통 도구: 부품 팔레트, 드래그 배치, 방향성 연결, 90° 회전, 선택 삭제, 전체 초기화, 구성 유효성 판정.
- 실패 보존: 열린 회로, 고립된 종, 불가능한 가계, 초점이 맞지 않는 광학계도 즉시 지우지 않고 결과가 왜 성립하지 않는지 표시한다.
- 증거 연결: 자유 구성의 부품·연결 상태도 A/B 시행과 학급 표본에 함께 저장한다.
- 교사 통제: 사용할 부품 종류·최대 수·기본 배치·연결 규칙을 미션별로 제한하거나 전부 개방할 수 있다.
- 구현 대상: 도르래 장치, 전기회로, 광학 벤치, 원자 조립, 반응기 혼합, 먹이그물, 가계도, 합성함수 기계.
- 확장 대상: 학생이 만든 구성에서 자동 계산되는 결과뿐 아니라 `왜 작동하지 않았는가`를 분류하는 실패 통계도 교사 화면에 제공한다.

샌드박스는 사실적인 그림 장식이 아니라 **구성 상태 → 지배 원리 → 측정값 → 실패 원인**을 투명하게 이어 주는 모형이어야 한다. 부품 위치가 물리량인 광학 벤치에서는 위치를 계산에 사용하고, 위치가 개념과 무관한 원자 조립에서는 개수 장부와 영역 구분만 판정에 사용한다.

### 1.5 판매 상품으로서의 공통 구성품

각 주제는 웹 시뮬레이터만 납품하지 않고 다음을 한 제품 단위로 묶는다.

- 교사용 10분 시연안, 25분 탐구안, 50분 실험안
- 중학교용 탐구 카드와 고등학교용 정량 분석 카드
- 교사용 발문, 예상 반응, 대표 오개념, 후속 질문
- 학생용 기록지 PDF와 화면 내 디지털 기록지
- 실험별 정답이 아니라 **판단 근거와 비교 기준**을 담은 해설
- 교육과정·단원·권장 학년·선수 개념 매핑표
- 과학·수학 모형 기술서, 참고 상수, 단위, 계산식, 한계
- 접근성·브라우저·기기 지원표와 버전 변경 기록

학생 계정 없이 한 기기에서 바로 쓰는 `교실 시연/모둠 실험`을 기본 상품으로 하고, 학교 라이선스에서는 선택적으로 참여 코드, 익명 예측 집계, 결과 공유를 제공한다. 학생 실명·학번은 기본 수집 항목에서 제외한다.

## 2. 공통 과학·수학 품질 기준

### 2.1 계산과 화면의 분리

- 계산 엔진은 UI와 분리된 순수 함수 또는 독립 모듈로 작성한다.
- 입력, 출력, 단위, 유효 범위, 기본값, 가정을 주제별 기술서에 명시한다.
- 학습용 과장 배율은 물리량을 바꾸지 않고 렌더링에만 적용한다.
- 이론해가 있는 경우 수치 계산 결과와 대조하는 기준 테스트를 둔다.
- 난수를 쓰는 실험은 시드 재현과 완전 무작위 실행을 모두 지원한다.
- 그래프는 색뿐 아니라 선 종류, 마커, 직접 라벨로 실험을 구분한다.

### 2.2 공통 실험 기록 형식

모든 실험 기록은 다음 최소 필드를 가진다.

```text
실험 번호 / 질문 / 최초 예측 / 고정 변수 / 조작 변수
최종 조건 / 핵심 결과 / A-B 차이 / 학생 설명 / 모델 한계
```

실험 데이터는 브라우저 안에 자동 저장하고 JSON·CSV 내보내기를 지원한다. 교사가 수업 전에 기록을 비우고 기준 조건을 불러올 수 있어야 한다.

### 2.3 공통 검수 문턱

- 과목 전문가가 식, 상수, 용어, 단위, 오개념 문구를 검토한다.
- 기준 사례, 경계값, 0값, 단위 변환, 대칭 조건을 자동 테스트한다.
- `한 변수만 변경` 미션에서 잠긴 변수가 실제로 변하지 않는지 검증한다.
- 데스크톱 프로젝터, 학교 크롬북급 노트북, 태블릿, 휴대전화에서 핵심 실험을 실행한다.
- 키보드만으로 모든 조작이 가능하고, 터치 대상은 최소 44px을 확보한다.
- 모션 감소 환경에서는 자동 재생을 멈추고 한 단계 실행을 제공한다.
- 작은 화면에서도 `장면 → 핵심 조작 → 결과 → 세부 조건` 순서를 유지한다.
- 교사가 설명 없이 2분 안에 실험을 열고, 학생이 1분 안에 첫 조작을 시작할 수 있어야 한다.

## 4. 주제별 실험실 기획

## 4.1 운동 분석 실험실 — 자유낙하에서 포물선까지

**교육과정 라벨:** 중핵(자유낙하·일과 에너지) + 고핵(2차원 운동·벡터·에너지)

**핵심 질문:** 힘이 일정할 때 위치·속도·에너지는 시간에 따라 어떻게 변하며, 수평 운동을 더하면 궤적은 어떻게 달라지는가?

### 핵심 장면과 관점

- `궤적 보기`: 발사점, 지면, 목표물, 현재 위치, 속도·가속도 벡터를 크게 본다.
- `성분 보기`: 수평 운동과 수직 운동을 동기화한 두 스트립으로 분리한다.
- `시간 그래프`: `x-t`, `y-t`, `vₓ-t`, `vᵧ-t`, `a-t`를 현재 시각선과 함께 본다.
- `데이터 공간`: 누적 실험을 2D·3D 산점도에 놓되, 상관관계가 인과를 증명하지 않는다는 안내를 고정한다.
- `이상/현실 모델`: 공기저항 없음과 이차 항력·바람 포함 모델을 같은 초기 조건으로 겹친다.

### 조절 변수와 판독값

- 기본 변수: 발사각, 초기 속력, 발사 높이.
- 환경 변수: 중력가속도, 바람 벡터, 공기밀도, 항력계수, 물체 질량·단면적.
- 핵심 판독: 비행 거리, 최고 높이, 비행 시간, 착지 속력, 현재 `vₓ/vᵧ`, 에너지 변화.
- 고등 심화식: 무항력 해 `x=v₀cosθ·t`, `y=y₀+v₀sinθ·t-½gt²`; 항력 모델 `F_d=½ρC_dA|v_rel|²`.

### 내장 실험

1. **자유낙하의 간격:** 같은 시간 간격의 위치 표시가 왜 점점 벌어지는지 `y-t`, `v-t` 그래프로 확인한다.
2. **무거우면 더 빨리 떨어질까:** 진공과 항력 포함 조건을 분리해 질량 효과를 검증한다.
3. **45°는 언제 가장 멀까:** 같은 높이·무항력 조건에서 각도만 바꾸고 거리 최대점을 찾는다.
4. **서로 다른데 같은 거리:** 30°/60°처럼 보완각 궤적의 거리와 최고점을 겹친다.
5. **최고점의 속도:** 최고점에서 `vᵧ=0`이지만 `vₓ`는 남는지 벡터와 그래프로 확인한다.
6. **속력을 두 배로:** 거리와 최고 높이가 단순히 두 배인지 예상한 뒤 비례 관계를 찾는다.
7. **두 개의 해로 표적 맞히기:** 낮은 각도와 높은 각도로 같은 표적을 맞히고 비행 시간·최고점을 비교한다.
8. **바람과 항력 분리:** 항력이 0일 때 바람 효과가 사라지는지, 항력과 공기밀도가 켜졌을 때 어떻게 달라지는지 확인한다.
9. **행성으로 옮기기:** 동일한 발사 벡터를 지구·달·화성에서 실행해 중력 실험실과 연결한다.

### 오개념 방지와 한계

- 45° 최대 거리는 같은 발사·착지 높이, 평평한 지면, 무항력 조건에서만 성립한다.
- 최고점에서는 수직 속도만 0이며 전체 속력과 가속도가 0이 아니다.
- 궤적 방향이 곧 힘의 방향이라는 인상을 주지 않도록 속도와 가속도 화살표 모양을 다르게 한다.
- 회전, 마그누스 효과, 난류, 지형은 기본 모델에 포함하지 않는다.

### 제품화 작업

기존 구현의 자유 실험·누적 데이터 기능은 유지한다. 여기에 예측 단계, 조건 잠금, A/B 실험 고정, 성분 그래프, 이상/현실 모델 전환, 단계별 원리 설명을 추가한다. 현재의 많은 환경 슬라이더는 기본 화면에서 접고, 미션이 요구하는 변수만 자동으로 연다.

## 4.2 일·에너지·간단한 기계 실험실 — 힘과 거리의 교환

**교육과정 라벨:** 중핵(일·에너지·역학적 에너지 보존) + 초등 도구 개념 연계 + 고등 역학 심화

**핵심 질문:** 더 작은 힘으로 같은 일을 할 때 무엇을 더 많이 움직여야 하며, 실제 기계에서는 에너지가 어디로 전달되는가?

이 주제는 `지레 단품`으로 판매하지 않는다. 지레, 도르래, 빗면을 같은 `입력 힘–입력 거리–출력 힘–출력 거리–효율` 언어로 묶고, 지레의 돌림힘은 고등 심화 모듈로 연다.

### 핵심 장면과 관점

- `실물 지레`: 받침점, 물체, 힘점을 직접 드래그하는 큰 작업대.
- `돌림힘 보기`: 회전 방향별 호 화살표와 `τ=rFsinθ` 성분을 표시한다.
- `거리·일 보기`: 입력점과 물체가 이동한 거리를 동시에 추적해 힘의 이득과 거리의 손해를 연결한다.
- `도구 해부`: 가위, 병따개, 손수레, 집게를 같은 지레 모형으로 겹쳐 본다.
- `기계 비교`: 같은 높이까지 물체를 올리는 지레·도르래·빗면의 힘, 거리, 일, 효율을 동일 축에서 비교한다.

### 조절 변수와 판독값

- 받침점 위치, 물체 질량·위치, 힘점 위치, 가하는 힘의 크기·각도.
- 심화 변수: 막대 질량과 질량중심, 마찰, 효율.
- 판독: 시계/반시계 돌림힘, 알짜 돌림힘, 균형 여부, 필요한 최소 힘, 입력·출력 이동거리, 일과 효율.

### 내장 실험

1. **받침점 이동:** 같은 물체를 들 때 받침점을 옮겨 필요한 힘의 변화를 표로 만든다.
2. **다른 힘, 같은 효과:** `힘×수직거리`가 같은 여러 조건을 찾아 균형시킨다.
3. **비스듬히 누르기:** 같은 크기의 힘도 각도에 따라 회전 효과가 달라지는 이유를 확인한다.
4. **힘을 아끼면 거리는:** 이상적 지레에서 입력 일과 출력 일을 비교한다.
5. **1·2·3종 지레:** 힘점·받침점·작용점의 순서를 바꾸고 이득과 운동 방향을 비교한다.
6. **막대도 무게가 있다:** 균일한 막대의 질량중심을 켜기 전후 평형점을 비교한다.
7. **같은 높이, 다른 길:** 빗면 길이를 바꾸고 필요한 힘과 이동거리, 이상적 일을 비교한다.
8. **도르래 줄 수 세기:** 물체를 지지하는 줄 수와 힘의 이득, 당겨야 하는 거리의 관계를 찾는다.

### 오개념 방지와 한계

- 힘의 크기만이 아니라 회전축까지의 **수직거리**가 중요함을 강조한다.
- 작은 힘이 에너지를 공짜로 만드는 것이 아니라 더 긴 거리를 움직인다는 점을 항상 함께 표시한다.
- 이상 모델과 마찰·막대 무게 포함 모델의 결과를 섞지 않는다.

### 고등 심화

힘 벡터를 평행·수직 성분으로 분해하고, 정적 평형 `ΣF=0`, `Στ=0`을 각각 만족하는지 별도 판독한다. 조건이 불균형이면 단순한 `왼쪽/오른쪽`뿐 아니라 알짜 돌림힘과 초기 각가속도 방향을 보여 준다.

## 4.3 전기회로 실험실 — 전류의 길과 에너지의 이동

**교육과정 라벨:** 중핵(전압·전류·옴의 법칙·전기 에너지) + 고핵(회로·전력)

**핵심 질문:** 회로의 연결 방식은 각 지점의 전류, 전압, 전력과 전구 밝기를 어떻게 결정하는가?

### 핵심 장면과 관점

- `실험대 보기`: 전지, 스위치, 전구, 저항, 전류계, 전압계를 연결점에 끌어 놓는다.
- `회로도 보기`: 같은 연결을 표준 기호 회로도로 즉시 변환한다.
- `전위 지도`: 도선의 각 점을 전위 높이로 펼쳐 전압 강하를 계단처럼 본다.
- `에너지 보기`: 전하 운반자 애니메이션과 에너지 전달을 구분해 표시한다.

### 계산 엔진과 변수

- 회로를 노드·소자 그래프로 표현하고 키르히호프 법칙으로 해를 구한다.
- 기본 변수: 전지 기전력, 저항값, 스위치, 직렬·병렬 연결.
- 심화 변수: 전지 내부저항, 전구의 비선형 저항, 계기 내부저항.
- 판독: 가지별 전류, 소자별 전압, 전력 `P=VI`, 등가저항, 회로 상태, 에너지/시간.

### 내장 실험

1. **왜 켜지지 않을까:** 끊긴 길, 한 단자만 연결, 우회 연결을 진단한다.
2. **전류는 소모될까:** 직렬회로 여러 지점의 전류계를 비교한다.
3. **직렬과 병렬의 밝기:** 전체 전류, 각 전구 전력, 한 전구 제거 후 변화를 비교한다.
4. **전압은 어디서 줄까:** 전위 지도에서 전지의 상승과 저항의 강하를 합산한다.
5. **계기를 잘못 연결하면:** 전류계 직렬·전압계 병렬 원리를 안전한 가상 고장으로 확인한다.
6. **단락은 왜 위험할까:** 내부저항을 포함해 매우 큰 전류와 전력 손실을 경고하되 실제 제작 절차는 안내하지 않는다.
7. **미지 저항 찾기:** 여러 전압에서 `V-I` 데이터를 모아 오옴성·비오옴성 소자를 구분한다.

### 오개념 방지와 한계

- 전류 입자가 전구에서 사라지는 듯한 애니메이션을 사용하지 않는다.
- 전지가 `일정 전류`를 보내는 장치가 아니라 회로 조건에 따라 전류가 정해진다는 점을 보여 준다.
- 전구 밝기는 전류 화살표 속도가 아니라 계산된 전력에 연결한다.
- 기본 모형은 정상상태 집중정수 회로이며 전자기파 전달시간, 실제 열화, 접촉 불량은 생략한다.

## 4.4 확률·통계 실험실 — 우연과 데이터에서 판단하기

**교육과정 라벨:** 중핵(대표값·도수분포·상대도수·경우의 수·확률·산포도·상자그림·산점도) + 고핵(확률과 통계)

**핵심 질문:** 우연한 결과는 어떻게 안정되며, 여러 자료의 분포와 두 변수의 관계에서 어디까지 주장할 수 있는가?

### 핵심 장면과 관점

- `시행 보기`: 동전·주사위·공 추출을 실제 속도 또는 고속으로 실행한다.
- `누적 보기`: 빈도 막대와 상대도수 궤적을 시행 번호에 따라 그린다.
- `분포 보기`: 이론분포와 반복 실험분포를 동일 축에 겹친다.
- `표본 묶음 보기`: 한 번의 1,000회와 100번의 10회를 구분해 표본 크기의 역할을 본다.
- `자료 분포 보기`: 원자료, 도수분포, 상자그림, 평균·중앙값을 같은 선택 집단에 연결한다.
- `두 변수 보기`: 산점도에서 점 하나와 실제 사례를 왕복하고, 추세선과 잔차를 함께 본다.

### 변수와 판독값

- 시행 횟수, 동전 앞면확률, 주사위 면별확률, 표본 크기, 반복 횟수, 난수 시드.
- 판독: 빈도, 상대도수, 이론확률과의 차이, 최장 연속, 기댓값, 분산, 표본비율 분포.
- 고등 심화: 이항분포, 표준편차, 표준화된 차이, 신뢰구간의 직관적 시각화.
- 자료 분석 변수: 표본 선택, 이상치, 집단 구분, 구간 폭, 축 범위, 추세선 표시.
- 추가 판독: 평균·중앙값·범위·사분위범위, 상관계수, 잔차, 집단별 분포 차이.

### 내장 실험

1. **10번과 1,000번:** 정확한 반반이 아니라 상대도수가 가까워지는 경향을 관찰한다.
2. **차이는 커질 수도 있다:** 앞뒤 횟수 차이와 비율 차이를 동시에 그려 서로 다른 결론을 확인한다.
3. **연속 앞면 다음은 무엇:** 독립 시행과 도박사의 오류를 실험한다.
4. **편향 동전 감정:** 숨겨진 `p`를 여러 표본으로 추정하고 불확실성을 비교한다.
5. **두 주사위의 합:** 2~12가 같은 확률이 아닌 이유를 표본공간 격자와 분포로 연결한다.
6. **같은 크기, 다른 표본:** 동일한 `n`의 여러 반을 비교해 한 번의 결과를 일반화할 수 없는 이유를 본다.
7. **재현과 무작위:** 같은 시드는 같은 결과를 재현하지만 그것이 조작된 결과는 아님을 확인한다.
8. **평균이 같은 두 반:** 평균은 같지만 퍼짐과 상자그림이 다른 자료를 비교한다.
9. **이상치 하나의 영향:** 한 값을 움직이며 평균·중앙값·범위·사분위범위의 민감도를 비교한다.
10. **상관은 원인일까:** 같은 산점도에 가능한 제3변수와 집단 구분을 켜고 인과 주장 가능 범위를 판단한다.
11. **축과 구간의 함정:** 같은 자료의 축 범위와 히스토그램 구간을 바꿔도 원자료는 변하지 않음을 확인한다.

### 오개념 방지와 한계

- 큰 수의 법칙을 `횟수가 많으면 정확히 이론값이 된다`고 쓰지 않는다.
- 빈도 차이와 상대도수 차이를 한 그래프 축에 섞지 않는다.
- 컴퓨터 의사난수와 물리적 무작위의 차이를 기술서에 밝힌다.
- 상관관계는 인과관계의 증거가 될 수 있지만 그 자체로 원인을 확정하지 못함을 모든 산점도 미션에서 확인한다.
- 평균 하나로 집단을 대표하지 않고 중앙값·산포도·분포 모양을 함께 읽게 한다.

## 4.5 행성 중력 실험실 — 질량, 반지름, 높이가 만드는 장

**교육과정 라벨:** 중핵(중력·자유낙하) + 고핵(역학·행성우주)

**핵심 질문:** 행성의 크기와 질량은 표면 중력과 고도별 중력, 낙하와 궤도를 어떻게 결정하는가?

초기 출시는 4.1 운동 분석 실험실의 `행성 중력 심화 팩`으로 묶는다. 질량·반지름 독립 조작과 궤도 모델이 충분히 검증되고 고등학교 수업안이 확보된 뒤에만 독립 상품으로 분리한다.

### 핵심 장면과 관점

- `표면 비교`: 지구·달·화성 등에서 같은 물체의 낙하·점프·투사를 동기화한다.
- `행성 내부/외부`: 질량과 반지름을 별도 축으로 조절해 `큰 행성=강한 중력` 단순화를 깨뜨린다.
- `중력장 보기`: 거리별 장의 세기와 등고선을 표시한다.
- `궤도 보기`: 수평 발사 속도를 높여 낙하가 궤도로 이어지는 관점을 보여 준다.

### 변수와 판독값

- 천체 질량 `M`, 반지름 `R`, 물체 질량 `m`, 시작 고도, 초기 속도와 방향.
- 기본 모형 `g=GM/r²`, 무게 `W=mg`, 위치에너지와 궤도 속력.
- 판독: 표면 중력, 무게, 낙하 시간, 충돌 속력, 최고점, 현재 고도의 `g`, 궤도 상태.

### 내장 실험

1. **질량은 그대로, 무게는 변화:** 같은 학생·물체를 여러 천체의 저울에 올린다.
2. **진공에서 함께 떨어지기:** 질량이 다른 두 물체를 같은 높이에서 낙하시킨다.
3. **왜 큰 행성이 꼭 세지 않을까:** 질량과 반지름을 따로 바꿔 같은 표면 중력 조합을 찾는다.
4. **높이 올라가면:** 일정 `g` 근사와 역제곱 모델의 차이가 언제 커지는지 찾는다.
5. **같은 점프, 다른 결과:** 같은 초기 속도로 최고점과 체공 시간을 비교한다.
6. **계속 떨어지지만 부딪히지 않기:** 수평 발사 속력을 올려 탄도·타원궤도·탈출을 구분한다.
7. **포물선 실험 연결:** 포물선 교구의 중력값을 실제 천체 데이터로 불러온다.

### 오개념 방지와 한계

- 질량과 무게를 단위부터 분리하고, 천체가 바뀌어도 물체 질량은 고정 표시한다.
- 대기, 행성 회전, 지형, 비구형 중력장은 기본 비교에서 제외한다.
- 매우 큰 거리에서 화면 확대를 위해 물체 크기를 몰래 키우지 않고 확대창·미니맵을 쓴다.

## 4.6 함수 그래프 실험실 — 식의 각 부분이 만드는 움직임

**교육과정 라벨:** 중핵(변화와 관계·함수·그래프) + 고핵(함수·변환·모델링)

**핵심 질문:** 식의 한 요소를 바꿀 때 그래프의 어느 성질은 바뀌고 어느 성질은 유지되는가?

### 핵심 장면과 관점

- `그래프 보기`: 기준 함수와 현재 함수를 동일 좌표에 겹친다.
- `변환 보기`: 이동·확대·반사·회전을 시작 그래프에서 끝 그래프로 연속 표시한다.
- `표·대응 보기`: 입력점 하나를 따라 식 계산, 표의 행, 그래프 점이 함께 강조된다.
- `표현 바꾸기`: 이차함수를 일반형·꼭짓점형·인수분해형으로 바꾸고 각 표현이 드러내는 정보를 비교한다.

### 변수와 판독값

- 1차함수 `y=ax+b`, 이차함수 `y=a(x-h)²+k`를 핵심 범위로 한다.
- 계수, 정의역, 축 범위, 기준 함수, 표시할 대표점.
- 판독: 기울기, 절편, 꼭짓점, 대칭축, 근, 증가·감소 구간, 두 그래프의 교점.
- 고등 심화: 평균변화율, 순간변화율의 시각적 도입, 데이터 적합과 잔차.

### 내장 실험

1. **기울기와 절편 분리:** 한 계수만 잠금 해제해 회전과 평행이동을 구분한다.
2. **같은 변화량의 뜻:** `x`가 1 늘 때의 `Δy`를 표·계단·기울기로 동시에 본다.
3. **꼭짓점 이동:** `h`, `k`, `a`가 위치와 벌어짐, 반사를 각각 어떻게 바꾸는지 확인한다.
4. **같은 그래프, 다른 식:** 세 형식이 같은 곡선을 나타내는지 대표점과 전개로 검증한다.
5. **조건으로 식 찾기:** 두 점 또는 꼭짓점·한 점을 만족하는 함수를 역으로 구성한다.
6. **교점은 해다:** 두 움직이는 그래프의 교점과 방정식의 해를 연결한다.
7. **데이터에 완벽한 선은 없다:** 실제형 데이터의 적합선과 잔차를 비교한다.

### 오개념 방지와 한계

- 축 자동 확대가 변화 크기를 왜곡하지 않도록 고정 축과 자동 축을 명확히 구분한다.
- `a가 커지면 그래프가 커진다` 같은 모호한 문구 대신 폭, 방향, 변화율을 구체적으로 쓴다.
- 자유 수식 파서는 후순위로 두고, 각 함수족의 개념 연결을 먼저 완성한다.

## 4.7 원자 조립 실험실 — 정체성, 질량, 전하를 분리하기

**교육과정 라벨:** 중핵(원소·원자·분자·이온·주기율표) + 고핵(원자 구조·동위원소)

**핵심 질문:** 양성자·중성자·전자의 수를 바꾸면 무엇이 바뀌고 무엇은 같은 원소로 남는가?

### 핵심 장면과 관점

- `입자 조립`: 핵과 전자 영역에 입자를 추가·제거한다.
- `기호 보기`: 원자번호, 질량수, 전하를 핵종 기호의 정확한 위치와 연결한다.
- `주기율표 보기`: 양성자 수가 바뀔 때 선택 원소가 이동하고, 전자만 바뀔 때 위치는 유지된다.
- `모형 비교`: 보어식 껍질 모형과 전자 구름 확률 모형을 나란히 두고 각각의 용도를 설명한다.

### 변수와 판독값

- 양성자, 중성자, 전자 수; 원자번호 1~20을 1차 범위로 한다.
- 판독: 원소명·기호, `Z`, `A`, 중성자 수, 순전하, 전자배치, 안정성 안내.
- 고등 심화: 동위원소 존재비와 평균 원자량, 이온화, 간단한 방출 스펙트럼.

### 내장 실험

1. **원소의 신분증:** 중성자와 전자를 바꿔도 양성자 수가 같으면 같은 원소인지 확인한다.
2. **동위원소 만들기:** 같은 원소의 여러 질량수를 비교하고 평균 원자량을 존재비로 계산한다.
3. **이온 만들기:** 전자 하나를 잃고 얻을 때 원자번호·질량수·전하 중 무엇이 변하는지 기록한다.
4. **기호 해독:** 주어진 핵종 기호에서 입자 수를 예측한 뒤 조립해 검증한다.
5. **전자배치와 주기율표:** 최외각전자 패턴과 족의 반복을 관찰한다.
6. **모형은 실물이 아니다:** 고정 궤도와 확률 분포 표현이 답하는 질문의 차이를 비교한다.

### 오개념 방지와 한계

- 전자가 행성처럼 정확한 원형 길을 돈다고 단정하지 않는다.
- 입자의 화면 크기와 핵-전자 거리에는 실제 축척이 적용되지 않았음을 표시한다.
- 안정성·방사성은 검증된 데이터 범위에서만 표시하고, 단순 규칙으로 모든 핵종을 판정하지 않는다.

## 4.8 먹이사슬 생태계 실험실 — 연쇄 변화와 시간 지연

**교육과정 라벨:** 중핵(생물·비생물 요소·먹이사슬·먹이그물) + 고핵(생태·환경 변화)

**핵심 질문:** 한 개체군 또는 환경 조건의 변화는 시간차를 두고 생태계 전체에 어떻게 전파되는가?

### 핵심 장면과 관점

- `서식지 보기`: 생산자·초식동물·포식자 개체군의 밀도와 자원 상태를 공간적으로 본다.
- `개체군 그래프`: 세 집단의 수와 변화율을 동일 시간축에 직접 라벨로 표시한다.
- `상호작용망`: 먹이, 경쟁, 사망, 번식 흐름의 방향과 현재 세기를 본다.
- `에너지·물질 보기`: 영양 단계별 에너지 전달량과 탄소·질소 등 물질의 저장고·이동을 별도 레이어로 본다.
- `모형 보기`: 직관적 매개변수와 차분/미분 방정식 항을 연결한다.

### 변수와 판독값

- 초기 개체수, 생산자 성장률, 환경수용력, 섭식률, 번식 효율, 사망률.
- 심화 변수: 계절성, 질병 충격, 서식지 감소, 외래종 또는 포획.
- 판독: 집단별 개체수·변화율, 자원량, 포식 압력, 진동 주기, 회복 시간, 국소 멸종 여부.
- 에너지·물질 판독: 영양 단계별 에너지, 호흡으로 빠져나간 에너지, 생물량, 분해자 유입, 물질 저장고별 양과 순환 속도.

### 내장 실험

1. **포식자가 줄면 끝인가:** 단기 증가와 장기 자원 고갈을 분리해 본다.
2. **최고점은 동시에 오지 않는다:** 생산자·초식동물·포식자 봉우리의 시간 지연을 측정한다.
3. **같은 시작, 다른 규칙:** 초기값이 같아도 성장률·섭식률에 따라 장기 결과가 달라짐을 본다.
4. **교란 뒤 회복:** 한 번의 가뭄·질병 충격 후 회복 시간과 복원력을 비교한다.
5. **수용력 감소:** 서식지 축소가 먹이망 각 단계에 미치는 연쇄 효과를 관찰한다.
6. **외래종 가정 실험:** 경쟁 또는 포식 관계 하나를 추가하고 예상치 못한 부작용을 찾는다.
7. **정책 비교:** 동일한 목표를 가진 포획·서식지 회복 조건을 결과와 부작용으로 비교한다.
8. **에너지는 순환할까:** 생산자에서 소비자·분해자로 전달되는 에너지와 열로 분산되는 에너지를 추적한다.
9. **물질은 사라질까:** 밀폐·개방 경계를 바꾸고 탄소 원자가 생물·대기·토양 저장고 사이를 이동하는 경로를 추적한다.
10. **화살표의 뜻:** `누가 누구를 먹는가`와 `에너지·물질이 어느 방향으로 이동하는가`를 구분해 먹이망을 다시 그린다.

### 오개념 방지와 한계

- 결과를 실제 지역 생태계의 예보값으로 제시하지 않는다.
- 한 종 변화가 항상 같은 방향의 결과를 만든다고 일반화하지 않으며 시간 범위를 표시한다.
- 확률적 사건, 연령 구조, 공간 이동, 유전적 적응을 생략한 경우 명시한다.
- 생태계 `성공`을 개체수가 고정되는 상태로만 정의하지 않고 변동과 회복력을 함께 본다.
- 에너지 흐름과 물질 순환을 같은 화살표 애니메이션으로 섞지 않는다.

## 4.9 달의 위상 실험실 — 우주 배치와 지상 관측을 연결하기

**교육과정 라벨:** 중핵(태양계·달 위상·일식·월식·지구 운동) + 고핵(행성우주·천문 관측)

**핵심 질문:** 달의 밝은 부분, 하늘에서 보이는 모양, 뜨고 지는 시각은 태양·지구·달의 배치와 어떻게 연결되는가?

### 핵심 장면과 관점

- `우주 관점`: 태양광 방향과 달 공전 위치, 항상 절반만 밝은 달을 본다.
- `지구 관측창`: 같은 순간 관측자가 보는 달 원반을 크게 표시한다.
- `하늘 경로`: 동쪽 지평선부터 남중·서쪽 지평선까지 시간대별 위치를 본다.
- `실제 비율`: 학습용 과장과 실제 크기·거리 모드를 분리하고 프리셋·미니맵으로 탐색한다.
- `궤도면 보기`: 달 궤도 경사를 켜 위상과 식의 조건을 구분한다.

### 변수와 판독값

- 달 공전각, 날짜/시간, 관측 위도·반구, 궤도 경사, 시간 재생 속도.
- 판독: 위상명, 밝은 면 비율, 태양과의 각거리, 예상 출·남중·몰 시각, 삭망월 진행률.
- 고등 심화: 항성월과 삭망월, 공전과 지구 자전의 합성, 식이 매달 일어나지 않는 기하.

### 내장 실험

1. **밝은 면은 어디를 향할까:** 공전 위치를 바꿔도 밝은 반구는 태양 쪽임을 확인한다.
2. **그림자가 위상을 만들까:** 위상과 월식 장면을 나란히 비교한다.
3. **위치를 보고 모양 예측:** 우주 배치를 본 뒤 지구 관측창을 가리고 위상을 예상한다.
4. **모양을 보고 시간 예측:** 상현달·보름달·하현달의 뜨는 시각을 하늘 경로로 검증한다.
5. **달은 밤에만 보일까:** 낮 시간대 관측 가능한 위상과 방향을 찾는다.
6. **왜 매달 식이 없을까:** 궤도 경사 0°와 실제값 근사 조건을 비교한다.
7. **두 달의 길이:** 달이 별에 대해 한 바퀴 돈 뒤 태양에 대한 같은 위상까지 더 이동하는 이유를 시간축으로 본다.

### 오개념 방지와 한계

- 달 위상과 지구 그림자를 같은 그림 언어로 표현하지 않는다.
- 같은 시각 지구 어디서나 위상 자체는 거의 같고 방향·하늘 경로가 달라짐을 구분한다.
- 학습용 크기와 거리에는 과장 배율을 고정 표기한다.
- 실제 정밀 천문력·지역별 관측 예보가 아니라면 `개념 모델`로 명확히 표시한다.

## 4.10 산·염기 실험실 — 색 변화에서 평형과 로그 척도까지

**교육과정 라벨:** 고핵(산·염기·중화) + 중학교 물질·입자 개념 연계

**핵심 질문:** 수소 이온 농도, 지시약 평형, 혼합 비율은 색과 pH를 어떻게 바꾸는가?

판매 페이지와 교안에서는 이 실험실을 `중학교 필수`로 분류하지 않는다. 중학생에게 제공할 때는 지시약 색, 상대적 산성·염기성, 안전한 가상 혼합의 관찰 층까지만 권장하고, pH 계산·적정·평형은 고등학교 수업으로 명시한다.

### 핵심 장면과 관점

- `실험대 보기`: 용액, 피펫, 뷰렛, 지시약을 안전한 가상 조작으로 다룬다.
- `색 스펙트럼`: 선택 지시약의 전이 범위와 현재 색을 pH 축에 직접 표시한다.
- `입자 비율`: 실제 개수를 그리지 않고 상대적인 산·염기형 비율을 과장한 개념 표현으로 본다.
- `적정 곡선`: 첨가 부피에 따른 pH와 등당량점, 지시약 변색 범위를 겹친다.

### 계산 엔진과 변수

- `pH=-log₁₀[H⁺]`, 물의 이온곱, 강산·강염기 혼합을 1차 정량 범위로 한다.
- 지시약은 산형/염기형의 색과 `pKₐ`를 이용한 전이 곡선으로 표현한다.
- 기본 변수: 용액 종류, 농도, 부피, 첨가량, 지시약 종류.
- 심화 변수: 약산·약염기, 완충용액, 온도 고정값.
- 판독: pH, `[H⁺]`, `[OH⁻]`, 몰수, 남은 산/염기, 지시약 상태비, 등당량점 오차.

### 내장 실험

1. **같은 용액, 다른 지시약:** 리트머스·BTB·페놀프탈레인의 전이 범위를 비교한다.
2. **pH 1 차이는 얼마:** pH 축이 선형 농도축이 아니라 10배 로그 척도임을 희석으로 확인한다.
3. **색만으로 정확한 pH를 알 수 있을까:** 넓은 전이 범위와 관찰 오차를 확인한다.
4. **중화는 한순간이 아니다:** 강산-강염기 적정에서 첨가 부피별 pH 변화를 기록한다.
5. **지시약 선택:** 등당량점 주변의 급격한 구간에 맞는 지시약을 고른다.
6. **미지 용액 판별:** 제한된 지시약과 pH 범위 정보로 가능한 용액을 좁힌다.
7. **완충 작용:** 같은 양의 산을 물과 완충용액에 넣고 pH 변화를 비교한다.

### 오개념·안전·한계

- pH가 1 차이 날 때 산성이 `조금` 변한다고 표현하지 않고 농도비를 함께 보여 준다.
- 색은 지시약 농도, 조명, 용액 자체 색의 영향을 받을 수 있으므로 절대적인 판독값으로 제시하지 않는다.
- `중성 pH=7`은 지정 온도 조건임을 심화 설명에서 밝힌다.
- 산성/염기성의 세기와 실제 위험성을 동일시하지 않는다.
- 실제 화학물질 혼합 절차나 가정 실험을 직접 지시하지 않고, 실제 실험은 학교 안전 기준과 교사 지도 아래 별도 수행하도록 한다.
- 기본 정량 모형은 지정 온도에서의 이상적 희석용액을 우선하며, 활동도·다양성자산·침전·복합 평형을 포함하지 않는 미션은 그 적용 범위를 표시한다.

## 4.11 열과 열전달 실험실 — 온도, 에너지, 평형을 구분하기

**교육과정 라벨:** 중핵(열평형·전도·대류·복사·비열·열팽창) + 고등 열역학 연계

**핵심 질문:** 온도와 열에너지는 어떻게 다르며, 두 물체의 에너지는 무엇이 같아질 때까지 어느 방향으로 이동하는가?

### 핵심 장면과 관점

- `열화상 보기`: 접촉한 두 물체와 주변 유체의 온도장을 시간에 따라 본다.
- `입자 보기`: 온도를 입자 한 개의 속도가 아니라 속력 분포와 평균 운동에너지로 표현한다.
- `에너지 장부`: 물체별 내부에너지 변화와 경계를 통과한 에너지를 누적 막대·흐름선으로 본다.
- `그래프 보기`: 물체별 `T-t`, 전달률, 누적 열량을 같은 현재 시각선에 연결한다.
- `전달 방식 보기`: 전도·대류·복사를 별도 레이어로 켜고, 어떤 매질과 조건이 필요한지 비교한다.

### 변수·계산 모형과 판독값

- 기본 변수: 물질, 질량, 초기 온도, 접촉 여부, 접촉 면적, 주변 온도.
- 심화 변수: 비열, 열전도율, 대류 계수, 표면 방사율, 단열 두께, 열원 출력.
- 기본 관계: `Q=mcΔT`, 에너지 보존, 두 물체 사이 온도차에 따른 전달 방향.
- 고등 심화: 전도·대류 전달률의 단순 집중정수 모형, 복사 `P=εσA(T⁴-T_env⁴)`.
- 판독: 현재 온도, 온도차, 받은/잃은 에너지, 순간 전달률, 평형 예상 온도, 평형 도달 시간.

### 내장 실험

1. **같은 온도면 같은 에너지일까:** 질량과 물질이 다른 두 물체의 온도와 에너지 변화를 비교한다.
2. **뜨거움과 양의 구분:** 작은 뜨거운 물체와 큰 미지근한 물체를 같은 찬물에 넣고 최종 온도를 예상한다.
3. **금속이 더 차갑게 느껴지는 이유:** 같은 실내 온도의 금속·나무에 손 모형을 접촉해 초기 열전달률을 비교한다.
4. **열평형 찾기:** 서로 다른 초기 온도·질량·비열에서 최종 온도를 예측하고 에너지 장부로 검산한다.
5. **어떤 단열이 오래 버틸까:** 두께와 열전도율을 한 번에 하나씩 바꿔 냉각 곡선을 비교한다.
6. **전도·대류·복사 분리:** 진공, 유체 흐름, 표면 방사율 조건을 바꿔 세 전달 방식을 구분한다.
7. **가열 중 온도 정지:** 상태 변화 모듈에서 공급 에너지가 입자 사이 상호작용 변화에 쓰이는 구간을 본다.
8. **같은 출력, 다른 상승:** 질량과 비열에 따라 초기 온도 상승률이 어떻게 달라지는지 확인한다.

### 오개념 방지와 한계

- 열을 물체 안에 고정되어 있는 `물질`처럼 그리지 않고 경계를 통해 전달된 에너지로 기록한다.
- 온도는 전체 에너지의 양이 아니며, 개별 입자의 속력 하나도 아니다.
- 열평형은 두 물체의 에너지가 같아지는 상태가 아니라 거시적 온도가 같아져 순열전달이 0인 상태다.
- 2D 입자 애니메이션의 입자 수·크기·충돌은 설명 모형이며 실제 축척이 아니다.
- 실제 재료의 상변화, 온도 의존 물성, 복잡한 유체 흐름은 선택한 모형 밖이면 명시한다.

## 4.12 빛·상·파동 실험실 — 보이는 결과를 경로와 파동으로 설명하기

**교육과정 라벨:** 중핵(시각과 상·반사·굴절·거울·렌즈·빛의 합성과 색·파동 요소와 소리) + 고등 광학·파동 연계

**핵심 질문:** 빛은 물체에서 눈까지 어떤 경로로 오며, 경계와 광학기구는 그 경로와 상을 어떻게 바꾸는가?

### 핵심 장면과 관점

- `현상 보기`: 광원, 물체, 거울·렌즈·경계면, 스크린, 눈을 직접 배치한다.
- `광선 보기`: 대표 광선과 법선, 실제 광선과 연장선을 구분해 실상·허상을 표시한다.
- `파면 보기`: 같은 현상을 파면·파장·진폭 표현으로 바꿔 광선 모형의 한계를 보완한다.
- `관측자 보기`: 눈 위치를 움직이며 실제로 눈에 들어오는 광선만 남긴다.
- `측정 보기`: 물체거리·상거리·초점거리·입사각·굴절각을 장면과 표·그래프에 연결한다.

### 변수·계산 모형과 판독값

- 광학 변수: 광원 위치·크기, 물체거리, 거울/렌즈 종류, 곡률·초점거리, 굴절률, 경계면 각도.
- 파동 변수: 진폭, 진동수, 파장, 매질에서의 속력, 위상차, 관측 위치.
- 기본 관계: 반사 법칙, 스넬 법칙, 얇은 렌즈·구면거울 식, `v=fλ`.
- 판독: 입사각·반사각·굴절각, 임계각, 상 위치·크기·방향·실허, 초점, 파장·진동수·속력.

### 내장 실험

1. **보려면 무엇이 필요할까:** 광원–물체–눈 경로 중 하나를 가려 물체가 보이는 조건을 찾는다.
2. **거울 속 상은 어디에 있을까:** 눈 위치를 바꾸고 반사 광선을 연장해 허상 위치를 삼각 측정한다.
3. **거울 절반을 가리면:** 상의 절반이 사라지는지, 밝기와 시야가 어떻게 달라지는지 확인한다.
4. **경계에서 꺾이는 이유:** 입사각과 굴절률을 바꾸며 각도 관계와 전반사 조건을 찾는다.
5. **렌즈로 화면에 잡히는 상:** 물체거리를 바꿔 실상·허상, 확대·축소, 상의 방향을 구분한다.
6. **렌즈 절반을 가리면:** 각 물체점의 빛이 렌즈 여러 부분을 지나는 경로를 추적한다.
7. **진동수를 바꾸면:** 같은 매질에서 파동 속력, 파장, 진동수 중 무엇이 함께 변하는지 본다.
8. **큰 소리와 높은 소리:** 진폭과 진동수를 별도 잠금 해제해 세기와 높낮이를 구분한다.
9. **빛의 합성과 물감 혼합:** 가산 혼합과 감산 혼합을 서로 다른 모형·재료로 비교한다.

### 오개념 방지와 한계

- 눈에서 빛이 나가 물체를 보는 것처럼 보이는 화살표를 사용하지 않는다.
- 거울 표면에 작은 그림이 붙어 있는 것과 허상을 구분하고, 스크린에 맺히는지로 검증한다.
- 대표 광선은 계산을 돕는 선택된 경로이지 실제로 세 가닥의 빛만 존재한다는 뜻이 아니다.
- 진폭이 커진다고 같은 매질에서 파동 속력이나 진동수가 자동으로 커지지 않는다.
- 얇은 렌즈, 근축광선, 균질 매질 가정과 회절을 무시할 수 없는 조건을 명시한다.

## 4.13 입자와 기체 실험실 — 보이지 않는 충돌로 압력을 읽기

**교육과정 라벨:** 중핵(입자 운동·기체 압력·압력/부피·온도/부피·상태와 입자 모형) + 고등 물질과 에너지 연계

**핵심 질문:** 압력·온도·부피의 거시적 변화는 입자의 운동, 충돌, 간격으로 어떻게 설명되는가?

### 핵심 장면과 관점

- `용기 보기`: 피스톤·벽·온도 조절기를 조작하고 충돌 충격을 벽에 누적 표시한다.
- `입자 추적`: 선택 입자 하나의 경로와 전체 속력 분포를 동시에 본다.
- `거시 계기`: 압력계·온도계·부피 눈금을 실제 입자 장면과 동기화한다.
- `분포 보기`: 속력 분포와 평균 운동에너지, 벽 충돌 빈도·충격량 분포를 본다.
- `상태 모형 비교`: 고체·액체·기체의 입자 간격, 운동, 상호작용을 같은 물질 조건에서 비교한다.

### 변수·계산 모형과 판독값

- 기본 변수: 입자 수, 용기 부피, 온도, 외부 압력, 피스톤 하중.
- 심화 변수: 입자 질량, 혼합 기체 비율, 상호작용 세기, 가열 속도.
- 기본 관계: 충돌 기반 압력, 온도와 평균 병진 운동에너지, 보일·샤를 관계.
- 고등 심화: 이상기체 상태방정식, 분압, 실제기체와 이상기체 차이의 정성적 도입.
- 판독: 압력·부피·온도·입자 수, 충돌 빈도, 평균 충격량, 평균 속력·제곱평균제곱근 속력.

### 내장 실험

1. **기체에도 질량이 있을까:** 밀폐 용기의 입자 수를 바꾸고 전체 질량과 저울값을 비교한다.
2. **눌렀을 때 입자는 작아질까:** 등온 압축에서 입자 크기, 간격, 충돌 빈도 중 무엇이 변하는지 본다.
3. **압력과 부피:** 온도·입자 수를 잠그고 `P-V` 자료를 모아 반비례를 검증한다.
4. **가열하면 입자가 커질까:** 입자 크기는 고정하고 속력 분포와 충돌, 피스톤 이동을 추적한다.
5. **온도와 부피:** 일정 압력 피스톤에서 절대온도와 부피의 관계를 그래프로 만든다.
6. **입자 수와 압력:** 같은 부피·온도에서 입자를 추가하고 압력 변화를 측정한다.
7. **향은 왜 퍼질까:** 외부 흐름을 끄고 무작위 운동과 농도 구배에 따른 확산을 관찰한다.
8. **끓는 물의 기포는 무엇일까:** 가열 단계와 위치에 따라 용존 기체 방출과 수증기 기포를 구분한다.

### 오개념 방지와 한계

- 가열할 때 입자 자체가 커지거나 차가워질 때 작아지는 표현을 금지한다.
- 입자 사이를 공기나 다른 연속 물질로 채워 그리지 않는다.
- 압력을 단순히 `입자가 누르는 힘` 한 번으로 설명하지 않고 단위면적·시간당 충돌 효과로 누적한다.
- 섭씨 온도를 비례식에 바로 쓰지 않고 절대온도와 연결한다.
- 2D 탄성 충돌 모형과 제한된 입자 수가 실제 기체의 축척·통계적 요동을 그대로 재현하지 않음을 밝힌다.

## 4.14 화학 반응과 보존 실험실 — 원자가 재배열되는 규칙

**교육과정 라벨:** 중핵(화학 변화·화학 반응식·질량 보존·일정 성분비·기체 반응·열에너지 출입) + 고핵(화학 반응의 세계)

**핵심 질문:** 새 물질이 생겨도 어떤 것은 보존되며, 반응식의 수와 실제 입자·질량은 어떻게 연결되는가?

### 핵심 장면과 관점

- `거시 실험대`: 열린/닫힌 반응 용기, 저울, 기체 포집, 온도 센서를 본다.
- `입자 재배열`: 반응 전후 원자마다 동일 식별 표식을 유지해 결합만 바뀌는 과정을 본다.
- `원자 장부`: 원소별 원자 수, 물질별 입자 수, 계 전체 질량을 반응 전후 표로 고정한다.
- `반응식 보기`: 모형의 입자 묶음과 계수, 화학식의 아래첨자를 직접 연결한다.
- `에너지 보기`: 계와 주위의 온도, 에너지 출입, 단순 에너지 프로필을 구분한다.

### 변수·계산 모형과 판독값

- 반응물 종류·양, 용기 개방 여부, 초기 온도, 농도, 표면적, 촉매 유무.
- 정량 모형: 균형 반응식, 몰비, 제한 반응물, 남은 입자, 질량 보존.
- 판독: 원소별 원자 수, 반응물·생성물 양, 계 안/밖으로 이동한 질량, 온도 변화, 반응 진행률.
- 반응속도 모듈은 충돌 빈도와 유효 충돌의 개념 비교용으로 제한하고 실제 산업 반응을 예측하지 않는다.

### 내장 실험

1. **질량이 줄어든 것처럼 보일 때:** 열린 용기와 닫힌 용기의 기체 생성 반응을 비교한다.
2. **연소 뒤 더 무거워질 수 있을까:** 계 경계를 넓혀 공기 중 산소가 반응물임을 질량 장부로 확인한다.
3. **원자는 사라질까:** 반응 전후 같은 원자 표식을 추적해 재배열과 보존을 검증한다.
4. **계수와 아래첨자:** 반응식 계수를 바꾸는 것과 물질의 화학식을 바꾸는 것이 왜 다른지 확인한다.
5. **남는 반응물:** 두 반응물의 비율을 바꾸고 제한 반응물·생성량·남은 양을 예측한다.
6. **일정 성분비:** 같은 화합물을 만드는 여러 입자 묶음에서 질량비가 일정한지 확인한다.
7. **뜨거워진 반응의 에너지:** 계가 잃거나 얻은 에너지와 주위 온도 변화를 함께 기록한다.
8. **빠름과 많음은 다르다:** 온도·농도·표면적이 반응 속도와 최종 생성량에 미치는 영향을 분리한다.

### 오개념·안전·한계

- 기체가 빠져나간 `열린 계의 측정값`과 전체 계의 질량 보존을 구분한다.
- 생성물에 없는 원소가 반응식 규칙 때문에 새로 생기는 듯한 자동 완성 기능을 금지한다.
- 반응 속도가 빨라지면 평형 또는 최종 생성량도 항상 커진다고 일반화하지 않는다.
- 발열 반응을 `열을 가진 물질이 나온다`고 표현하지 않고 계와 주위 사이 에너지 이동으로 표시한다.
- 실제 약품 혼합·연소 절차는 제공하지 않으며 학교 안전 규정과 교사 지도 없는 재현을 유도하지 않는다.
- 기본 입자 애니메이션은 균형 반응식과 보존을 설명하는 모형이며 실제 반응 메커니즘·중간체·평형·분자 운동의 시간축을 그대로 재현하지 않는다.

## 4.15 유전과 세포분열 실험실 — 확률, 분리, 다양성 연결하기

**교육과정 라벨:** 중핵(세포분열·유전 형질과 유전 원리·변이) + 고핵(세포와 물질대사·유전)

**핵심 질문:** 부모의 유전 정보는 세포분열과 생식 과정에서 어떻게 분리·조합되며, 왜 같은 부모의 자손도 서로 다른가?

### 핵심 장면과 관점

- `세포 보기`: 염색체 복제, 체세포분열, 감수분열을 같은 시작 세포에서 단계별 비교한다.
- `염색체 추적`: 상동염색체와 염색분체를 색뿐 아니라 무늬·라벨로 구분해 끝까지 추적한다.
- `배우자 보기`: 한 개체에서 가능한 배우자 종류와 실제 무작위 생성 결과를 분리한다.
- `가계·확률 보기`: 퍼넷 사각형의 가능성과 여러 가족 시뮬레이션의 실제 비율을 연결한다.
- `유전자–형질 보기`: 유전자형, 단백질·세포 과정, 표현형, 환경 영향을 단계적으로 연다.

### 변수·계산 모형과 판독값

- 기본 변수: 대립유전자, 부모 유전자형, 자손 수, 무작위 시드.
- 심화 변수: 두 유전자 좌위, 독립/연관, 교차율, 성염색체 연관, 불완전 우성, 환경 효과.
- 판독: 세포별 염색체·DNA 상대량, 가능한 배우자, 유전자형·표현형 확률과 관측 빈도.
- 모든 확률 결과는 `한 자녀의 운명`이 아니라 반복 가능한 모형의 가능성으로 표시한다.

### 내장 실험

1. **체세포분열과 감수분열:** 분열 횟수, 딸세포 수, 염색체 조합, 유전적 동일성을 비교한다.
2. **복제와 염색체 수:** DNA가 복제될 때 염색체 수와 DNA 양을 같은 것으로 세지 않는지 확인한다.
3. **분리 법칙:** 상동염색체가 갈라지는 순간과 배우자의 대립유전자 구성을 연결한다.
4. **3:1은 네 자녀 중 세 명일까:** 한 가족과 많은 가족의 분포를 비교해 확률과 보장을 구분한다.
5. **우성은 흔하거나 강할까:** 우성 여부와 집단 빈도·적응도 변수를 독립시켜 반례를 만든다.
6. **두 형질의 조합:** 독립 배열 조건과 연관 조건의 자손 분포를 비교한다.
7. **같은 유전자형, 다른 표현형:** 환경 변수를 바꿔 유전자와 형질의 관계가 단순 일대일이 아님을 본다.
8. **가계도에서 가능한 것:** 제한된 정보로 가능한 유전자형 범위를 추론하고 확정할 수 없는 경우를 표시한다.

### 오개념·윤리·한계

- 염색체, DNA, 유전자, 대립유전자를 같은 크기의 동의어처럼 쓰지 않는다.
- 우성은 `더 강함·더 좋음·더 흔함`을 뜻하지 않는다.
- 멘델 단일유전자 모형을 키·지능·대부분의 질환 같은 복합 형질에 그대로 적용하지 않는다.
- 사람의 질병 위험을 진단하거나 실제 가족의 유전자형을 추정하게 하지 않고 가상 데이터만 사용한다.
- 집단유전, 후성유전, 다유전자·환경 상호작용을 생략한 미션에는 적용 한계를 고정 표시한다.

## 4.16 계절과 태양 고도 실험실 — 기울기에서 받은 에너지까지

**교육과정 라벨:** 중핵(지구 자전·공전, 태양계와 지구) + 고등 지구시스템·행성우주 연계

**핵심 질문:** 지구 자전축의 기울기와 공전은 태양 고도·낮 길이·단위면적당 에너지를 어떻게 바꾸어 계절을 만드는가?

### 핵심 장면과 관점

- `우주 관점`: 기울기가 같은 방향을 유지하는 지구를 공전 궤도 위에서 본다.
- `지역 표면 보기`: 선택 위도의 작은 면적에 같은 광선 묶음이 얼마나 퍼지는지 본다.
- `하늘 경로`: 계절별 태양의 일주 경로, 남중 고도, 일출·일몰 방향과 낮 길이를 겹친다.
- `양반구 비교`: 같은 날짜 북반구·남반구 두 지점의 에너지와 낮 길이를 동기화한다.
- `연간 그래프`: 태양 고도, 낮 길이, 대기권 상단 일사량, 지구–태양 거리를 같은 날짜선으로 비교한다.

### 변수·계산 모형과 판독값

- 기본 변수: 날짜·공전 위치, 시간, 위도, 반구, 자전축 기울기.
- 심화 변수: 궤도 이심률, 공전 속도, 대기 투과의 단순 계수, 지표 열용량·지연.
- 판독: 태양 적위, 남중 고도, 낮 길이, 입사각, 단위면적당 순간·일 누적 에너지, 지구–태양 거리.
- 원인 확인 모드에서는 원궤도를 기본으로 하여 거리 효과를 제거하고, 심화 모드에서 실제 이심률을 복원한다.

### 내장 실험

1. **태양과 가까워서 여름일까:** 거리를 고정한 원궤도에서도 계절 효과가 생기는지 확인한다.
2. **두 반구의 같은 날짜:** 북반구 여름일 때 남반구의 태양 고도·낮 길이를 비교한다.
3. **같은 빛이 퍼지는 면적:** 광선 묶음과 표면 각도를 바꿔 단위면적당 에너지를 측정한다.
4. **낮 길이의 효과:** 순간 정오 에너지와 하루 누적 에너지를 구분한다.
5. **기울기가 0°라면:** 위도별 낮 길이·계절 변화가 어떻게 달라지는지 본다.
6. **고위도의 극단:** 백야·극야가 나타나는 위도와 날짜 조건을 찾는다.
7. **하지가 가장 덥지 않은 이유:** 최대 일사 시점과 표면 온도 모형의 지연을 비교한다.
8. **궤도도 완전한 원은 아니다:** 실제 이심률에서 거리 효과가 존재하지만 현대 지구 계절의 주원인이 아님을 정량 비교한다.

### 오개념 방지와 한계

- 자전축이 공전 중 태양을 향해 방향을 바꾸는 듯한 애니메이션을 금지한다.
- 계절의 주원인을 지구–태양 거리로 설명하지 않되, 거리 효과가 정확히 0이라고도 가르치지 않는다.
- 태양 고도, 낮 길이, 일사량과 실제 기온을 동일시하지 않는다.
- 구름, 대기·해양 순환, 지표 특성까지 포함하지 않은 기본 모형은 실제 지역 기후 예측에 쓰지 않는다.
- 크기·거리 과장 모드와 실제 비율 모드를 분리하고 배율을 항상 표시한다.

## 5. 교사용 제품 모드

### 5.1 교실 시연 모드

- 프로젝터에서 장면과 핵심 수치가 먼저 보이고 제어 레일은 접을 수 있다.
- `결과 가리기`로 학생 예측을 받은 뒤 장면·수치·그래프를 순차 공개한다.
- 미션을 고르면 관련 변수만 열리고 나머지는 잠긴다.
- 교사용 발문은 학생 화면에 보이지 않는 발표자 노트로 제공한다.

### 5.2 학생 탐구 모드

- 참여 즉시 오늘의 질문과 예측 단계가 열린다.
- A/B 실험을 최소 한 번 저장해야 설명 단계로 넘어간다.
- 자동 판정은 정답 여부보다 변수 통제와 증거 사용을 확인한다.
- 학생은 자기 실험 기록만 보고, 내보내기 전 미리보기를 확인한다.

### 5.3 학교 라이선스 확장

- 교사는 미션 세션을 열고 6자리 코드 또는 QR로 참여시킨다.
- 학생은 세션 안에서만 쓰는 팀 별칭을 사용한다.
- 대시보드는 예측 분포, 선택 조건, 결과 분포, 시도 횟수, 설명 유형을 익명 집계한다.
- 교사는 결과 보관 기간과 삭제를 관리한다.
- 인터넷 연결이 불안정하면 학생 기록을 로컬에 보존하고 연결 복구 후 제출한다.

## 6. 개발 우선순위와 묶음 전략

### 6.1 0단계 — 공통 제품 기반

조석과 운동 분석에 먼저 공통 실험 상태, A/B 비교, 난이도 층, 교사용 결과 가리기, 실험 기록 내보내기, 기술서/교안 연결을 적용한다. 여기서 공통 UI와 데이터 계약을 확정한다. 다만 두 주제는 공통 플랫폼의 검증용 기준 제품이며, 새 상품의 교육과정 우선순위와 동일하지는 않다.

### 6.2 1차 교육과정 핵심 상품

1. **전기회로:** 중학교 직접 정합성, 오개념 빈도, 안전한 반복 실험의 구매 가치가 모두 높다.
2. **열과 열전달:** 중학교 핵심 내용이 넓고 열·온도·에너지의 언어 혼동을 여러 학년에서 다시 사용한다.
3. **입자와 기체:** 중학교 화학의 미시–거시 연결 기반이며 이후 상태 변화·반응·산염기의 선수 개념이 된다.
4. **빛·상·파동:** 관점·광선·파동·관측자를 연결하는 시뮬레이션 이점이 크고 교실 실험의 측정 한계를 보완한다.
5. **달의 위상:** 조석의 관점 전환 철학을 가장 직접적으로 재사용하며 공간 오개념 교정 가치가 높다.
6. **함수 그래프:** 중·고 수학의 다중 표상 기반이며 다른 과학 실험실의 그래프 읽기에도 재사용된다.
7. **확률·통계:** 대량 반복과 분포·상관 비교가 디지털 교구에 특히 적합하며 수학 데이터 묶음의 두 번째 축이다.

### 6.3 2차 개념 연결 상품

- **운동 분석:** 기존 포물선 구현을 자유낙하·에너지부터 시작하도록 재구성한다.
- **화학 반응과 보존:** 입자와 기체 실험실의 입자 렌더링·장부·그래프를 재사용한다.
- **원자 조립:** 반응식의 원자 보존과 주기율표·이온으로 이어지는 미시 화학 제품군을 완성한다.
- **먹이사슬 생태계:** 에너지 흐름·물질 순환·개체군 시간 지연을 통합한 뒤 출시한다.
- **유전과 세포분열:** 확률 엔진과 생명과학 표상을 결합하되 윤리·한계 검토를 별도로 통과한다.
- **계절과 태양 고도:** 달 위상의 천체 카메라·시간·좌표계를 재사용한다.

### 6.4 고등학교·심화 확장

- **산·염기:** 고등학교 통합과학·화학 수업에 맞춘 pH·중화·적정 제품으로 출시한다.
- **행성 중력:** 운동 분석의 심화 팩으로 시작해 역제곱 장·궤도 검증 후 독립시킨다.
- **일·에너지·간단한 기계:** 지레 단품은 만들지 않고 지레·도르래·빗면·효율을 묶는다.
- **조석:** 정규 단원 직접성보다 공간 추론·지구과학 심화 가치가 강한 대표 탐구 상품으로 위치시킨다.

### 6.5 판매 묶음 예시

- `중등 물리 핵심 실험실`: 운동 분석 + 전기회로 + 열과 열전달 + 빛·상·파동
- `중등 화학 미시 실험실`: 입자와 기체 + 원자 조립 + 화학 반응과 보존
- `중등 지구·생명 실험실`: 달의 위상 + 계절과 태양 + 생태계 + 유전
- `중등 수학 데이터 실험실`: 함수 그래프 + 확률·통계
- `고등 물리·지구 심화 팩`: 포물선 정량 모델 + 행성 중력 + 조석
- `고등 화학 심화 팩`: 원자·주기율표 + 반응 정량 + 산·염기
- 학교 전체 라이선스는 모든 실험실, 교안, 익명 수업 세션, 업데이트를 포함한다.

단품과 묶음 모두 `중핵/고핵/연계` 라벨, 권장 학년, 선수 개념, 적용 가능한 과목·단원, 정량 수준을 구매 전에 공개한다. 단순히 `중고등용`이라고 묶어 판매하지 않는다.

## 7. 각 주제의 완료 정의

한 주제가 `완료`가 되려면 다음을 모두 만족해야 한다.

- 대표 질문 1개와 최소 6개의 서로 다른 인과 실험이 있다.
- 관찰·측정·모델의 세 깊이가 같은 계산 결과로 연결된다.
- 최소 2개의 관점 또는 표현 모드가 단순 장식이 아니라 서로 다른 이해를 제공한다.
- 한 변수 통제, A/B 저장, 차이값, 그래프 또는 표, 학생 설명이 한 흐름으로 작동한다.
- 지정한 교육과정 라벨의 학교급용 수업이 최소 한 차시 완성돼 있고, 다른 학교급은 실제 연계 가치가 검증된 경우에만 추가한다.
- 대표 오개념 3개 이상을 화면 표현과 발문으로 예방한다.
- 각 오개념마다 `사전 예측 문항 → 반례 실험 → 증거 기반 재설명 → 변형 문항`이 연결된다.
- 미션별 교육과정 내용 요소·성취기준·선수 개념과 연구 근거가 내부 추적표에 기록된다.
- 모형의 가정, 제외 변수, 적용 범위가 학생용과 교사용 문서에 모두 있다.
- 계산 기준 테스트, 키보드 테스트, 모바일·프로젝터 테스트를 통과한다.
- 프로젝트 전용 두 색만 사용하고 카탈로그와 페이지 토큰이 일치한다.
- 교사 파일럿에서 준비 2분 이내, 첫 실험 5분 이내, A/B 비교 15분 이내가 가능하다.

## 8. 기획 확정 전에 필요한 실제 검증

1. 중학교 과학·수학 교사와 고등학교 과목 교사에게 주제별 `필수/과도/누락` 내용을 검토받는다.
2. 현재 적용 학년에 맞춰 2022 개정 교육과정의 정확한 성취기준 코드를 주제·미션별로 매핑한다.
3. 각 주제에서 10분 시연만으로도 가장 큰 오개념 하나가 실제로 줄어드는지 소규모 수업으로 확인한다.
4. 학교 네트워크 제한, 크롬북 성능, 프로젝터 대비, 태블릿 터치 환경을 실제 교실에서 확인한다.
5. 교사가 구매 이유로 보는 요소가 화려한 장면, 수업 시간 절감, 실험 안전, 정량 데이터, 평가 자료 중 무엇인지 인터뷰로 우선순위를 정한다.
6. 단품, 과목 묶음, 학교 라이선스별 가격 실험은 콘텐츠 완성도와 업데이트 범위를 먼저 정의한 뒤 진행한다.
7. 교사 검토와 별개로 중학생·고등학생 각 5명 이상의 사고구술 테스트에서 용어, 조작, 그래프 해석이 의도대로 연결되는지 확인한다.
8. 핵심 미션은 사전·사후 동형 문항과 2~4주 지연 문항으로 `즉시 정답`이 아니라 개념 전이·유지를 확인한다.
9. 학교별 교과서 단원 순서는 별도 매핑표로 관리하고, 국가교육과정 정합성과 출판사 차시 매핑을 혼동하지 않는다.

이 검증을 마친 후에야 실시간 대시보드, 학교 계정, LMS 연동 같은 운영 기능을 확장한다. 첫 제품의 경쟁력은 계정 기능의 수보다 **원리를 정확히 보여 주는 장면, 의미 있는 실험 다양성, 교사가 바로 쓸 수 있는 수업 설계**에서 만들어야 한다.
