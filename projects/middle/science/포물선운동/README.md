# 포물선 운동 실험

수업에서 교사가 전체 시연을 하고, 학생이 각도를 바꾸어 예상과 결과를 비교하는 2D 디지털 교구입니다.

## 현재 구현 범위

- 미션 1~3: 가장 먼 각도 찾기, 보완각 비교, 목표물 맞히기
- 30°, 45°, 60° 예상 선택과 발사각 조절
- 현재·이전 실험 궤적 비교, 거리·최고점·비행시간 표시
- 브라우저 안의 학생 제출과 교사용 익명 통계 데모
- 공기 저항이 없는 같은 높이 발사·착지 모델

## 실행과 배포용 빌드

`projectile-lab` 폴더에서 아래 명령을 실행합니다.

```sh
npm install
npm run dev
```

정적 배포 파일은 `../projectile-lab-static/`에 생성됩니다.

```sh
npm run build
```

## 실제 수업 세션 연결 전 주의

현재 교사 인사이트는 화면 흐름을 검증하기 위한 로컬 데모입니다. 실제 학생 제출을 수집하려면 참여 코드, 교사 인증, 행 단위 접근 제어, 보관 기간·삭제 정책을 갖춘 백엔드를 별도로 연결해야 합니다.
