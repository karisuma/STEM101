# 조석 시뮬레이터 만들기

학생과 선생님이 함께 바이브코딩으로 만든 STEM101의 첫 번째 제작 프로젝트입니다.

## 질문

달과 태양의 위치가 달라지면 제주 바닷물의 높이는 어떻게 변할까?

## 만들고 테스트할 것

- 해와 달을 각 궤도에서 움직일 수 있게 만들기
- 지구 표면의 관측 위치를 바꿀 수 있게 만들기
- 달과 태양의 조석 영향력을 각각 조절하기
- 하루 동안 예상되는 수위 변화를 그래프로 표시하기
- 해와 달이 비슷한 방향 또는 반대 방향에 있을 때 조석력이 강화되는지 확인하기
- 두 천체가 직각에 가까울 때 변화 폭이 줄어드는지 확인하기

## 제작 과정

1. 조석에 영향을 주는 해, 달, 지구의 관계를 질문으로 정리합니다.
2. Three.js로 천체와 궤도를 만들고 드래그 조작을 추가합니다.
3. 단순화된 주기 함수로 하루 수위 변화를 계산합니다.
4. 천체의 배치와 그래프의 변화가 예상과 일치하는지 테스트합니다.
5. 실제 조석과 다른 점을 찾아 모형의 한계를 설명합니다.

## 중요한 모형의 한계

현재 계산은 조석 원리를 직관적으로 살펴보기 위한 교육용 단순 모형입니다. 실제 조석 예측에 필요한 해저 지형, 해안선, 수심, 기상, 여러 분조와 지역별 위상차를 포함하지 않습니다. 따라서 실제 물때나 안전 판단에는 사용할 수 없습니다.

## 다음 수업에서 수정해 볼 질문

- 관측 위치를 바꾸면 그래프의 위상은 어떻게 달라져야 할까?
- 달의 거리가 가까워지거나 멀어지는 조건을 추가하면 무엇이 바뀔까?
- 실제 제주 조석 자료와 비교하는 테스트를 어떻게 만들 수 있을까?
- 현재 수식 중 과학적으로 더 정확하게 바꿀 수 있는 부분은 어디일까?
