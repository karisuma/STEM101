# STEM101 비식별 학급 서버

시뮬레이션의 공개 정적 파일과 분리된 좌석 라이선스·학급 표본 API입니다. 학생의 이름, 이메일, 전화번호, 생년월일을 입력하거나 저장하는 API가 없습니다. 학생은 `1반-3`, `학생12` 같은 좌석 별칭과 임의 토큰만 사용합니다.

## 실행 조건

- Node.js 22.5 이상(`node:sqlite` 사용)
- HTTPS 역방향 프록시와 서버 전용 영구 디스크를 권장
- 첫 실행 전 `STEM101_ADMIN_PASSWORD`에 12자 이상 암호 설정
- 공개 SITE origin을 `STEM101_ALLOWED_ORIGINS`에 쉼표로 등록

```text
STEM101_ADMIN_PASSWORD=<긴 암호> node server/classroom-server.mjs
```

기본 포트는 8787, DB는 `server/data/classroom.sqlite`입니다. 운영에서는 `PORT`, `STEM101_DB_PATH`, `STEM101_ADMIN_CODE`, `STEM101_ALLOWED_ORIGINS`를 환경 변수로 설정합니다. DB 파일과 환경 변수는 Git에 커밋하지 않습니다.

## 권한 흐름

1. 시스템 관리자가 관리자 API/콘솔에서 감독자 코드, 초기 암호, 좌석 한도, 만료일을 발급합니다.
2. 감독자는 수업을 만들며 남은 라이선스 좌석 한도 안에서 `학생1…N` 계정을 생성합니다.
3. 서버는 좌석별 임의 토큰을 한 번 반환합니다. 감독자는 생성된 학생 링크를 배포합니다.
4. 학생은 좌석 토큰으로 자기 결과를 제출하고 같은 수업의 비식별 표본을 읽습니다.
5. 감독자는 모든 실험 표본을 읽고 수업 변수 잠금 설정을 저장할 수 있습니다.

암호는 scrypt로 해시되며 세션·좌석 토큰은 SHA-256 해시만 DB에 저장됩니다. 수업 삭제 대신 복구 가능한 보관 처리를 사용합니다.
