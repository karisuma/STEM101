# Tide Lab

태양·지구·달의 상대적인 움직임과 한 관측 지점의 낮밤 및 조석 변화를
함께 보여주는 교육용 웹 시뮬레이터입니다.

## 실행

Node.js 20.19 이상 환경에서 아래 명령을 실행합니다.

```sh
npm install
npm run dev
```

프로덕션 빌드는 다음과 같습니다.

```sh
npm run build
```

## 현재 구현 범위

- React + TypeScript + Vite
- React Three Fiber 기반 3D 지구·태양·달
- 지구 집중 / 천체 보기 카메라
- 날짜 및 위도·경도 선택
- 브라우저 현재 위치 사용
- 24시간 자동 재생과 시간 탐색
- 태양 방향 기반 낮·밤 판정
- 달·태양의 2차 조석 퍼텐셜 합성
- 조석 팽대부의 교육용 3D 강조
- 선택 위치의 상대 수위 그래프
- 사리·조금 조건 비교

## 모델의 한계

이 앱은 실제 지역 조석 예보가 아니라 조석의 원리를 설명하는 개념
모델입니다. 해안선, 수심, 해저 지형, 코리올리 효과, 마찰, 해양 분지의
공진은 계산하지 않습니다. 화면의 해수면 변형은 이해를 돕기 위해 크게
강조됩니다.

조석 계산은 다음 형태의 2차 조석 퍼텐셜을 사용합니다.

```text
η(n, t) =
  A_moon × P₂(n · moonDirection)
  + A_sun × P₂(n · sunDirection)

P₂(x) = (3x² - 1) / 2
```

3D 해수면과 하단 그래프는 동일한 태양·달 방향 및 조석 모델을 공유합니다.
